## Обстановка

Семь правил тарифа на дорогу, и это только SJI. Позиционными аргументами их не
передать: через неделю никто не скажет, что означает третье число.

## Приказ

Написать `artifacts/tariff.rb`: класс `Abacus::Tariff` — правила тарифа одной
дороги.

## Договор вызова

```ruby
tariff = Abacus::Tariff.new(base_rate: 40)              # minimum: 0, rounding: :up
tariff = Abacus::Tariff.from(base_rate: 40, minimum: 250, rounding: :nearest)

tariff.to_h            # => { base_rate: 40, minimum: 250, rounding: :nearest }
tariff.with(minimum: 0) # => новый тариф; исходный не тронут

tariff.charge_for(entry)                                # ставка за 100 кг
tariff.charge_for(entry, surcharge: 100)                # + надбавка, сен
tariff.charge_for(entry, surcharge: 100, discount: 0.1) # − скидка, доля
tariff.charge_for(entry, **rules)                       # опции хешем
```

## Порядок счёта

Он часть договора, а не деталь реализации:

1. `base_rate` × вес ÷ 100 — ставка за сто килограммов;
2. плюс `surcharge` (в сенах);
3. минус `discount` (доля от полученного);
4. если вышло меньше `minimum` — берётся `minimum`;
5. округление по `rounding`.

## Критерии приёмки

- [ ] `base_rate:` обязателен и умолчания не имеет; `minimum:` по умолчанию `0`,
      `rounding:` по умолчанию `:up`.
- [ ] `rounding` принимает `:up`, `:down`, `:nearest`; всё остальное —
      `ArgumentError` со списком допустимых.
- [ ] Тариф заморожен (`frozen?` → `true`).
- [ ] `from(**options)` отвергает неизвестные ключи `ArgumentError`, называя и
      лишние, и известные. Молча отбрасывать нельзя.
- [ ] `with(**overrides)` возвращает **новый** тариф; исходный не меняется;
      неизвестные ключи отвергаются и здесь.
- [ ] `to_h` возвращает правила хешем, пригодным для `from(**...)`.
- [ ] `charge_for` считает в порядке, указанном выше.
- [ ] `surcharge:` и `discount:` — именованные, по умолчанию `0`; скидка вне
      `[0, 1]` — `ArgumentError`; неизвестная опция — тоже.
- [ ] Запись без `:weight` — `KeyError`, а не плата, посчитанная от нуля.
- [ ] `make test` → восемнадцать зелёных проверок.

## Подводный камень

`options.slice(*KNOWN)` короче проверки и никогда не падает. Именно поэтому он
здесь не подходит: опечатка в имени правила превратится в правило, которое не
применилось, — молча.
