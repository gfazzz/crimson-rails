## Обстановка

Одиннадцать файлов подключаются друг к другу путями от того места, где ты
сидишь. Перенеси папку — и ничего не найдётся.

## Приказ

Собрать `abacus` в гем. Артефакта два:

```bash
cp starter.rb      artifacts/abacus.rb        # точка входа, ляжет в lib/abacus.rb
cp starter.gemspec artifacts/abacus.gemspec   # паспорт
```

Модули прошлых серий готовы и лежат в `support/lib/abacus/`. Их менять не
нужно.

## Раскладка гема

```
abacus/
├── abacus.gemspec
├── README.md
├── LICENSE
└── lib/
    ├── abacus.rb          ← твоя точка входа
    └── abacus/
        ├── errors.rb  keys.rb  convertible.rb  entry.rb
        ├── ledger.rb  reports.rb  tariff.rb  registry.rb
        └── macros.rb  totals.rb  dynamic.rb
```

## Критерии приёмки

**Точка входа `abacus.rb`:**

- [ ] `require "abacus"` подтягивает всё: `Abacus::Ledger`, `Report`, `Tariff`,
      `Keys`, `Entry`, `Convertible`, `Registry`, `Loader`, `Finder`, `Macros`.
- [ ] Файлы подключаются через `require`, **не** `require_relative`: проверка
      раскладывает точку входа и библиотеку по разным каталогам.
- [ ] Порядок подключения верен: один из файлов подключает модуль из другого
      в момент чтения класса.
- [ ] `Abacus::VERSION` объявлен, заморожен и имеет вид `major.minor.patch`.
- [ ] Повторный `require "abacus"` возвращает `false`.
- [ ] Вне модуля `Abacus` не определено ничего: ни `::Ledger`, ни `::Entry`.

**Паспорт `abacus.gemspec`:**

- [ ] `name` — `"abacus"`; `version` берётся из `Abacus::VERSION`, а не
      вписана числом.
- [ ] `license` — `"MIT"`; `summary`, `description`, `authors` заполнены, без
      оставшихся заготовок вроде `TODO`.
- [ ] `required_ruby_version` разрешает 3.1 и запрещает 2.7.
- [ ] `files` включает `lib/abacus.rb` и файлы `lib/abacus/*.rb`, и собирается
      **без** `git ls-files`: паспорт должен читаться там, где нет репозитория.
- [ ] `require_paths` — `["lib"]`.
- [ ] `make test` → одиннадцать зелёных проверок.

## Подводный камень

`require_relative` при разработке работает: файлы лежат рядом. Проверка
специально кладёт точку входа отдельно от папки `abacus/` — так, как бывает в
установленном геме.

## Выполнение

```bash

cp starter.gemspec artifacts/abacus.gemspec
make test
```
