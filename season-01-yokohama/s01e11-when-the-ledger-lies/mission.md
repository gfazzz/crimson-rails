## Обстановка

Разбор останавливается на двести третьей строке с сообщением про `nil`.
Отправитель говорит, что виноват телеграф; телеграф говорит, что сеансы прошли
чисто. Разобраться нельзя, пока ошибка не называет, что и где случилось.

## Приказ

Написать `artifacts/errors.rb`: иерархию ошибок `Abacus` и загрузчик
`Abacus::Loader`.

## Договор вызова

```ruby
# источник — любой объект с fetch и close
loader = Abacus::Loader.new(source, known_roads: %w[NTK KSN HYG SJI])
loader.load        # => массив записей
loader.attempts    # => сколько раз обращались к источнику

Abacus::MalformedRow.new("нет кода дороги", line: 203).line     # => 203
Abacus::MalformedRow.new("нет кода дороги", line: 203).message  # содержит 203
```

## Иерархия

```
StandardError
└── Abacus::Error
    ├── Abacus::LedgerError        беда в самой ведомости — не повторять
    │   ├── Abacus::MalformedRow
    │   └── Abacus::UnknownRoad
    └── Abacus::TransmissionError  беда связи — повторить имеет смысл
```

## Критерии приёмки

- [ ] Все классы — ветвь `StandardError`, а не `Exception`.
- [ ] `Abacus::Error` — общий корень: `rescue Abacus::Error` ловит любую свою
      ошибку.
- [ ] `TransmissionError` **не** наследник `LedgerError`: их лечат по-разному.
- [ ] `LedgerError` принимает `line:`, отдаёт его через `attr_reader` и
      включает в `message`; без `line` сообщение не ломается; есть сообщение
      по умолчанию.
- [ ] `Loader#load` при `TransmissionError` повторяет обращение к источнику,
      но не более `MAX_ATTEMPTS` раз, после чего отдаёт ошибку наружу.
- [ ] Беды ведомости **не повторяются**: источник опрашивается один раз.
- [ ] `attempts` отражает число обращений и обнуляется при новой загрузке.
- [ ] Источник закрывается **всегда**: при удаче, при ошибке разбора и после
      исчерпания повторов — и ровно один раз.
- [ ] Исходное исключение не проглатывается: наружу выходит оно, а не
      результат `ensure`.
- [ ] Строка, не являющаяся записью, и запись без кода дороги дают
      `MalformedRow` с верным номером строки (нумерация с единицы).
- [ ] Дорога вне `known_roads` даёт `UnknownRoad` с кодом и номером строки;
      без `known_roads` дороги не проверяются.
- [ ] `make test` → девятнадцать зелёных проверок.

## Подводный камень

`ensure` — не место для `return` и не место для кода, который сам может
упасть. И то и другое стирает исходную ошибку, а вместе с ней — причину.
