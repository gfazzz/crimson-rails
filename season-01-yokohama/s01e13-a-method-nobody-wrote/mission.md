## Обстановка

Двадцать два поля тарифа — это шестьдесят шесть строк однообразного кода:
чтение, умолчание, проверка на пустоту. Меняется одно слово.

## Приказ

Написать `artifacts/macros.rb`: модуль `Abacus::Macros`, объявляющий поля
одной строкой.

## Договор вызова

```ruby
class TariffRow
  extend Abacus::Macros

  field :base_rate, default: 0
  field :rounding,  default: :up
  field :note
end

row = TariffRow.new(base_rate: 40)

row.base_rate       # => 40
row.rounding        # => :up      (умолчание)
row.note            # => nil
row.base_rate?      # => true
row.note?           # => false
row[:base_rate]     # => 40
row["rounding"]     # => :up
row.to_h            # => { base_rate: 40, rounding: :up, note: nil }
TariffRow.fields    # => [:base_rate, :rounding, :note]

TariffRow.new(mimimum: 5)   # ArgumentError
row[:clerk]                 # KeyError
```

## Критерии приёмки

- [ ] `field(name, default: nil)` создаёт метод чтения и предикат `name?`;
      возвращает сам класс, чтобы объявления сцеплялись.
- [ ] Умолчание каждого поля — своё: методы замыкают разные значения.
- [ ] Предикат истинен, когда значение не `nil` и не `false`; ноль и пустая
      строка — заполнены (s01e01).
- [ ] `fields` перечисляет поля в порядке объявления.
- [ ] Созданные методы **настоящие**: видны в `instance_methods`, находятся
      через `method`, подтверждаются `respond_to?` и не задевают
      `method_missing`.
- [ ] `initialize(**attributes)` отвергает неизвестные поля `ArgumentError`
      со списком известных.
- [ ] `[]` принимает символ и строку, учитывает умолчание, для неизвестного
      имени даёт `KeyError`, приватные методы полями не считает
      (`public_send`, не `send`).
- [ ] `to_h` возвращает все поля с умолчаниями.
- [ ] Наследник видит поля родителя, добавляет свои и **не изменяет список
      родителя**: `inherited` копирует, а не передаёт ссылку, и зовёт `super`.
- [ ] `make test` → двадцать зелёных проверок.

## Подводный камень

Тело метода, объявленного через `def`, не видит локальных переменных места
объявления. Именно поэтому `field` создаёт методы блоком: блок — замыкание и
помнит `name` и `default` своей строки.
