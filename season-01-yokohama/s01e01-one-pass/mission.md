## Обстановка

Четыреста двенадцать перевозок за декабрь, четыре дороги, три вопроса к
полудню. Вопросов завтра будет больше, и разграфлять новый бланк под каждый —
работа, которая растёт быстрее, чем ведомость.

## Приказ

Написать `artifacts/ledger.rb`: класс `Abacus::Ledger`, который обходит
ведомость **один раз** и отдаёт каждую запись тому, кто спрашивает.

## Данные

Запись ведомости — хеш:

```ruby
{ road: "NTK", cargo: "уголь", weight: 1200, charge: 340 }
```

| Ключ | Что значит |
|---|---|
| `:road` | код дороги: `NTK`, `KSN`, `HYG`, `SJI` |
| `:cargo` | груз |
| `:weight` | вес, кг |
| `:charge` | плата, сен |

Ведомость создаётся так: `Abacus::Ledger.new(entries)`, где `entries` — массив
таких хешей. Пустой массив — законная ведомость.

## Договор вызова

```ruby
ledger = Abacus::Ledger.new(entries)

ledger.each_entry { |entry| puts entry[:road] }   # → сама ведомость
ledger.each_entry                                  # → Enumerator
ledger.total_by   { |entry| entry[:charge] }       # → сумма плат
ledger.count_where { |entry| entry[:weight] > 2000 }  # → число записей
```

## Критерии приёмки

- [ ] `each_entry` вызывает блок ровно один раз на запись, в исходном порядке.
- [ ] `each_entry` с блоком возвращает **саму ведомость**, а не массив записей.
- [ ] `each_entry` без блока возвращает `Enumerator` и не поднимает
      `LocalJumpError`.
- [ ] `total_by` возвращает сумму значений, которые вернул блок; на пустой
      ведомости — `0`, а не `nil`.
- [ ] `total_by` обходит записи **через `each_entry`**, а не своим циклом по
      `@entries`.
- [ ] `count_where` считает записи по истинности значения блока: `nil` и
      `false` ложны, `0` и `""` истинны.
- [ ] `total_by` и `count_where` без блока поднимают `ArgumentError` с текстом,
      из которого понятно, какому методу нужен блок и зачем.
- [ ] `make test` → тринадцать зелёных проверок.

## Выполнение

```bash
cp starter.rb artifacts/ledger.rb
make test
```

весь смысл. Эталон — в `solution/`, открывай после честной попытки.

## После выполнения

Один бланк вместо трёх и три цифры на нём. Со следующей серии блок перестанет
быть безымянным: его понадобится сохранить, передать дальше и вызвать не
сейчас, а потом.
