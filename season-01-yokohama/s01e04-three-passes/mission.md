## Обстановка

Бланк с итогом внизу вернули. Нужен отчёт: платы столбцом, дороги списком,
тяжёлые перевозки отдельно от лёгких, средняя плата. Ведомость при этом должна
остаться тем, чем была, — хранилищем записей.

## Приказ

Написать `artifacts/reports.rb`: класс `Abacus::Report`, принимающий ведомость
и отвечающий на вопросы. Ведомость не менять — она готова в `support/ledger.rb`.

## Договор вызова

```ruby
report = Abacus::Report.new(Abacus::Ledger.new(entries))

report.charges                  # => [340, 0, 712, ...]      порядок ведомости
report.roads                    # => ["NTK", "KSN", "HYG", "SJI"]
report.heavier_than(2000)       # => [записи]
report.lighter_than(2000)       # => [записи]
report.split_by_weight(2000)    # => [[тяжёлые], [лёгкие]]
report.total_charge             # => 61_240
report.longest_cargo_name       # => "каменный уголь"
report.average_charge           # => 448.7
```

## Критерии приёмки

- [ ] `charges` — платы в порядке ведомости, ни одной не потеряно.
- [ ] `roads` — коды дорог без повторов, **в порядке первого появления**; на
      пустой ведомости — пустой массив.
- [ ] `heavier_than(kg)` отбирает **строго** тяжелее `kg`: ровно `kg` не
      подходит.
- [ ] `lighter_than(kg)` — дополнение: вместе они дают всю ведомость и не
      пересекаются.
- [ ] `split_by_weight(kg)` возвращает обе половины **за один обход**.
- [ ] `total_charge` на пустой ведомости возвращает `0`, а не `nil`.
- [ ] `longest_cargo_name` — самое длинное название; при равной длине остаётся
      **первое встретившееся**; на пустой ведомости — `nil`.
- [ ] `average_charge` — дробное число (1 и 2 дают 1.5, а не 1); на пустой
      ведомости — `nil`, а не `0` и не деление на ноль.
- [ ] `make test` → пятнадцать зелёных проверок.

## Подводные камни

**Пустая ведомость.** Три метода из восьми ведут себя на ней особым образом, и
все три проверяются. Прежде чем писать метод, спроси: что он должен ответить,
если записей нет вовсе?

**Ноль или `nil`.** `total_charge` на пустой — ноль: сумма ничего равна нулю.
`average_charge` на пустой — `nil`: средней не существует. Разница не
стилистическая.

## После выполнения

Отчёт уходит в Токио. Со следующей серии начальник станции спросит не общий
итог, а по каждой дороге отдельно, — и выяснится, что у одной из них сумма не
сходится.
