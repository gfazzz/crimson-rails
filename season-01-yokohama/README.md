## Season 1. Previously

Ничего. Это начало.

Императорская японская дорога заказала Расчётной палате методику сквозных
тарифов: четыре компании, одна колея, и никто не может договориться, кто кому
сколько должен за груз, проехавший по всем четырём. Палата взялась. Ехать
через полмира на маленький подряд никто из старших не захотел.

Поехал ты — младший вычислитель, с рекомендательным письмом, стопкой бланков
и адресом телеграфной конторы в Йокогаме, через которую можно достать машину
на Сеймур-стрит. Ответ идёт сутки и стоит по слову.

В первой же японской ведомости, которую тебе дадут свести, будет строка,
помеченная красным. Ты решишь, что это описка писаря. Через семь месяцев, уже
в Лондоне, ты поймёшь, что видел её первым.

## Что даёт сезон

Ruby в объёме, который делает Rails объяснимым, — и ни строчкой больше.
Критерий отбора жёсткий: **концепт входит в сезон, только если без него Rails
выглядит магией.** Поэтому здесь есть блоки, `Enumerable`, хеш как способ
передать API, модули и порядок предков, `self`, исключения и чтение чужого
метапрограммирования — и нет ни потоков, ни Fiber, ни refinements, ни
построения своего DSL с нуля.

Один сезон не делает из человека рубиста, и не пытается. На C в OPERATION
MOONLIGHT ушло восемьдесят серий; курс по Ruby такого же размера был бы
отдельным курсом, а не первым сезоном этого.

**Чем сезон кончается.** Не «напиши ещё одну библиотеку», а чтение чужого
кода: в `s01e15` ты открываешь исходник `ActiveSupport::Concern` — сорок строк
настоящего метапрограммирования — и объясняешь каждую строку. Можешь
объяснить — сезона хватило.

## Контракт проверки сезона

`SPEC.md` §4. Для этого сезона:

**Обязан проверять** — свойства поведения на произвольных данных: блок вызван
ровно N раз; модуль подмешан, а не унаследован; `each_slice` корректен на
неполном последнем куске; метод вернул то, что обещал вернуть, включая
краевые случаи (пустая ведомость, одна запись, запись с нулевой платой).

**Не засчитывается как проверка** — сравнение вывода с эталонной строкой;
пример вместо свойства; поиск подстроки в коде студента.

Из этого следует устройство тестов сезона: минитест поверх артефакта, данные
генерируются в самом тесте (с фиксированным seed, где нужна случайность), и
ни один тест не читает исходник студента как текст.

## Сквозной артефакт: `abacus`

Счётная библиотека Палаты. Растёт от серии к серии и к `s01e14` собирается в
настоящий гем:

```
abacus/
├── lib/
│   ├── abacus.rb
│   └── abacus/
│       ├── ledger.rb      s01e01–s01e03
│       ├── reports.rb     s01e04–s01e05
│       ├── tariff.rb      s01e06–s01e07
│       ├── entry.rb       s01e08
│       ├── convertible.rb s01e09
│       ├── registry.rb    s01e10
│       ├── errors.rb      s01e11
│       ├── dynamic.rb     s01e12
│       └── macros.rb      s01e13
└── abacus.gemspec         s01e14
```

В сезоне 4 `abacus` не выбрасывается: он становится обычным гемом внутри
приложения Rails и продолжает считать то, что считал.

## Требования среды

Ruby 3.3 или новее (`ruby -v`). Минитест входит в поставку Ruby — ставить
нечего. Ни Rails, ни базы, ни сети в этом сезоне не нужно.

```bash
make test SEASON=01        # весь сезон
make test SERIES=s01e01    # одна серия
```
