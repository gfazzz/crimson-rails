**Потом написать своё.** `artifacts/concern.rb`: модуль `Abacus::Concern`,
делающий то же самое.

## Договор вызова

```ruby
module Weighable
  extend Abacus::Concern

  included do
    @weighable_host = name          # выполнится в КЛАССЕ-хозяине
  end

  class_methods do
    def unit_name = "килограмм"
  end

  def heavy? = weight > 2000
end

module Billable
  extend Abacus::Concern
  include Weighable                 # зависимость: ждёт настоящего класса
end

class Shipment
  include Billable
end

Shipment.unit_name          # => "килограмм"  — ClassMethods дошли
Shipment.ancestors          # => [Shipment, Billable, Weighable, Object, ...]
Shipment.new(2400, 10).heavy?
```

## Критерии приёмки

**Примесь:**

- [ ] `extend Abacus::Concern` заводит примеси список зависимостей.
- [ ] Методы экземпляра подмешиваются как обычно.
- [ ] Вложенный `ClassMethods` подключается **сам**, без ручного хука.
- [ ] Блок `included do ... end` выполняется в контексте класса-хозяина:
      `self` в нём — класс.
- [ ] Примесь, включённая в другую примесь, **не включается в неё**, а ждёт;
      при включении зависящей примеси в класс зависимость попадает в **этот
      класс**.
- [ ] Порядок предков: зависящий ближе к классу, чем зависимость.
- [ ] `ClassMethods` зависимости тоже доходят до класса-хозяина.
- [ ] Повторное включение в тот же класс не делает ничего — в том числе не
      выполняет блок `included` второй раз.
- [ ] Второй блок `included` — `Abacus::Concern::MultipleIncludedBlocks`.
- [ ] `class_methods` дважды дополняет **один и тот же** модуль.
- [ ] `included(base)` с аргументом продолжает работать как обычный хук Ruby.

**Приёмка сезона:**

- [ ] Пятнадцать проверок, по одной на каждую серию, проходят через собранный
      гем `abacus` из `support/lib/`.
- [ ] Ни одна из них не вводит новой темы.

- [ ] `make test` → двадцать семь зелёных проверок.

## Подводный камень

Перехватывать нужно `append_features`, а не `included`. Хук `included`
срабатывает **после** включения и отменить его не может, а весь приём держится
на возможности не включиться.
