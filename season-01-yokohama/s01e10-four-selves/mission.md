## Обстановка

Колея, единица веса, минимум и округление у каждой дороги свои. Сейчас эти
сведения лежат в трёх местах кода, и дважды их правили порознь.

## Приказ

Написать `artifacts/registry.rb`: класс `Abacus::Registry` — книга дорог, одна
на контору.

## Договор вызова

```ruby
Abacus::Registry.register("NTK", gauge: 1067, unit: :lb)
Abacus::Registry["NTK"]        # => { gauge: 1067, unit: :lb }
Abacus::Registry.codes         # => ["NTK"]
Abacus::Registry.each { |code, rules| ... }
Abacus::Registry.instance      # тот же объект при каждом вызове
Abacus::Registry.reset!        # забыть реестр (нужно тестам)

Abacus::Registry.configure do
  register("SJI", gauge: 1067, unit: :kan)   # без получателя
  register("KSN", gauge: 1067, unit: :kg)
end

registry = Abacus::Registry.new              # отдельный реестр — законен
registry.register("TKY", gauge: 1435, unit: :kg).codes
```

## Критерии приёмки

- [ ] `register(code, gauge:, unit:)` запоминает дорогу и возвращает `self`;
      вызовы сцепляются.
- [ ] Повторная запись того же кода заменяет правила и не плодит дубликат.
- [ ] `[]` для неизвестного кода — `KeyError` с кодом и списком известных.
- [ ] `codes` — коды дорог; `each` без блока — `Enumerator`, с блоком —
      возвращает сам реестр.
- [ ] `Registry.instance` возвращает **один и тот же** объект; `reset!`
      заставляет создать новый.
- [ ] Переменная реестра принадлежит **классу**, а не экземпляру: у
      `Registry.new` её нет. `@@переменные` не использовать.
- [ ] `Registry.register`, `[]`, `codes`, `each`, `configure` — методы класса,
      делегирующие экземпляру, а не второе хранилище.
- [ ] Эти методы определены через `class << self`.
- [ ] `configure(&block)` выполняет блок так, что `register` вызывается **без
      получателя**, и возвращает реестр.
- [ ] Внутри `configure` по-прежнему видны локальные переменные вызывающего
      кода.
- [ ] `make test` → шестнадцать зелёных проверок.

## Подводный камень

`configure`, написанный как `block.call(self)`, компилируется и проходит часть
проверок. Вызов `register` без получателя при этом работать не будет: аргумент
— не то же самое, что подменённый `self`.
