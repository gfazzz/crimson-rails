# Теория — s01e09

## 1. Цепочка предков — это всё, что нужно понимать

Поиск метода в Ruby устроен предельно просто: взять `ancestors`, идти слева
направо, взять первый найденный метод. Всё остальное — следствия.

```ruby
class Shipment
  prepend Rounded
  include Convertible
end

Shipment.ancestors
# [Rounded, Shipment, Convertible, Object, Kernel, BasicObject]
```

| Где | Кто туда попадает |
|---|---|
| перед классом | `prepend` |
| сам класс | его методы |
| сразу за классом | `include`, последний включённый — ближе |
| дальше | родительский класс и его модули |

`extend` не показан в `ancestors` класса: он кладёт модуль в **одиночный
класс** объекта. Увидеть можно так: `obj.singleton_class.ancestors`.

## 2. Порядок нескольких `include`

```ruby
class A
  include M1
  include M2
end
A.ancestors   # [A, M2, M1, Object, ...]
```

Последний включённый оказывается ближе к классу — то есть побеждает. Это
противоположно интуиции «читаю сверху вниз», и на этом иногда спотыкаются,
подключая два модуля с одноимёнными методами.

Повторный `include` того же модуля ничего не делает: модуль уже в цепочке.

## 3. `extend`: два совершенно разных применения

```ruby
obj.extend(M)          # методы M становятся методами ЭТОГО объекта
class C; extend M; end # методы M становятся методами КЛАССА C
```

Второе — частный случай первого: класс тоже объект, и `extend` кладёт модуль в
его одиночный класс. Отсюда идиома с хуком `included`.

Третий способ записи того же:

```ruby
class C
  class << self
    include M       # то же, что extend M
  end
end
```

`class << self` — явное открытие одиночного класса. В `s01e10` он будет
разобран отдельно.

## 4. `prepend` и почему он появился поздно

`prepend` добавлен в Ruby 2.0. До него единственным способом обернуть чужой
метод была цепочка псевдонимов:

```ruby
class Shipment
  alias_method :weight_kg_without_rounding, :weight_kg
  def weight_kg = weight_kg_without_rounding.round
end
```

Этот приём (`alias_method_chain` в старом Rails) работал, но плодил имена,
ломался при двойном применении и делал трассу нечитаемой. `prepend` решает ту
же задачу честно: модуль встаёт перед классом, `super` идёт в исходный метод,
цепочка видна в `ancestors`.

Практические применения: измерение времени, журналирование, кеширование,
проверка прав — всё, что оборачивает существующее поведение, не переписывая его.

## 5. Хуки

| Хук | Когда зовётся |
|---|---|
| `self.included(base)` | при `include` |
| `self.extended(base)` | при `extend` |
| `self.prepended(base)` | при `prepend` |
| `self.inherited(sub)` | при наследовании |
| `method_added(name)` | при определении метода |

Все они — обычные методы, которые Ruby вызывает сам. На них построено
практически всё, что выглядит как магия фреймворков: регистрация подклассов,
объявление атрибутов, автоматическое подключение.

`ActiveSupport::Concern` — обёртка над `included`, решающая две его проблемы:
вложенный `ClassMethods` подключается сам, и разрешаются зависимости между
модулями, которые включают друг друга. В `s01e15` разберём её построчно.

## 6. Модуль как роль: критерий выбора

| Вопрос | Ответ |
|---|---|
| «Чем это является?» | наследование |
| «Что это умеет?» | примесь |
| «Что у этого есть?» | композиция (поле-объект) |

Ошибка выбора обычно выглядит так: роль приписали наследованием, а через
полгода понадобился второй родитель. В Ruby родитель один, и лечение — переписывание.

Обратная ошибка тоже реальна: примесь, которая тащит в класс состояние
(переменные экземпляра) и зависит от его внутренностей. Такой модуль — не роль,
а половина класса, и лучше бы ему стать отдельным объектом.

Признак здоровой примеси: она зовёт **публичные** методы хозяина и не заводит
своих переменных экземпляра.

## 7. Пересчёт через общую единицу

Три единицы — три коэффициента, а не девять пар. Общая единица (килограмм)
делает таблицу линейной:

```
kan ──×3.75──► kg ──÷0.4536──► lb
```

Добавление четвёртой единицы добавляет одну строку, а не четыре. Тот же приём
— в кодировках (всё через Unicode), во времени (всё через UTC), в деньгах
(всё через одну валюту на момент операции).
