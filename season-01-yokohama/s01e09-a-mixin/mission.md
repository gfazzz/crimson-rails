## Обстановка

SJI ведёт вес в кан, NTK в фунтах, KSN и HYG в килограммах. Пересчёт нужен не
только записи ведомости, но и вагону, партии, тарифной строке — всему, у чего
есть вес и единица.

## Приказ

Написать `artifacts/convertible.rb`: модуль `Abacus::Convertible` (роль «умеет
пересчитывать вес») и модуль `Abacus::Rounded` (округление поверх чужого
расчёта).

Класс-хозяин писать не нужно: его определяет тест. Модуль не должен знать, как
хозяин устроен, — только что у него есть `weight` и `unit`.

## Данные

| Единица | Килограммов в одной |
|---|---|
| `:kg` | 1 |
| `:kan` | 3.75 |
| `:lb` | 0.45359237 |

## Договор вызова

```ruby
class Shipment
  include Abacus::Convertible
  attr_reader :weight, :unit
end

Shipment.units                            # => [:kg, :kan, :lb]
Shipment.new(213, :kan).weight_kg         # => 798.75
Shipment.new(3.75, :kg).weight_in(:kan)   # => 1.0
Shipment.new(1, :shaku).weight_kg         # ArgumentError

class RoundedShipment < Shipment
  prepend Abacus::Rounded
end
RoundedShipment.new(213, :kan).weight_kg  # => 799
```

## Критерии приёмки

- [ ] `weight_kg` пересчитывает вес хозяина в килограммы по его `unit`.
- [ ] `weight_in(target)` переводит в запрошенную единицу **через
      килограммы**, а не таблицей всех пар.
- [ ] Круговой пересчёт возвращает исходное число.
- [ ] Неизвестная единица — `ArgumentError` со списком известных; и на входе,
      и на выходе.
- [ ] `include` даёт классу-хозяину метод **класса** `units` — через хук
      `self.included` и `extend`, а не через `include`.
- [ ] `units` не становится методом экземпляра.
- [ ] Модуль появляется в `ancestors` хозяина и не меняет его `superclass`.
- [ ] `Abacus::Rounded` округляет результат, получая его через `super`, а не
      считая заново.
- [ ] `prepend` ставит `Rounded` перед классом в `ancestors`.
- [ ] `extend` на отдельном объекте работает так же и не затрагивает соседей.
- [ ] Исходный `weight_kg` после всего этого возвращает прежнее дробное
      значение.
- [ ] `make test` → шестнадцать зелёных проверок.

## Подводный камень

В хуке `included` тянет написать `base.include(ClassMethods)`. Это добавит
`units` каждой перевозке и ни разу — самому классу. Нужен `extend`.
