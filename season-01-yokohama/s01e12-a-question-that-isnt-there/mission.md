## Обстановка

Каждый новый вопрос к ведомости — два новых метода одинакового устройства.
Меняется не действие, а имя.

## Приказ

Написать `artifacts/dynamic.rb`: класс `Abacus::Finder`, разбирающий имена
`find_by_<поле>` и `count_by_<поле>` на лету.

Модуль `Abacus::Totals` уже написан и лежит в `support/`. Его нужно подключить.
Он разбирает **свои** имена — `total_by_road`, `total_by_cargo` — и стоит в
цепочке позади `Finder`.

## Договор вызова

```ruby
finder = Abacus::Finder.new(entries)

finder.find_by_road("SJI")     # => записи этой дороги, в порядке ведомости
finder.find_by_cargo("чай")
finder.count_by_road("SJI")    # => число
finder.total_by_road("SJI")    # => сумма; это разбирает Totals

finder.respond_to?(:find_by_road)    # => true
finder.method(:count_by_cargo)       # => Method
finder.find_by_clerk("Ито")          # NoMethodError
```

Поля: `road`, `cargo`, `weight`, `charge`.

## Критерии приёмки

- [ ] `find_by_<поле>(значение)` возвращает подходящие записи в порядке
      ведомости; ничего не нашлось — пустой массив.
- [ ] `count_by_<поле>(значение)` возвращает их число и согласован с поиском.
- [ ] Имя вне образца — `NoMethodError`, и в сообщении видно имя метода.
      Достигается вызовом `super`, а не своим `raise`.
- [ ] Обычные методы объекта (`entries`, `to_s`, `inspect`) не сломаны.
- [ ] Ровно один аргумент; иначе `ArgumentError` с именем метода.
- [ ] `respond_to?` подтверждает разбираемые имена и отрицает прочие.
- [ ] `method(:find_by_road)` возвращает рабочий `Method` — значит,
      переопределён `respond_to_missing?`, а не `respond_to?`.
- [ ] Подключён `Abacus::Totals`, и его имена работают: `total_by_road`
      считает сумму, `respond_to?` его признаёт, `method` его находит.
      Это проверяет, что незнакомое имя передаётся **дальше по цепочке**.
- [ ] Имя, неизвестное обоим, по-прежнему даёт `NoMethodError`.
- [ ] `method_missing` и `respond_to_missing?` — приватные.
- [ ] `make test` → двадцать три зелёные проверки.

## Подводный камень

`return nil unless match` вместо `return super unless match` проходит половину
проверок и ломает две вещи сразу: опечатка превращается в `nil`, а методы
подмешанного модуля исчезают без следа.
