## Обстановка

Дороги прислали собственные итоги. Общего числа для сверки мало: расхождение
надо искать по каждой дороге отдельно, а такого свода у отчёта пока нет.

## Приказ

Добавить в `artifacts/reports.rb` четыре метода. Ведомость не менять.

## Договор вызова

```ruby
report.charges_by_road
# => { "NTK" => 18_420, "KSN" => 14_905, "HYG" => 11_260, "SJI" => 16_655 }

report.cargo_counts
# => { "уголь" => 12, "рис" => 9, "чай" => 7 }

report.summary_by_road
# => { "NTK" => { count: 41, weight: 84_120, charge: 18_420 }, ... }

report.mismatch("NTK" => 18_420, "KSN" => 14_905, "HYG" => 11_260, "SJI" => 16_615)
# => { "SJI" => 40 }
```

## Критерии приёмки

- [ ] `charges_by_road` — сумма плат по каждой дороге; дорога с единственной
      перевозкой присутствует; на пустой ведомости — пустой хеш.
- [ ] `cargo_counts` — сколько раз встретился каждый груз; на пустой
      ведомости — пустой хеш.
- [ ] `summary_by_road` — три итога (`count`, `weight`, `charge`) по каждой
      дороге, собранные **за один обход ведомости**.
- [ ] Сумма `charge` по всем дорогам в своде совпадает с `total_charge`.
- [ ] `mismatch(reported)` возвращает **только** расхождения: дорога →
      (наш итог − присланный).
- [ ] Всё сошлось — возвращается пустой хеш, без нулевых строк.
- [ ] Знак расхождения сохраняется: наш итог меньше — число отрицательное.
- [ ] Дорога, которая есть только у одной из сторон, попадает в расхождения на
      всю свою сумму, а не пропускается.
- [ ] `make test` → пятнадцать зелёных проверок.

## Подводные камни

**Один обход.** Три группировки подряд дадут верный ответ и три прохода по
ведомости. Тест считает обходы.

**Порядок аргументов.** У `each_with_object` он обратный к `reduce`: сначала
элемент, потом накопитель.

**Ключи сверки.** Обходить надо объединение ключей обеих сторон. Дорога,
которой нет у тебя, — самое интересное расхождение из возможных.
