## Обстановка

Четыре дороги, четыре ведомости. Начальник станции хочет самую тяжёлую
перевозку, десять самых дорогих, всё тяжелее трёх тонн и разбивку по дорогам.
Четыре метода уже написаны, и все четыре устроены одинаково.

## Приказ

Дополнить `artifacts/ledger.rb`: объявить ведомость перечислимой и **убрать**
то, что после этого писать не нужно.

Эта серия единственная в сезоне, где файл должен стать **короче**.

## Договор вызова

```ruby
ledger = Abacus::Ledger.new(entries)

ledger.map { |e| e[:charge] }
ledger.select { |e| e[:road] == "SJI" }      # => Array
ledger.sort_by { |e| e[:charge] }
ledger.max_by { |e| e[:weight] }
ledger.each_slice(8).to_a
ledger.lazy.select { |e| e[:weight] > 3000 }.first(3)

ledger.each_entry { |e| ... }                # имя из s01e01 по-прежнему работает
ledger.top_by(4) { |e| e[:charge] }          # => четыре самые дорогие
ledger.by_road                               # => { "NTK" => [...], "SJI" => [...] }
```

## Критерии приёмки

- [ ] `Abacus::Ledger` подключает `Enumerable` (`ancestors` это показывает).
- [ ] Обход называется `each`, отдаёт записи **по одной** через `yield`,
      возвращает `self`, без блока — `Enumerator`.
- [ ] `each_entry` продолжает работать и вести себя как раньше.
- [ ] `total_by` и `count_where` переписаны средствами модуля: ручного
      накопителя в них больше нет, поведение прежнее, включая `ArgumentError`
      без блока.
- [ ] `top_by(n, &key)` возвращает `n` самых крупных; если записей меньше `n` —
      отдаёт сколько есть; без блока — `ArgumentError`.
- [ ] `by_road` возвращает хеш «код дороги → её записи» и **ничего не
      фильтрует**: дорога с единственной перевозкой остаётся в своде.
- [ ] Ленивый обход не перебирает всю ведомость ради трёх записей.
- [ ] Правила из `s01e02` продолжают работать без изменений.
- [ ] `make test` → семнадцать зелёных проверок.

## Подводный камень

Соблазн написать `each` так:

```ruby
def each(&block)
  @entries.each(&block)      # выглядит аккуратнее
end
```

Работать будет почти всё, кроме двух вещей: метод вернёт `@entries` вместо
`self` (проверка из `s01e01`), а без блока отдаст `Enumerator` **массива**, а не
ведомости. Разница вылезет в `s01e08`, когда у записей появится класс.
