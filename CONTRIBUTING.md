# Как устроен репозиторий и как в него писать

## Если ты проходишь курс

Форкни репозиторий и работай в своём форке. Твой код живёт **только** в
`artifacts/` внутри серии:

```bash
cd season-01-yokohama/s01e01-one-pass
cp starter.rb artifacts/ledger.rb
make test
```

Коммить свои решения в свой форк не возбраняется, наоборот: история коммитов —
это и есть свидетельство прохождения, куда честнее сертификата. Но **пулл-реквест
в курс не должен содержать файлов из `artifacts/`** — это проверяет CI
(`.github/workflows/pr-guard.yml`).

## Если ты правишь курс

### Серия

Каталог серии называется `sNNeMM-<латинский-слаг>` и содержит:

| Файл | Что внутри | Объём |
|---|---|---|
| `README.md` | сцена, теория, «Проверка», задание, разбор ошибок, развязка, ссылки | 180–300 строк |
| `mission.md` | брифинг: обстановка, приказ, дано, критерии приёмки | в форме брифинга |
| `theory.md` | углубление, компромиссы, источники | 110–200 строк |
| `starter.rb` | каркас с `TODO` (в сезонах 4–8 — каталог `starter/`) | |
| `solution/` | эталон | |
| `tests/` | проверка свойств | |
| `artifacts/` | пусто, только `.gitkeep` | |
| `Makefile` | цель `test` | |

Разделы `README.md` идут строго в порядке, заданном `SPEC.md` §2. Серия
длиннее 300 строк — повод разделить её надвое.

### Тест

Шесть требований — `SPEC.md` §6. Коротко:

1. без внешних сервисов; серии, которым нужен браузер, кладут рядом пустой
   файл `NEEDS_BROWSER` и уходят в `make test-visual`;
2. проверяется свойство, а не текст: тест не ищет подстроку в коде студента;
3. первый прогон на `starter` красный, и его вывод объясняет, чего не хватает;
4. воспроизводимость: никакого системного времени и случайности без seed;
5. фолбэк на `solution/`, чтобы репозиторий всегда был зелёным;
6. каждая проверка — дискриминатор: падает на правдоподобно неверном решении.

Проверить последнее можно руками: испортить `solution/` правдоподобным
способом и убедиться, что тест покраснел.

### Тексты

- обращение к читателю — на «ты», во всех документах;
- по-русски, без рунглиша (`.cursorrules`, раздел «Язык курса»);
- ADA — машина: без похвалы, эмоций и смайликов;
- железнодорожное сравнение живёт, только если объясняет концепт; если его
  можно выбросить без потери — выбрасывают (`CONCEPT.md`, «правило метафоры»);
- даты и локации — из `docs/ROUTE.md`, не сочиняются на месте.

### Прогон

```bash
make test                 # все серии
make test SEASON=01       # один сезон
make test SERIES=s01e01   # одна серия
make test-visual          # серии, которым нужен headless-браузер
make links                # битые ссылки между документами
make check                # links + test, как в CI
make progress             # где я остановился
```

### Порядок работы над сезоном

Пилотная серия целиком → приёмка по `SPEC.md` §11 → остальные серии.
**Не генерировать сезон целиком «с доработкой потом»** — в двух выпущенных
курсах это каждый раз приводило к переписыванию с нуля.
