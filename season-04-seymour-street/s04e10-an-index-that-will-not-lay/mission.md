## Обстановка

Три недели шесть клерков вводили в машину маршрутные листы из бумажных книг.
Пять тысяч четыреста строк с шестьдесят девятого года: бланк, номер участка,
дорога, станция, мили, ключ ввода клерка.

На эту таблицу надо положить то же правило, что стоит в реестре с шестой
серии: на один участок одного бланка — одна строка.

Оно не ложится. Тысяча восемьсот пар.

## Приказ

Завести архив, разобрать повторы и объявить правило базе. Четырьмя
миграциями, и порядок их — часть задания.

## `db/migrate` — четыре шага

### 1. `CreateEntries` — схема

| Столбец | Каким быть |
|---|---|
| `docket` | номер бланка, строка, обязательный |
| `position` | номер участка в бланке, целое, обязательный |
| `company_code` | код дороги — **строкой, не ссылкой** |
| `station` | станция передачи, **необязательная** |
| `miles` | целое, обязательное |
| `clerk` | ключ ввода, строка, обязательный |
| `+ две даты` | |

Дорога кодом, а не ссылкой на реестр: внешний ключ потребовал бы, чтобы каждая
дорога шестьдесят девятого года нашлась в реестре сегодня. Половина из них с
тех пор слилась, переименовалась или исчезла. **Архив хранит написанное, а не
существующее.**

Станция необязательна по той же причине: в листах шестидесятых её не писали.

Индекс по паре «бланк + участок» — **обычный, не уникальный**. По нему архив
ищут и по нему же находят повторы.

### 2. `AddVoidedAtToEntries` — схема

| Что | Как |
|---|---|
| `voided_at` | время, **необязательное** |

`null: false` здесь невозможен: у пяти тысяч существующих строк значения нет.

Отдельная миграция, потому что следующий шаг стоит дорого, а этот — нет.

### 3. `VoidDuplicateDockets` — данные

Правило Палаты: из строк с одной парой «бланк + участок» живой остаётся
**самая ранняя**. Остальные гасятся — отметкой, а не удалением.

| Что | Как |
|---|---|
| проводка | снята: долгий проход не держат одной проводкой |
| модель | **своя**, объявленная в самой миграции |
| проход | порциями; ни одним запросом, ни строка за строкой |
| перезапуск | отбор считается заново на каждом заходе |
| откат | подумай, что тут вообще можно откатить |
| схема | не трогается: это шаг с данными |

### 4. `EnforceOneLiveDocket` — ограничение

| Что | Как |
|---|---|
| индекс | уникальный по паре «бланк + участок» |
| условие | только живые строки |
| имя | своё: имя, которое придумает Rails, совпадёт с именем индекса из шага 1 |

## Критерии приёмки

**Архив**

- [ ] Таблица `entries` ровно с этими столбцами.
- [ ] Дорога — строка; внешнего ключа на реестр нет.
- [ ] Станция может быть пустой.
- [ ] Индекс по паре «бланк + участок» есть и **не уникальный**.

**Отметка о погашении**

- [ ] `voided_at` — время, необязательное.
- [ ] Её **нет** в первой миграции: столбец добавляют к живой таблице отдельно.

**Шаги**

- [ ] У шага с данными проводка снята.
- [ ] У шагов со схемой проводка на месте.
- [ ] Шаг с данными схему не меняет.

**Разбор повторов**

- [ ] Все миграции доходят до конца на архиве, в котором уже лежат строки.
- [ ] В живой части на каждую пару «бланк + участок» одна строка.
- [ ] Живой остаётся самая ранняя.
- [ ] Строки, у которых нет пары, не тронуты.
- [ ] Ни одна строка не удалена; погашенные читаются по-прежнему.
- [ ] Проход идёт порциями: запросов на запись больше одного и много меньше,
      чем строк.

**Перезапуск**

- [ ] Шаг, оборванный посередине, при повторном запуске доделывает работу.
- [ ] Второй прогон шага ничего не меняет.

**Ограничение**

- [ ] Уникальный индекс есть и он **частичный**.
- [ ] Сырой `INSERT` второй живой строки на тот же участок отвергается базой.
- [ ] Строка ложится, если её близнец погашен.
- [ ] Погашенных строк на один участок бывает сколько угодно.

**Приёмка сезона**

- [ ] Форма ведомости объявлена миграцией, а не подразумевается.
- [ ] Деньги — целыми пенсами, даты — датами.
- [ ] За каждой уникальностью в модели стоит уникальный индекс.
- [ ] Связь не оставляет сирот: внешние ключи и `dependent:` расставлены.
- [ ] Выручка делится по участкам, и участок уникален в своей перевозке.
- [ ] Свод за пять лет идёт без N+1.
- [ ] Условия на значения проверяет база, а не только модель.
- [ ] Расчёт за месяц ложится целиком или не ложится вовсе.
- [ ] Правило можно объявить на данных, которые ему пока не соответствуют.
- [ ] Откат до нуля оставляет пустую схему.

- [ ] `make test` → двадцать четыре зелёные проверки.
- [ ] `make solution` в корне сезона → десять серий, ни одной красной.

## Подводный камень

Первый: одна миграция вместо трёх. Хочется, потому что изменение одно. На
живой таблице это проводка, которая держится столько, сколько идёт заполнение.

Второй: отбор, посчитанный один раз, до прохода. На целом прогоне он верен, а
после обрыва — уже нет: часть работы сделана, и список лишних другой.

Третий: удалить повторы. Быстрее, короче и необратимо. Спроси сначала, имеют
ли эти строки цену как история; здесь имеют, и именно они оказались уликой.

Четвёртый: уникальный индекс без условия при том, что погашенные строки
остались лежать. Пара «бланк + участок» окажется занята навсегда.

## Выполнение

```bash
cp -R starter/. ../app/
# написать четыре миграции
cd ../app && bin/rails db:migrate && cd -
make test
```

Если миграция прогналась пустой заготовкой, её версия уже записана как
пройденная, и Rails к файлу не вернётся. Прогнать заново, с нуля:

```bash
cd ../app && bin/rails db:migrate:reset
```

дорога, одна станция, один ключ ввода, двадцать два года.
