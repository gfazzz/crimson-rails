# CRIMSON RAILS

**Заготовка курса по Ruby on Rails 8. Кода пока нет — есть концепция и ТЗ.**

| Документ | О чём |
|---|---|
| [CONCEPT.md](CONCEPT.md) | сеттинг, чему учит, сезоны, почему это проверяемо |
| [SPEC.md](SPEC.md) | техническое задание: структура, канон серии, требования к тестам, критерии приёмки |

Источник идеи — [eurecable.com/ideas/972](https://eurecable.com/ideas/972).

**Восемь сезонов, а не четыре.** Курс не начинается с `rails new`: первые три
сезона — Ruby как язык, HTML и CSS как контракт, JavaScript как язык браузера.
Курс по Rails для человека, не знающего Ruby, — это курс по копированию из
документации.

Стандарт унаследован от [OPERATION MOONLIGHT](https://github.com/gfazzz/moonlight-course)
и [KERNEL SHADOWS](https://github.com/gfazzz/kernel-shadows) 1.0 — он проверен
на 181 серии.

**Следующий шаг:** пилотная серия `s01e01` целиком. Она задаёт стандарт,
по ней сверяются остальные; генерировать сезон до неё — значит переписывать
его потом (проверено дважды).
