## Обстановка

Журнал берут из конторы. Текст записей пишут посты, имена ставят приёмщики,
ссылку на источник прикладывает тот, кто передал. Ни одно из этих слов не
написано нами.

До этой серии разницы не было: журнал приходил из разметки, а разметку писали
мы. Теперь в строку журнала попадает то, чего мы не набирали, — и попадает
ровно туда, где браузер читает разметку.

## Приказ

Развести разметку и данные так, чтобы автор данных не мог написать разметку.

## `telegraph.html`

### Образец строки

`<template id="entry-template">` с одной пустой `<li>` внутри. Места под
чужие данные помечены `data-part`:

| Метка | Что кладут |
|---|---|
| `text` | текст записи |
| `hand` | почерк — кто принял |
| `source` | ссылка на источник; лежит скрытой, у большинства записей её нет |

Содержимое `<template>` браузер разбирает, но не показывает и не исполняет:
образец — разметка, а не запись, и в журнал не считается.

### Строки журнала

Привести к той же форме, что у образца. Пока они разные, заполнять их придётся
двумя способами — а заполнять будет одна функция.

## `render.js`

### `safeHref(value, base)`

Адрес из чужих данных, годный для `href`, — или `null`.

| Что пришло | Что вернуть |
|---|---|
| `https://…`, `http://…`, `mailto:…`, `tel:…` | адрес |
| `#register`, `/entries/14`, `posts/14` | адрес: он никуда не уводит |
| `javascript:`, `data:`, `vbscript:`, всё прочее | `null` |
| пустое, пробелы, `null` | `null` |

Два требования, из которых всё остальное следует:

- **список разрешённого, а не запрещённого.** Перечислять запрещённое значит
  перечислять только то, что уже придумали;
- **адрес разбирают, а не сверяют по началу строки.** `«  JaVaScRiPt:alert(1)»`
  начинается не с `javascript:`.

### Сборка строки

| Что | Как |
|---|---|
| новая строка | клонировать образец из `<template>`, а не собирать разметку строкой |
| текст, почерк | текстом, и только текстом, целиком, как прислали |
| источник годен | поставить `href`, показать |
| источник не годен | **снять** `href`, спрятать |

Снять, а не спрятать: адрес, оставшийся в атрибуте, однажды покажут — из
отладки, из чужого стиля, из следующей правки.

## Критерии приёмки

**Образец**

- [ ] Образец строки лежит в разметке, в `<template>`, с местами под текст и
      почерк.
- [ ] Сам по себе читателю не показывается и записью не считается.
- [ ] Новая строка собрана из образца: правка образца доезжает до строки.

**Чужой текст**

- [ ] Запись с тегами внутри показана дословно, целиком, как прислали.
- [ ] Ни одного элемента из неё на странице не завелось.
- [ ] Чужое имя — так же: текстом.
- [ ] Сводка над журналом собрана текстом.
- [ ] Вторая отрисовка не удваивает строки и ничего не портит.

**Чужой адрес**

- [ ] `safeHref` пропускает обычные адреса и свои.
- [ ] Схема, которой нет в списке разрешённого, не проходит — в любом
      написании и с пробелами по краям.
- [ ] Относительный адрес и адрес с пробелами по краям проходят: адрес
      разбирают, а не сравнивают строки.
- [ ] Пустого адреса не бывает.
- [ ] Негодный источник не оставляет после себя атрибут — даже если он там
      был.
- [ ] Годный источник виден и ведёт куда сказано.
- [ ] У записи без источника пустой ссылки нет.

**Форма записи**

- [ ] `source` доезжает до состояния.
- [ ] Поле, о котором не договаривались, в состояние не попадает.
- [ ] Источник со страницы читается обратно.

**Прежние редакции**

- [ ] Журнал конторы заменяет разметочный.
- [ ] Мел ставится щелчком и переживает отрисовку.
- [ ] Отбор прячет, а не удаляет.

- [ ] `make test` → двадцать три зелёные проверки.

## Подводный камень

Первый: «почистить» чужой текст, вырезав из него теги. Это не защита, а порча
— пост написал то, что написал, — и обходится она в одну строку, которую
придумали двадцать лет назад. Чужой текст не чистят; его кладут туда, где
разметки не бывает.

Второй: спрятать негодную ссылку вместо того, чтобы снять адрес. Спрятанное
показывают.

Третий: `<template>` — не «невидимый `div`». Его содержимое лежит в
`content`, отдельном документе; `querySelector` по странице внутрь него не
заглядывает, и `cloneNode(true)` обязателен — иначе первая же запись унесёт
образец с собой.
