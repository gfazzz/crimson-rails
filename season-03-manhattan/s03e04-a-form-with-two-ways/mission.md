## Обстановка

Каждый третий бланк с постов приходит с ошибкой: не указан пост, текст в одно
слово. Дарнелл читает бланк до того, как отбить, и возвращает — это сутки. Не
читала бы — контора вернула бы через трое.

Оба чтения нужны, и по разным причинам: одно ловит быстро, другое — наверняка.

## Приказ

Довести `artifacts/telegraph.js` до четвёртой редакции. Разметка не меняется.

**Отправку формы не заменять.** Заменить её пока нечем: ходить в контору
журнал научится в `s03e07`. Отменяется ровно то, что отправлять нельзя.

## Что делает модуль

1. **Объявляет, что сообщает сам** — `compose.noValidate = true`. В разметке
   этого писать нельзя: там `novalidate` выключит проверку и без скрипта.
2. **Создаёт живую область** внутри формы подачи: пустую, спрятанную,
   `role="status"`. Заранее — потому что объявляется только то, что появилось
   в уже существующей области.
3. **На отправку:**
   - добавляет своё правило: текст короче пяти знаков (без учёта пробелов по
     краям) — не текст. Через `setCustomValidity` с объяснением по-русски;
   - если форма проходит проверку — **не мешает**: она уходит в контору;
   - если нет — отменяет отправку, показывает сообщение и ставит фокус в
     первое неверное поле.
4. **На ввод:** снимает своё правило и убирает сообщение. Висящее сообщение об
   ошибке, которой уже нет, хуже отсутствия сообщения.

Сообщение собирается из подписи поля и `validationMessage` — браузер уже
сформулировал его на языке читателя.

## Критерии приёмки

Половина проверок открывает журнал с **выключенным** JavaScript.

**Без скрипта**

- [ ] Пустая форма не уходит: `required` на месте, браузер не пускает сам.
- [ ] Заполненная форма уходит, страница переходит, запись появляется в
      конторе.
- [ ] Кнопка отбора видна.

**Со скриптом**

- [ ] У формы подачи появился `novalidate`; в разметке его нет.
- [ ] Внутри формы есть живая область (`role="status"` или `aria-live`), она
      пуста и спрятана.
- [ ] Пустая форма не уходит, сообщение видно и непусто, в контору ничего не
      уехало.
- [ ] Фокус после отказа стоит в первом неверном поле.
- [ ] Текст из двух знаков не уходит, и сообщение объясняет про пять знаков.
- [ ] Введённое после отказа не пропало.
- [ ] После исправления сообщение спрятано.
- [ ] Правильно заполненная форма уходит в контору.

**Прежние редакции**

- [ ] Кнопка отбора со скриптом спрятана, сводка собрана, отбор прячет чужие
      записи, нажатие ставит мел, отправка формы отбора отменяется.
- [ ] Страница не получила ни одной ошибки.

- [ ] `make test` → тринадцать зелёных проверок.

## Подводный камень

`preventDefault` первой строкой обработчика — самая частая и самая дорогая
ошибка этой серии. Форма перестаёт отправляться вообще; проверки на ошибку не
жалуются, потому что ошибки нет; замечает это пост, чья запись пропала.

Второй: живая область, вставленная вместе с текстом, не объявляется. Проверка
смотрит именно на это — область обязана существовать до того, как в ней
появится первое слово.

Третий: `setCustomValidity` — залипающий. Поставил один раз и не снял — поле
неверно навсегда, даже когда текст исправили.

## Выполнение

```bash
npm install                      # playwright, один раз на репозиторий
npx playwright install chromium  # сам браузер, один раз на машину

cp starter.html artifacts/telegraph.html
cp starter.js   artifacts/telegraph.js
cp starter.css  artifacts/telegraph.css
make test
```

Серия помечена `NEEDS_BROWSER`: в общий прогон `make test` она не входит,
запускается через `make test-visual SEASON=03`.

Проверить руками стоит так: открыть журнал, отключить JavaScript и нажать
«Передать» с пустой формой, потом с заполненной. Оба раза браузер обязан
повести себя разумно без единой строки твоего кода.

## После выполнения

Форма начнёт читать себя сама, не переставая при этом отправляться.

А Дарнелл достанет шпиль с бланками за восьмое. Их будет пять — ровно по числу
записей, у которых есть почерк. Бланка с 59-й улицы среди них не окажется.
Каждая отбитая запись начинается с бланка; нет бланка — никто не приносил;
никто не приносил — никто и не отбивал. А запись есть.
