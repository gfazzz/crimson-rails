## Чему ты научишься

- Отличать основание от улучшения и проверять это выключением скрипта.
- Подключать модуль ES и понимать, чем он отличается от обычного скрипта.
- Знать, что браузер умеет сам, — и не писать этого руками.
- Прятать, а не удалять; добавлять, а не отнимать.
- Приёму, который дороже синтаксиса: **скрипт улучшает то, что уже
  работает.** Если без него не работает ничего — это не улучшение, а
  единственная опора, и она однажды подведёт.

Подробнее — в [`theory.md`](theory.md).

## Теория: что на чём стоит

### Три слоя

```
разметка   что это такое и что с этим можно делать   работает всегда
стили      как это выглядит                          не работает — читаемо
скрипт     как это делается удобнее                  не работает — работает
```

Порядок не декоративный. Разметка доезжает первой и одна; стили могут не
доехать, и страница останется читаемой; скрипт может не доехать, и страница
останется работающей — если её так построили.

**Скрипт не доезжает чаще, чем кажется.** Не только «читатель отключил
JavaScript» (таких единицы), а: сеть оборвалась на середине файла, блокировщик
принял домен за чужой, корпоративный посредник вырезал модуль, устройство
старое и споткнулось о синтаксис, ошибка в одной строке остановила весь модуль.
Во всех этих случаях разметка уже пришла.

### Что браузер умеет без единой строки

```html
<form method="post" action="/entries">   отправка и переход
<input required minlength="3">           проверка и сообщение на языке читателя
<input type="date" min max>              календарь и границы
<details><summary>                       раскрывающийся блок
<dialog>                                 модальное окно с ловушкой фокуса
<a href="#register">                     переход внутри страницы
<input type="search"> в форме с get      поиск, который ложится в закладку
```

Каждая строка выше — это то, чего не нужно писать. Написанное руками будет
хуже: без клавиатуры, без голоса, без перевода сообщений, без работы в тот
день, когда модуль не доехал.

### Модуль — не то же, что скрипт

```html
<script src="telegraph.js"></script>                  обычный
<script type="module" src="telegraph.js"></script>    модуль
```

| | обычный | модуль |
|---|---|---|
| когда выполняется | сразу, останавливая разбор | после разбора, как `defer` |
| область видимости | общая на всю страницу | своя |
| режим | обычный | строгий, всегда |
| `import` | нет | есть |
| выполняется дважды при двух тегах | да | нет |

Модуль отложен **по умолчанию** — поэтому дерево уже существует, когда он
начинает работать, и `DOMContentLoaded` ждать незачем. Атрибут `async` эту
отложенность отменяет: с ним модуль выполнится, как только скачается, —
возможно, раньше дерева, которое он собирался улучшать.

### Голых имён не бывает

```js
import { register } from "./register.js";   ✔ путь с расширением
import { throttle } from "lodash";          ✘ браузер не знает, где это
```

Браузер не ищет пакеты в `node_modules`. Имя без пути он понимает только через
карту импортов — и Rails 8 даёт её как раз для этого (`importmap-rails`). Пока
карты нет, путь пишется целиком, с расширением. Заодно это значит, что файл,
который грузит браузер, и файл, который импортирует проверка, — один и тот же,
и между ними нет сборки, в которой что-нибудь потеряется.

### Прятать, а не удалять

```js
node.hidden = true;    ✔ вернётся, если понадобится
node.remove();         ✘ не вернётся
```

Кнопка «Показать» нужна тому, у кого скрипта нет. Со скриптом она лишняя — но
«лишняя» и «её не должно существовать» не одно и то же. Удалённый узел не
вернёшь; спрятанный вернёшь одной строкой.

То же правило наоборот: модуль **не отнимает** у разметки `action` и `method`.
Пока он работает, разницы не видно; в тот день, когда он не загрузится, форма
отправится в никуда.

### Где это в Rails

```erb
<%= form_with model: @entry do |form| %>
```

Rails печатает обычную форму с `action` и `method`: она работает и без Turbo.
Turbo Drive перехватывает отправку **поверх** работающей формы, а `turbo-frame`
без скрипта ведёт себя как обычная ссылка. Stimulus подключается к готовой
разметке через `data-controller` — то есть к тому, что уже есть на странице,
а не вместо него.

Вся эта конструкция держится на одном допущении: разметка осмысленна сама по
себе. Приложение, где она — набор пустых `<div>` для скрипта, теряет и Turbo,
и Stimulus вместе с ним.

## Проверка: ADA задаёт вопросы

```
[ADA · КАБЕЛЬ]
ТРИ ВОПРОСА. ПЛАЧУ ЗА СЛОВО.
```

**1.** ADA: «Форма без `action`. Что произойдёт, когда модуль не доедет?»

<details><summary>Ответ</summary>

Форма отправится на текущий адрес: страница перезагрузится, введённое
пропадёт, запись не уйдёт. Ошибки при этом не будет — будет тишина.

`action` и `method` — это не «на случай отключённого JavaScript». Это то,
куда и чем форма отправляется; перехват скриптом — надстройка над этим, а не
замена.
</details>

**2.** ADA: «`<a href="#" onclick="…">` вместо кнопки. Перечисли, что
сломалось.»

<details><summary>Ответ</summary>

Голосовой браузер объявит ссылку и пообещает переход, которого не будет.
Средний клик и «открыть в новой вкладке» откроют пустоту. Без скрипта не
случится ничего. Строгая политика безопасности не выполнит обработчик в
атрибуте. И пробел, которым нажимают кнопки, на ссылке не сработает.

Одна подмена — пять поломок. Кнопка называется `<button>`.
</details>

**3.** ADA: «Модуль спрятал кнопку `hidden` или удалил `remove()`. Разница?»

<details><summary>Ответ</summary>

Спрятанную можно вернуть, удалённую — нет. Разница становится важной ровно
тогда, когда что-то пошло не так: обработчик отвалился, запрос не прошёл,
режим переключился. Со спрятанной есть куда отступить.

Общее правило сезона: **улучшение обратимо.** Всё, что модуль сделал, он
должен уметь не делать.
</details>

## Разбор типичных ошибок

1. **Форма без `action` и `method`.** Без скрипта отправляется в никуда.
2. **Подача записи методом `get`.** Такой запрос повторяют перезагрузкой —
   и запись задваивается.
3. **Поле без `name`.** На сервер не уедет, и заметно это только там.
4. **Ссылка вместо кнопки.** Пять поломок сразу, ни одной заметной.
5. **Обработчик в атрибуте.** Выполняется вне модуля и запрещается строгой
   политикой безопасности.
6. **Встроенный скрипт.** То же самое, только длиннее.
7. **Пометка «скрипт доехал» прямо в разметке.** Врёт ровно в том случае,
   ради которого её ставили.
8. **`remove()` вместо `hidden`.** Обратной дороги нет.
9. **Модуль снимает `action` с формы.** Разницу видно в один-единственный
   день — и он же худший.
10. **Второй запуск модуля добавляет второе.** Страницу возвращают из кеша
    чаще, чем думают.

Я каждого узнаю по почерку: как держит паузу, как ставит точку. Все записи в
этом журнале приняты кем-то. У этой почерка нет.
