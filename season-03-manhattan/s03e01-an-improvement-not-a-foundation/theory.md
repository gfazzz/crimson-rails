# Теория — s03e01

## 1. Три слоя и порядок между ними

```
разметка   что это и что с этим можно делать   доезжает первой и одна
стили      как это выглядит                    не доехали — читаемо
скрипт     как это делается удобнее            не доехал — работает
```

Порядок задан не вкусом, а тем, как устроена доставка: браузер получает
разметку, начинает её разбирать и показывать, потом применяет стили, потом
выполняет модули. Каждый следующий слой может не случиться.

**Скрипт не доезжает чаще, чем принято думать.** Читатель, отключивший
JavaScript, — редкость; всё остальное — нет:

- сеть оборвалась на середине файла;
- блокировщик рекламы принял домен раздачи за чужой;
- корпоративный посредник вырезал модуль или переписал его;
- устройство старое и споткнулось о синтаксис, которого не знает;
- ошибка в одной строке остановила весь модуль целиком;
- вкладку восстановили из кеша в состоянии, которого модуль не ждал.

Во всех этих случаях разметка уже пришла и уже показана. Вопрос только в том,
можно ли ей пользоваться.

## 2. Что браузер умеет сам

```html
<form method="post" action="/entries">     отправка, переход, повтор
<input required minlength="3">             проверка и сообщение на языке читателя
<input type="date" min="1891-06-01">       календарь и границы
<input type="search"> + <form method=get>  поиск, ложащийся в закладку
<details><summary>                         раскрывающийся блок с клавиатурой
<dialog>                                   модальное окно и ловушка фокуса
<a href="#register">                       переход по документу и адрес в строке
<input type="file" accept>                 выбор файла
<video controls>                           плеер с клавиатурой и субтитрами
```

Всё перечисленное написанное руками получается хуже: без клавиатуры, без
голосового браузера, без перевода сообщений на язык читателя и без работы в
тот день, когда модуль не доехал.

Правило отбора: **сначала найди тег, потом пиши код.** Код нужен там, где тега
нет.

## 3. Модуль

```html
<script src="telegraph.js"></script>                обычный скрипт
<script type="module" src="telegraph.js"></script>  модуль
```

| | обычный | модуль |
|---|---|---|
| когда выполняется | немедленно, останавливая разбор | после разбора |
| область видимости | общая на страницу | своя |
| режим | обычный | строгий всегда |
| `import` / `export` | нет | есть |
| `await` на верхнем уровне | нет | есть |
| два одинаковых тега | выполнится дважды | выполнится один раз |
| `this` на верхнем уровне | `window` | `undefined` |

Модуль отложен по умолчанию — как `defer`. Значит, дерево уже построено, когда
модуль начинает работать: `DOMContentLoaded` ждать не нужно, а `document.write`
не работает и работать не будет.

Атрибут `async` эту отложенность отменяет: с ним модуль выполняется, как только
скачался. Для аналитики это годится; для модуля, который улучшает разметку, —
нет.

Строгий режим здесь бесплатный и полезный: необъявленная переменная становится
ошибкой, а не новым глобальным именем.

## 4. Пути и карта импортов

```js
import { register } from "./register.js";        ✔
import { register } from "/js/register.js";      ✔
import { throttle } from "lodash";               ✘ без карты импортов
```

Браузер не знает про `node_modules` и не достраивает расширения. Голое имя он
разрешает только через карту:

```html
<script type="importmap">
  { "imports": { "lodash": "https://cdn.example/lodash.js" } }
</script>
```

Rails 8 отдаёт эту карту сам (`importmap-rails`) — потому и обходится без
сборщика. В этом сезоне карты нет: пути пишутся целиком, и благодаря этому
файл, который грузит браузер, и файл, который импортирует проверка, —
буквально один и тот же.

## 5. Обратимость

```js
node.hidden = true;     ✔ вернётся одной строкой
node.remove();          ✘ не вернётся
form.removeAttribute("action");   ✘ отнял у разметки то, что в ней было
```

Улучшение обратимо: всё, что модуль сделал, он должен уметь не делать. Это не
из аккуратности, а из того же соображения, что и весь сезон: модуль может
отвалиться в середине — после того как уже что-то сделал.

Отсюда же и правило «прятать, а не удалять»: спрятанный узел вернуть можно,
удалённый придётся создавать заново — и тогда он потеряет всё, что на нём
висело.

## 6. Идемпотентность

Модуль обязан переживать повторное выполнение. Причина бытовая: браузер
возвращает страницу из кеша вперёд-назад вместе с деревом и выполняет модули
снова.

```js
// ✘ дописывает
document.body.append(notice);

// ✔ приводит к виду
let notice = document.querySelector("#notice");
if (!notice) {
  notice = document.createElement("p");
  notice.id = "notice";
  document.body.append(notice);
}
notice.textContent = text;
```

Первый вариант при втором выполнении даёт два уведомления. Второй — одно, и
так будет при любом числе выполнений. Это то же свойство, которое в сезоне 6
называется идемпотентностью и стоит там дороже: там повтор приходит из очереди.

## 7. Пометка «скрипт доехал»

```js
document.documentElement.dataset.script = "on";
```

```css
[data-script="on"] .only-without-script { display: none; }
```

Пометку ставит модуль, и в этом весь смысл: она появляется тогда и только
тогда, когда модуль выполнился. Написанная в разметке, она врёт в единственном
случае, ради которого затевалась.

Приём старый и когда-то назывался «класс `no-js`»: разметка объявляла
`class="no-js"`, а скрипт первым делом его снимал. Разница только в том, что с
`dataset` не нужно ничего снимать.

## 8. Где это в Rails

```erb
<%= form_with model: @entry do |form| %>
  <%= form.text_area :text, required: true %>
<% end %>

<div data-controller="register" data-register-url-value="/entries">
<turbo-frame id="entries" src="/entries">
```

- `form_with` печатает обычную форму с `action` и `method`. Turbo перехватывает
  отправку поверх неё; без Turbo форма работает сама;
- `turbo-frame` — пользовательский элемент (`s03e09`). Без скрипта браузер
  показывает его содержимое как обычный блок, а ссылки внутри ведут себя как
  ссылки;
- Stimulus подключается к готовой разметке через `data-controller` — то есть
  к тому, что уже есть, а не вместо него.

Вся конструкция держится на допущении, что разметка осмысленна сама по себе.
Приложение, где она — набор пустых блоков, которые заполнит скрипт, теряет и
Turbo, и Stimulus вместе с ним, и возвращается к тому, с чего этот сезон
начинается.
