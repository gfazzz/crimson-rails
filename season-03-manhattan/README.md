## Что даёт сезон

JavaScript в объёме, который делает Hotwire объяснимым, а не магическим.
Критерий отбора тот же, что в сезонах 1 и 2: **концепт входит, только если без
него Rails выглядит магией.**

Поэтому здесь есть дерево документа, события и делегирование, формы,
асинхронность, `fetch`, вставка чужой разметки, пользовательские элементы и
адрес как состояние. И нет ни одного фреймворка, ни сборщика, ни
транспилятора: **файл, который грузит браузер, и файл, который импортирует
проверка, — один и тот же.**

Главная мысль сезона объявлена в первой серии и проверяется в последней:
**скрипт улучшает то, что уже работает.** Журнал, у которого не доехал модуль,
остаётся журналом: форма отправляется, ссылки ведут, записи видны.

**Чем сезон кончается.** Реестр обновляется сам, переживает перезагрузку и
делится ссылкой. И выясняется, что одна запись в нём появляется не потому, что
её передали.

## Контракт проверки сезона

`SPEC.md` §4. Для этого сезона:

**Обязан проверять** — поведение модуля ES и реакцию дерева документа на
событие: делегирование работает на элементе, которого не было при загрузке;
отрисовка дважды подряд даёт одно дерево; отказ сервера доходит до читателя;
повторная отправка не заводит вторую запись; чужой текст остаётся текстом.
Для двух серий — **настоящий браузер**: страница без скрипта отправляет форму
и переходит, со скриптом — не переходит.

**Не засчитывается как проверка** — поиск подстроки в исходнике проходящего
курс; подставной `fetch`, проверяющий подставной `fetch`; «функция вызвалась»
вместо «в дереве появилось».

## Среда

Node 20 или новее и один пакет — `jsdom`. Он чистый JavaScript, без сборки.

```bash
cd season-03-manhattan
npm install --omit=optional     # jsdom
```

Прогон — встроенный `node --test`, внешнего раннера нет.

```bash
make test SEASON=03             # весь сезон, без браузера
make test SERIES=s03e02         # одна серия
```

Три вещи, которые стоит знать про эту среду:

- **модуль не пересобирается.** Браузер грузит `telegraph.js` как модуль,
  проверка импортирует тот же файл. Отсюда запрет на голые имена в `import`:
  `import { x } from "lodash"` браузер без карты импортов не поймёт;
- **сервер настоящий.** Серии про запросы ходят к серверу на `node:http`, а не
  к подставному `fetch`. Подставной `fetch` проверяет подставной `fetch`;
- **jsdom честно не умеет отправлять формы.** Поэтому главный вопрос сезона —
  работает ли страница без скрипта — задаётся браузеру, а не ему.

**Две серии требуют браузера** — `s03e04` (форма и настоящий переход) и
`s03e09` (свой элемент, фокус, живая область). Они помечены файлом
`NEEDS_BROWSER`, в основной прогон не входят и запускаются отдельно:

```bash
npm install                     # теперь и playwright
npx playwright install chromium
make test-visual SEASON=03
```

## Сквозной артефакт: `telegraph`

Журнал приёма диспетчерской Третьей авеню. Растёт от серии к серии:

```
telegraph/
├── telegraph.html      e01–e10 — журнал, работающий без скрипта
├── telegraph.css       дан готовым и не меняется: сезон не про стили
├── telegraph.js        e01–e10 — модуль, который его улучшает
├── state.js            e05 — состояние отдельно от отрисовки
└── office.js           e07 — разговор с конторой отдельно от того и другого
```

В сезоне 5 этот же журнал станет страницей Rails: модуль превратится в
контроллер Stimulus, а обновление без перезагрузки — в Turbo Stream. Ни одна
мысль сезона при этом не пропадёт — поменяется только, кто её выполняет.
