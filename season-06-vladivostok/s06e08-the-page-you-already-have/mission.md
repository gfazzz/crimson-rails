## Обстановка

Лист выплат казны за месяц Окулов получает по проводу каждое утро — сорок
минут аппарата. В девяти случаях из десяти лист тот же, что вчера.

## Приказ

У листа — версия и время последней правки. Тот, у кого лист уже есть и он
верен, получает «тот же лист» — 304, без тела, — и контора ради этого не
читает выплаты. Пользоваться своей копией, не спросив, читающему нельзя.

## Что уже есть

| Где | Что |
|---|---|
| `GET /payouts/1892-06` | лист выплат за месяц: страница (`show.html.erb`) и JSON (`show.json.jbuilder`) |
| `PayoutsController#show` | выборка выплат месяца — ленивая, в `@disbursements` |

## `app/controllers/payouts_controller.rb`

| Что | Как |
|---|---|
| `ETag` | версия листа: месяц, число выплат, последняя правка |
| `Last-Modified` | время последней правки; у пустого месяца — его начало |
| вопрос с верной версией или временем | 304, пустое тело, выплаты не читаются |
| лист изменился — добавили, убрали, поправили | 200, новая версия |
| `Cache-Control` | читающий спрашивает каждый раз |

## Критерии приёмки

**Версия**

- [ ] У листа есть `ETag` и `Last-Modified`; на листе — выплаты месяца.
- [ ] `Cache-Control` требует спросить перед каждым использованием копии.

**Лист у тебя уже есть**

- [ ] С верным `If-None-Match` — 304, пустое тело, строки выплат не читаются.
- [ ] С `If-Modified-Since` на время последней правки — 304.
- [ ] Выплата после этого времени — 200.
- [ ] JSON — 200 с выплатами; с верной версией — 304.
- [ ] Пустой месяц — 200 с версией; с ней — 304.

**Лист изменился**

- [ ] Новая выплата — 200, новая версия, три строки.
- [ ] Убранная выплата — 200.
- [ ] Поправленная выплата — 200 и новая сумма на листе.
- [ ] Майская версия для июньского листа — 200.

- [ ] `make test` → одиннадцать зелёных проверок; s06e01–s06e07 — зелёные.

## Подводный камень

Первый: без `fresh_when` проверка «версия» — зелёная. `ETag` и 304 даёт сам
Rails, по готовому телу; проверка, которая считает, что прочла контора, —
красная.

Второй: `fresh_when ..., public: true`. Удобно для прокси, но без срока
кеш вправе решить сам, что лист свежий.

Третий: `last_modified` пустого месяца. `maximum(:updated_at)` у пустой
выборки — `nil`, и `fresh_when` с `last_modified: nil` Last-Modified не
поставит.
