## Обстановка

Нагасаки иногда молчит: не лежит, а думает — или ответил, и ответ потерялся.
Мёллер ждёт две минуты и считает это обрывом. Свою телеграмму второй раз она
вслепую не подаёт: на бланке её номер отправления, и Нагасаки узнает повтор.
Справку по номеру линия даёт только о своих телеграммах; о чужих — «не
наша».

## Приказ

Клиент линии ждёт станцию не дольше предела, считает молчание обрывом, даёт
линии номер отправления на каждой подаче и умеет спросить справку о
телеграмме.

## `app/models/telegraph_line.rb`

| Что | Как |
|---|---|
| соединение со станцией | не дольше секунды |
| ответ станции | не дольше двух секунд |
| станция молчит дольше предела | `TelegraphLine::Down` |
| каждая подача | заголовок `Idempotency-Key` — номер отправления телеграммы (`telegram.key`) |
| `TelegraphLine.trace(number)` | `GET /messages/<номер>`: 200 — хеш ответа, 404 — `nil`, 5xx и молчание — `Down` |
| повторы | решает задача (s06e03), а не `Net::HTTP` |

Задача `DispatchJob` уже умеет повторять обрыв. Проверь, что с чужой линией
она разговаривает без открытой транзакции.

## Критерии приёмки

**Молчание**

- [ ] Линия молчит четыре секунды — работник освобождается раньше, чем через
      три с половиной; телеграмма ждёт повтора.
- [ ] Линия думает секунду — работник её дожидается.

**Потерянный ответ**

- [ ] Линия приняла и не ответила — повтор; линия передала телеграмму один
      раз, в книге — номер первой подачи.
- [ ] Все попытки одной телеграммы несут один и тот же номер отправления —
      номер телеграммы.
- [ ] Две телеграммы — два номера отправления.

**Пока линия думает**

- [ ] Контора записывает в книгу, пока работник ждёт линию, — быстрее чем за
      0,8 секунды.

**Справка**

- [ ] Справка о нашей телеграмме — её номер; о кабельной квитанции из
      Нагасаки — не пусто.
- [ ] Номер, которого линия не знает, — `nil`.
- [ ] Лежащая линия — `Down`; молчащая — `Down`, и не дольше предела.

- [ ] `make test` → девять зелёных проверок; s06e01–s06e04 — зелёные.

## Подводный камень

Первый: `Net::HTTP.post` из прошлых серий. У него нет места для пределов
ожидания и заголовков — понадобится `Net::HTTP.start` и объект запроса.

Второй: справка через `Net::HTTP.get_response` или `start` без
`max_retries: 0`. У молчащей линии она ждёт вдвое дольше — `Net::HTTP` сам
повторит `GET` — и вернёт ответ второго запроса.

Третий: ключ повтора из текста телеграммы. Две одинаковые телеграммы в разные
дни линия примет за одну.

     -d '{"to":"Нагасаки","body":"ПРОБА"}' http://127.0.0.1:4750/messages

Повтори `curl` с тем же ключом — номер тот же, линия второй раз не передала.

## После выполнения

Ни одного из шести иркутских номеров Нагасаки не передавал. Государственный
телеграф отвечает: квитанции приняты с Петербургской линии, та — с Берлина,
Берлин — с Лондона. Поданы в Лондоне, по коду частного отправителя.
