## Владивосток, казначейская часть, 3 августа, 09:00

По-здешнему — двадцать второе июля. Окулов кладёт на стол свою книгу выплат
за три месяца, рядом — выписку книги конторы.

— Сверьте, — говорит он. — Раз уж вы взялись. Моя книга — по квитанциям. Ваша
— по поставкам. Если они не сходятся, я хочу знать, на сколько.

Книгу казначейства тоже можно спросить по проводу: казначейская часть
отдаёт её конторе по месяцам. Спрашивать её надо, как всякую чужую книгу, —
с пределом ожидания и без веры в то, что она ответит с первого раза.

**11:00.** Ты гонишь через контору май — таким, каким он был: двенадцать
пароходов, квитанции кабелем и сушей, квитанции, присланные дважды, линия,
которая рвалась, теряла ответы и молчала; работник, умерший после выплаты;
два работника разом. Потом — сутки, чтобы всё, что должно повториться,
повторилось.

Каждая поставка оплачена один раз. Казначейство узнало о каждой выплате один
раз. Ничего не застряло. Копии не врут. Табло, открытое первого мая и ни разу
не перезагруженное, показывает то же, что книга. Сводок — по одной на день.

Остаётся сверка.

## Чему ты научишься

- Сверять свою книгу с чужой: взять чужую книгу по проводу, найти
  расхождение, записать его один раз.
- Ставить сверку расписанием за прошлый месяц.
- Проверять контору не серией, а месяцем, в котором случилось всё сразу.
- Приёму, который дороже синтаксиса: **приёмка проверяет свойства, которые
  переживают нагрузку, а не шаги, которые их строят.** «Каждая поставка
  оплачена ровно раз» верно или неверно после любого месяца — сколько бы
  серий ни понадобилось, чтобы это стало верным.

Подробнее — в [`theory.md`](theory.md).

## Теория: две книги

### Сверка

```ruby
rows = TreasuryBook.payments(month)          # чужая книга по проводу (s06e05)
rows.group_by { |row| row["delivery"] }.flat_map do |reference, paid|
  next [] unless paid.size > 1
  kept = paid.find { |row| row["receipt"] == ours } || paid.first
  (paid - [kept]).map { |row| { delivery_id: …, receipt: row["receipt"], … } }
end
Overpayment.upsert_all(overpaid, unique_by: %i[delivery_id receipt])
```

Три решения, и каждое — из сезона:

| Решение | Откуда |
|---|---|
| чужую книгу спрашивают с пределом, молчание — обрыв, повторяет задача | `s06e03`, `s06e05` |
| «своя» выплата — по той квитанции, по которой платила контора | `s06e04`: ключ — поставка |
| переплата ложится одна на пару «поставка + квитанция» | `s06e04`, `s06e10`: эффект с ключом |

Сверку ставит расписание — первого числа за прошлый месяц, от времени
постановки (`s06e10`). Её ставят и руками, и дважды: ключ переплаты делает
вторую сверку той же, что первая.

### Приёмка: месяц, а не список

Приёмка сезона 5 обходила все адреса окна. Приёмка сезона 6 проживает месяц:

| Что случается | Чем кончиться обязано |
|---|---|
| квитанция кабелем и сушей, квитанция дважды | одна выплата на поставку |
| обрыв, потерянный ответ, молчание линии | одна телеграмма казначейству на выплату — и на линии тоже одна |
| работник умер после выплаты, два работника разом | ни одной двойной выплаты, ничего в упавших |
| сутки после | ни одной застрявшей телеграммы, пустая очередь |
| правки книг весь месяц | копия сводки равна пересчёту; лист выплат знает свою версию |
| всё, что изменилось | пришло на табло по кабелю |
| два календаря, квитанции в семь утра | сводки по одной на день, повторы видны, выплата — в своём владивостокском дне |
| книга казначейства | переплаты — ровно иркутские квитанции |

Случайность в приёмке — с зерном (`Random.new(1892)`): тот же май даёт тот же
итог, и прогон повторяем (SPEC §6).

## Проверка: ADA задаёт вопросы

```
[ADA · КАБЕЛЬ НАГАСАКИ]
ТРИ ВОПРОСА.
```

**1.** ADA: «Почему „своя“ выплата казны — по квитанции конторы, а не первая
по книге казначейства? Первая же раньше».

<details><summary>Ответ</summary>

Раньше в книге — не значит раньше в жизни. Иркутская квитанция на NGS-0513
легла в книгу казначейства раньше кабельной — телеграф государственный,
бланк старого стиля, конторщик вписал её в другой день. Если «своя» — первая
по книге, переплатой назовут настоящую, кабельную, и сверка укажет не на тот
документ.

Контора платила по поставке и знает, по какой квитанции. Эта и есть своя.
</details>

**2.** ADA: «Приёмка гоняет весь месяц в каждой проверке. Не проще ли один
раз прогнать месяц и проверить всё одной проверкой?»

<details><summary>Ответ</summary>

Проще и быстрее. Но одна проверка, упав, скажет «что-то не так» — и
остановится на первом утверждении. Восемь проверок скажут, что именно: выплаты
верны, а табло — нет. Цена — время прогона. Здесь она приемлема: месяц
проживается за секунды.
</details>

**3.** ADA: «В приёмке нет ни одной проверки на код серий. Как она ловит
ошибку, скажем, в `s06e04`?»

<details><summary>Ответ</summary>

Через свойство, которое серия строила. Сломай ключ выплаты — и после мая
найдётся поставка, оплаченная дважды. Убери ключ повтора у линии — и потерянный
ответ передаст телеграмму казначейству второй раз. Приёмке не нужно знать, где
ключ; ей нужно, чтобы свойство держалось.

Это и есть контракт сезона: проверяется эффект, а не то, как он сделан.
</details>

## Задание: две книги

Клиент книги казначейства, сверка с ключом переплаты, расписание сверки. И
приёмка сезона — ей ничего писать не надо: она проверяет то, что написано за


Ожидаемо — семнадцать зелёных проверок: девять сверки и восемь приёмки.
Приёмка идёт около минуты: в каждой проверке — месяц.

## Разбор типичных ошибок

1. **«Своя» — первая по книге казначейства.** Переплатой названа настоящая
   квитанция.
2. **Переплата — все выплаты казны.** Каждая поставка «переплачена».
3. **`insert_all` вместо `upsert_all`.** Вторая сверка молча пропускает
   записанное — и поправленная казначейством сумма остаётся старой.
4. **Без ключа переплаты.** Вторая сверка удваивает переплаты.
5. **Без повтора.** Закрытое казначейство — сверка в упавших.
6. **Без пределов ожидания.** Молчащее казначейство держит работника.
7. **Сверка за текущий месяц.** Первого числа — сверка месяца, который только
   начался.
8. **Приёмка красная, серии зелёные.** Серии проверяли свойства по одному;
   месяц проверяет их вместе. Ищи, какое свойство не пережило соседа.

Контора пережила май со всеми его сбоями: каждая поставка оплачена ровно один

Окулов долго смотрит на итог.

Гектор Лэнг, Владивосток; Кувабара Хэйхатиро, Нагасаки — отец того

— Я поставлял то, что заказано, и брал то, что платили. — Лэнг складывает

Казна платила мне за каждую квитанцию — и за нагасакскую, и за лондонскую.
Разницу я каждый месяц отправлял туда, куда велел третий пайщик.
