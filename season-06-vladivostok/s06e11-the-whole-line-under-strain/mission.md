## Обстановка

Книга выплат казначейства — по квитанциям, книга конторы — по поставкам.
Окулов хочет знать, на сколько они расходятся. Книгу казначейства можно
спросить по проводу, по месяцам.

## Приказ

Сверка с книгой казначейства: всё, что казна выплатила за поставку сверх
одного раза, — в книгу переплат, по одному разу. Сверка — по расписанию,
первого числа за прошлый месяц. И приёмка сезона: май целиком, под
нагрузкой.

## `app/jobs/reconcile_job.rb`

| Что | Как |
|---|---|
| `ReconcileJob.perform_later(month)` | сверка за месяц |
| без месяца | прошлый месяц — от времени постановки |
| выплат казны за поставку больше одной | все, кроме «своей», — переплаты |
| «своя» выплата | по квитанции, по которой платила контора; если контора не платила — первая по книге казначейства |
| сверка второй раз | те же переплаты, ничего в упавших |
| казначейство закрыто или молчит | повтор с паузой |

## Критерии приёмки

**Сверка**

- [ ] Переплаты — ровно выплаты сверх одной на поставку; поставка с одной
      выплатой — не переплата.
- [ ] «Своя» — по квитанции конторы, даже если в книге казначейства она
      вторая.
- [ ] Страница переплат показывает итог.
- [ ] Сверка дважды — те же две переплаты, ничего в упавших.
- [ ] Казначейство поправило сумму — после второй сверки переплата с новой
      суммой.
- [ ] Вторую переплату с той же парой база не принимает.
- [ ] Казначейство закрыто — повтор; открылось — сверка сделана.
- [ ] Казначейство молчит — работник свободен раньше, чем через 3,5 секунды.
- [ ] Сверка по расписанию — 1 июня в 9:00 по Владивостоку, и сводит май.

**Приёмка сезона** (май 1892 года целиком: двенадцать пароходов, квитанции
кабелем и сушей, квитанции дважды, обрывы, потерянный ответ, молчание линии,
смерть работника, два работника разом, сутки после)

- [ ] Каждая поставка оплачена ровно один раз.
- [ ] Казначейство узнало о каждой выплате ровно один раз — и линия передала
      каждую телеграмму о выплате один раз.
- [ ] В упавших пусто, застрявших телеграмм нет, очередь пуста.
- [ ] Копия сводки равна пересчёту; поправленный лист выплат — новая версия.
- [ ] Табло, открытое первого мая, после всего, что пришло по кабелю,
      показывает «оплачено» у каждой поставки.
- [ ] Тридцать одна сводка за май; повторов — шесть; выплачено — сколько в
      книге, и каждая выплата — в сводке своего владивостокского дня.
- [ ] Переплаты — ровно иркутские квитанции; итог 14 400 рублей.
- [ ] Тот же май с тем же зерном — тот же итог.

- [ ] `make test` → семнадцать зелёных проверок.
- [ ] `make solution` в корне сезона → одиннадцать серий, ни одной красной.

## Подводный камень

Первый: `paid.first` как «своя». Проверки сверки, где своя и первая
совпадают, пройдут; на NGS-0513 — нет.

Второй: приёмка красная там, где серия зелёная. Серия проверяла свойство
одно; месяц — все вместе. Сломанное свойство почти всегда — соседа: табло,
которое не слушает, сводка, которая считает по Гринвичу, повтор, который
идёт без ключа.

Третий: приёмка идёт около минуты. В каждой её проверке — месяц, и линия в
нём честно молчит свои секунды.

## После выполнения

Переплат за май, июнь и июль — девятнадцать, все по иркутским квитанциям:
45 600 рублей. Государственный телеграф раскрывает казначейству код
отправителя: Расчётная палата, Сеймур-стрит, кабинет секретаря. В
учредительном договоре дома 1869 года третий пайщик — младший клерк Палаты
Эдмунд Прайор, с 1883 года её секретарь. Разницу дом каждый месяц отправлял в
Константинополь. В октябре Прайор едет туда сам — Восточным экспрессом.
