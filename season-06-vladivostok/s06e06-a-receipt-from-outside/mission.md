## Обстановка

С этой недели Большое Северное шлёт квитанции о приёмке конторе дома само,
по проводу. Каждая присылка подписана общим секретом — от текста и от
времени. Не услышав ответа, станция пришлёт квитанцию ещё раз.

## Приказ

Адрес, на который линия шлёт квитанции. Принимать только подписанное линией
и свежее; отвечать сразу; работу оставлять работнику.

## Что уже есть

| Где | Что |
|---|---|
| `Rails.configuration.x.line_secret` | общий секрет с линией (`config/application.rb`) |
| `Acceptance.receive!` | принять квитанцию: записать, найти повтор, оставить записку на выплату (s06e04) |

## Что шлёт линия

```http
POST /receipts
Content-Type: application/json
X-Line-Timestamp: -2449400400
X-Line-Signature: 6f1c…

{"number":"НГС-7712","route":"cable","delivery":"NGS-0512","signed_by":"Кувабара","accepted_on":"1892-06-16"}
```

`X-Line-Timestamp` — секунды Unix, когда подписано (в 1892 году — со знаком
минус). `X-Line-Signature` — HMAC-SHA256 секрета над строкой
`«время».«тело»`, шестнадцатеричный.

## `config/routes.rb`

| Маршрут | Куда |
|---|---|
| `POST /receipts` | приём квитанции |

И ничего сверх.

## `app/controllers/receipts_controller.rb`

| Что пришло | Ответ |
|---|---|
| нет подписи, чужая подпись, тело не то, время старше пяти минут | **401**, JSON; в книге ничего |
| подписано, поставка есть, квитанция проходит | **202**, JSON; квитанция в книге; выплата — работнику |
| та же квитанция второй раз | **202**; вторая строка не заводится |
| поставки нет; тело не JSON; путь неизвестен | **422**, JSON; в книге ничего |

Защита форм (CSRF) для этого адреса не нужна: у линии нет нашей формы.

## Критерии приёмки

**Подлинность**

- [ ] Подписанная квитанция — 202, JSON, строка в книге.
- [ ] Без подписи — 401, книга пуста.
- [ ] Чужой секрет — 401.
- [ ] Тело поправлено после подписи — 401.
- [ ] Подписано час назад — 401; две минуты назад — 202.
- [ ] С включённой защитой форм линия получает 202.

**Работа — не в запросе**

- [ ] После 202 выплаты нет; после работника — есть.

**Повтор**

- [ ] Одна квитанция, присланная дважды, — 202 оба раза, одна строка, одна
      выплата.

**Непринятое**

- [ ] Поставки нет — 422, JSON, книга пуста.
- [ ] Не JSON — 422.
- [ ] Неизвестный путь — 422, книга пуста.

**Табличка**

- [ ] `POST /receipts` — и ни одного маршрута сверх.

- [ ] `make test` → двенадцать зелёных проверок; s06e01–s06e05 — зелёные.

## Подводный камень

Первый: образец времени `/\A\d+\z/`. В 1892 году секунды Unix отрицательны,
и честная квитанция не пройдёт.

Второй: `params` вместо `request.raw_post`. Rails разобрал JSON в параметры,
и собранное обратно тело — не то, что подписано.

Третий: `ApplicationController` защищает формы, а в проверках защита
выключена. Без `skip_forgery_protection` всё зелёное — кроме проверки,
которая включает защиту, как на проде.

## Выполнение

```bash
cp -R starter/. ../app/
# дописать то, что помечено TODO
make test
```

Прислать квитанцию руками:

```bash
cd ../app && bin/rails runner '
  body = { number: "НГС-1", route: "cable", delivery: Delivery.first.reference,
           signed_by: "Кувабара", accepted_on: Date.current }.to_json
  stamp = Time.current.to_i.to_s
  puts "curl -i -H \"Content-Type: application/json\" -H \"X-Line-Timestamp: #{stamp}\" " \
       "-H \"X-Line-Signature: #{OpenSSL::HMAC.hexdigest("SHA256", Rails.configuration.x.line_secret, "#{stamp}.#{body}")}\" " \
       "-d #{body.inspect} http://localhost:3000/receipts"'
```
