## Обстановка

Доску у причала Сабуров переписывает по записке из конторы: посыльный в
восемь и в два, между ними — ничего. Нужно табло, на которое контора пишет
сама, как только в книге что-то изменилось, — и только то, что легло.

## Приказ

Табло причала слушает поток. Поставка — новая или изменённая, в том числе
квитанцией и выплатой, — отправляет по кабелю свою строку табло. Рисует
строку работник, отправляет — после коммита. Кабель в разработке соединяет
работника и сервер.

## Что уже есть

| Где | Что |
|---|---|
| `GET /board` | табло: строка на поставку, `tbody#pier` |
| `app/views/board/_delivery.html.erb` | строка табло, `id` — `dom_id(delivery)`, состояние — `delivery.board_state` |
| `Delivery::PIER` | имя потока табло |
| `touch: true` у квитанции и выплаты | поставка меняется от них (s06e07) |

## `app/views/board/show.html.erb`

Табло слушает поток `Delivery::PIER`.

## `app/models/delivery.rb`

| Что случилось | Что уходит по кабелю в `Delivery::PIER` |
|---|---|
| новая поставка | её строка — в конец `tbody#pier` |
| поставку поправили, тронули | её строка заменяет свою |
| правка откатилась | ничего |

Строку рисует работник, а не тот, кто правит.

## `config/cable.yml`

В разработке — кабель, который передаёт новости между процессами. На проде —
тоже.

## Критерии приёмки

**Табло**

- [ ] Табло показывает, где каждая поставка.
- [ ] Табло слушает поток `Turbo::StreamsChannel`, подписанное имя проходит
      проверку сервера.

**Новость приходит сама**

- [ ] Квитанция — по кабелю строка «квитанция», цель на табло есть.
- [ ] Выплата — строка «оплачено».
- [ ] Пароход у причала — строка «у причала»; чужая строка не меняется.
- [ ] Новая поставка — новая строка; строк три, не четыре и не одна.

**Кто рисует и когда**

- [ ] При правке по кабелю ничего не уходит; после работника — уходит.
- [ ] Откатившаяся правка не отправляет ничего.

**Кабель**

- [ ] В разработке и на проде кабель — не `async`.

- [ ] `make test` → десять зелёных проверок; s06e01–s06e08 — зелёные.

## Подводный камень

Первый: `broadcasts_to` без аргументов. Он возьмёт шаблон
`deliveries/_delivery` — строку книги поставок из s06e07, а не табло.

Второй: `after_update_commit` без `after_create_commit`. Новый пароход не
появится на табло, пока его не поправят.

Третий: `async` в разработке. Проверки кабеля идут на адаптере `test` и
зелёные; табло в браузере молчит.

```bash
cd ../app && bin/rails server      # http://localhost:3000/board
cd ../app && bin/jobs              # работник: он и рисует строки табло
cd ../app && bin/rails runner 'Delivery.first.update!(arrived_on: Date.current)'
```

Строка на табло меняется, страница не перезагружается.
