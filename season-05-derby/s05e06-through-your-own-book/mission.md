## Обстановка

На бумаге касса находит бланк по номеру в книге своей дороги и ставит штамп.
Что вшито в книгу, касса не проверяет: раз лист в книге `MID`, он `MID`.
Окну нужна своя книга для каждой дороги — и такая, в которую чужой лист не
вшить.

## Приказ

Книга перевозок каждой дороги и страница перевозки — по вложенному адресу.
Бланк ищется в книге своей дороги; через чужую книгу он не открывается.

## `config/routes.rb`

| Маршрут | Куда |
|---|---|
| `GET /companies/:company_code/consignments` | книга перевозок дороги |
| `GET /companies/:company_code/consignments/:reference` | одна перевозка в этой книге |

Вложены в `resources :companies`; параметр перевозки — `:reference`.

## `app/models/consignment.rb`

`to_param` — номер бланка.

## `app/controllers/consignments_controller.rb`

| Действие | Что |
|---|---|
| `index` | перевозки этой дороги, по дате отправки |
| `show` | перевозка **среди перевозок этой дороги**; нет — 404; участки — вместе с дорогами |

Дорога — из адреса, в одном закрытом методе; нет дороги — 404.

## `app/views/`

| Шаблон | Что |
|---|---|
| `consignments/index.html.erb` | таблица с подписью: номер бланка (заголовок строки, ссылка), дата, груз, плата; пустая книга — фраза |
| `consignments/show.html.erb` | отправитель ссылкой, дата, груз, плата, вес; участки таблицей с подписью «Участки перевозки …» |
| `legs/_leg.html.erb` | строка участка: номер, дорога ссылкой, роль словом, мили |
| `companies/show.html.erb` | путь в книгу перевозок |

## `app/helpers/legs_helper.rb`

`leg_role(leg)` — «принял», «вёз», «сдал».

## Критерии приёмки

**Маршруты**

- [ ] Книга и перевозка в ней ведут куда нужно; адрес несёт код дороги и
      номер бланка.
- [ ] Адрес перевозки — `/companies/MID/consignments/B-0992`.
- [ ] Во вложенном адресе код держится тем же образцом.

**Книга**

- [ ] В книге `MID` — только бланки `MID`, все.
- [ ] По дате отправки.
- [ ] Пустая книга — 200.
- [ ] Книга несуществующей дороги — 404.
- [ ] Со страницы дороги — путь в её книгу.

**Бланк через свою книгу**

- [ ] Бланк открывается через книгу своей дороги.
- [ ] Бланк `MDL` через книгу `MID` — **404**.
- [ ] Несуществующий номер в настоящей книге — 404.

**Участки**

- [ ] По порядку, с дорогами-ссылками и ролями словом.
- [ ] Страница спрашивает дороги одинаковое число раз при двух участках и
      при шести.

- [ ] `make test` → тринадцать зелёных проверок; s05e01–e05 — тоже.

## Подводный камень

Первый: `Consignment.find_by!(reference: …)`. Адрес будет выглядеть
вложенным, и все проверки, которые открывают свой бланк через свою книгу,
пройдут. Не пройдёт одна — та, что открывает чужой.

Второй: чужой бланк — перенаправлением к хозяину. Удобно, и сообщает то, о
чём не спрашивали.

Третий: шаблон участка, который спрашивает `leg.company` без `includes`.
На трёх участках не видно.

## После выполнения

Пилбим открывает бланк `D-41207` через книгу `MID` — 404; через книгу `MDL` —
бланк там. В бумажной книге `MID` за девяностый год между листами `MID` вшито
по листу `MDL` в месяц, и на каждом — его штамп «получено». Листы приходят из
Лондона вместе с расчётом.
