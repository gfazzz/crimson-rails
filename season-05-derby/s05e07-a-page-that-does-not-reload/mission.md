## Обстановка

Эшворт пишет ответ секретариату, пока ходит по окну за нужными страницами.
Листок в её руке переживает любой переход; черновика в окне нет, а был бы —
пропадал бы на каждом шаге. И ещё одно: после «назад» окно иногда снова
говорит «Бланк внесён» — о бланке, внесённом давно.

Turbo Drive в окне включён с первого дня. Это серия о том, что он делает и
что ему нужно сказать.

## Приказ

Черновик телеграммы в макете, переживающий переходы и формы. Разовые
сообщения — не в кеш.

## `app/views/layouts/application.html.erb`

| Что | Как |
|---|---|
| черновик телеграммы | в шапке: поле с подписью «Черновик телеграммы»; переносится со страницы на страницу как есть |
| сообщения `notice` и `alert` | не попадают в снимок страницы, который Turbo кладёт в кеш |

Это вся работа с кодом. Остальное в серии — увидеть в браузере то, что
сезон до сих пор проверял по кодам ответа.

## Критерии приёмки

Все проверки — в Chrome без окна; перед действием на окне ставится метка.

**Переходы**

- [ ] Ссылка меняет страницу, а не окно: метка на месте, адрес сменился.
- [ ] «Назад» возвращает без перезагрузки.
- [ ] Заголовок окна следует за страницей.

**Формы**

- [ ] Непринятый бланк показывает причины на месте, без перезагрузки.
- [ ] Принятый ведёт на страницу дороги и говорит, что внесён.
- [ ] После «назад» старое «Бланк внесён» не возвращается.

**Черновик**

- [ ] Переживает переход по ссылке.
- [ ] Переживает отправку формы.

**Снятие с реестра**

- [ ] Сначала вопрос; «нет» — дорога остаётся.
- [ ] «Да» — дорога снята, окно не перезагружалось.
- [ ] Отказ — страница дороги с причиной, на месте.

- [ ] `make test` → одиннадцать зелёных проверок в браузере.

## Подводный камень

Первый: `data-turbo-permanent` без `id`. Turbo не знает, какой элемент новой
страницы — этот же, и ничего не переносит.

Второй: черновик в шаблоне одной страницы. На остальных его нет — переносить
нечего.

Третий: «старое сообщение после назад — выключим Turbo». Сообщение пропадёт
вместе со всем, ради чего Turbo стоит.

## Выполнение

```bash
cp -R starter/. ../app/
# дописать то, что помечено TODO
make test          # в этой серии — с браузером
```

Нужен Chrome или Chromium. Драйвер под него Selenium найдёт сам; если в
`PATH` лежит `chromedriver` другой версии — убери его из `PATH`. Путь к
нестандартному браузеру — в переменной `CRIMSON_CHROME`.

Посмотреть глазами:

```bash
cd ../app && bin/rails server
# открой страницу, набери черновик, походи по ссылкам
```
