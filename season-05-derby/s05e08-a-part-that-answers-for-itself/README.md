## Чему ты научишься

- Выносить кусок страницы во фрейм со своим адресом: `turbo_frame_tag`.
- Подгружать фрейм лениво: `src:` и `loading: :lazy`.
- Открывать правку на месте куска страницы — и возвращать туда результат.
- Держать обещание фрейма: на запрос фрейма — фрейм с тем же id.
- Приёму, который дороже синтаксиса: **у куска страницы, который отвечает за
  себя, свой адрес — и по этому адресу он обязан открываться и без Turbo.**
  Фрейм, который живёт только внутри страницы, — вклейка без номера листа.

Подробнее — в [`theory.md`](theory.md).

## Теория: вклейка

### Фрейм

```erb
<%= turbo_frame_tag dom_id(@company, :card) do %>
  <p><%= @company.name %></p>
  <p><%= link_to "Править", edit_company_path(@company) %></p>
<% end %>
```

Это элемент `<turbo-frame id="card_company_7">`. Ссылка или форма внутри него
по умолчанию ведут **фрейм, а не страницу**:

1. Turbo запрашивает адрес ссылки с заголовком `Turbo-Frame: card_company_7`.
2. В ответе ищет `<turbo-frame id="card_company_7">`.
3. Ставит его содержимое на место старого. Остальная страница не двигается.

Значит, страница правки обязана содержать тот же фрейм:

```erb
<%# companies/edit.html.erb %>
<%= turbo_frame_tag dom_id(@company, :card) do %>
  <%= form_with model: @company do |form| %> … <% end %>
<% end %>
```

Открытая из карточки, правка встаёт на место карточки. Открытая сама по себе
— это обычная страница. Одна страница, два способа её увидеть.

После правки контроллер отвечает, как всегда, 303 на страницу дороги; Turbo
идёт за перенаправлением **с тем же заголовком** и берёт из страницы дороги
новую карточку. Отказ — 422 и форма во фрейме: Turbo возьмёт фрейм из ответа.

### Ленивый фрейм

```erb
<%= turbo_frame_tag dom_id(@company, :settlements),
                    src: company_settlements_path(@company), loading: :lazy do %>
  <p><%= link_to "Расчёты с дорогой MID", company_settlements_path(@company),
                 data: { turbo_frame: "_top" } %></p>
<% end %>
```

Страница дороги больше не считает расчётов. На её месте — фрейм с адресом
листа: Turbo запросит его, когда фрейм окажется на экране. До того — внутри
ссылка на тот же лист: без Turbo по ней откроется полный лист.

Лист расчётов — обычная страница со своим маршрутом, с макетом и `h1`, и
таблица на ней обёрнута в фрейм **с тем же id**.

### Обещание фрейма

Главная ошибка с фреймами — ссылка внутри фрейма, которая ведёт туда, где
этого фрейма нет. Turbo откроет её во фрейме, не найдёт фрейма в ответе и
напишет на его месте «Content missing».

| Ссылка во фрейме ведёт | Что сделать |
|---|---|
| на страницу, где тот же фрейм есть | ничего: так и задумано |
| на страницу без этого фрейма | `data: { turbo_frame: "_top" }` — вести всю страницу |
| все ссылки фрейма — наружу | `target: "_top"` у самого фрейма |

Проверка серии обходит каждую ссылку каждого фрейма и требует одного из двух.

## Проверка: ADA задаёт вопросы

```
[ADA · ЧАСТНАЯ ЛИНИЯ]
ТРИ ВОПРОСА.
```

**1.** ADA: «Зачем листу расчётов свой маршрут, если он всё равно показывается
внутри страницы дороги?»

<details><summary>Ответ</summary>

Потому что фрейм подгружается по адресу, и адрес обязан отвечать. Лист со
своим маршрутом — это страница, которую можно открыть ссылкой, отправить,
распечатать, открыть без Turbo. Фрейм без своего адреса пришлось бы
отрисовывать внутри страницы дороги — и она снова считала бы двести
шестьдесят восемь месяцев, прежде чем показать название.
</details>

**2.** ADA: «Правка ответила 303 на страницу дороги. Как Turbo понял, что
менять нужно только карточку?»

<details><summary>Ответ</summary>

Запрос формы ушёл из фрейма с заголовком `Turbo-Frame`. Перенаправление Turbo
выполнил с тем же заголовком и в ответе — странице дороги целиком — нашёл
фрейм с тем же id. Контроллер об этом не знал и не должен: он ответил ровно
как в s05e05.

Поэтому страница дороги обязана содержать карточку-фрейм: иначе после правки
будет «Content missing».
</details>

**3.** ADA: «Почему ссылка "Расчёты с дорогой MID" внутри ленивого фрейма
помечена `_top`?»

<details><summary>Ответ</summary>

Потому что без Turbo фрейм не подгрузится, и эта ссылка — единственный путь к
листу. Щёлкнутая с Turbo, но до подгрузки, она по умолчанию повела бы фрейм —
и это было бы верно. Но лист — самостоятельная страница, и открыть его
целиком — честнее, чем полагаться на совпадение id. `_top` говорит об этом
прямо.
</details>

## Разбор типичных ошибок

1. **Лист без фрейма с тем же id.** «Content missing» на странице дороги.
2. **Разные id на двух страницах.** То же самое, только незаметнее.
3. **Лист только фреймом, без макета.** Открытый ссылкой, он — обрывок.
4. **«Править» вне карточки.** Правка уходит на всю страницу.
5. **Ссылка во фрейме на страницу без фрейма.** «Content missing» после
   щелчка.
6. **Фрейм, который считает страница.** Ленивости нет: страница ждёт лист.
