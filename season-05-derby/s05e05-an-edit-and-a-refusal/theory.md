# Теория — s05e05

## 1. Семь действий, три из них — сегодня

| Действие | Глагол и адрес | Что обещает | Исходы |
|---|---|---|---|
| `edit` | `GET /companies/MID/edit` | форму с тем, что есть | 200 |
| `update` | `PATCH /companies/MID` | правку | 303 / 422 |
| `destroy` | `DELETE /companies/MID` | снятие | 303 / 422 |

`PUT` на тот же адрес `resources` тоже ведёт в `update`: исторически `PUT`
значил «замени целиком», `PATCH` — «поправь часть». Rails шлёт `PATCH`.

## 2. Идемпотентность глаголов

| Глагол | Меняет ли | Повторить — то же самое? |
|---|---|---|
| `GET`, `HEAD` | нет | да |
| `PUT`, `DELETE` | да | да: удалённое второй раз не удалится |
| `PATCH` | да | не обязательно |
| `POST` | да | нет |

Отсюда два правила. `GET` не меняет ничего — никогда: его повторяют браузеры,
посредники, программы, которые заранее открывают ссылки. И всё, что меняет,
идёт формой, а не ссылкой.

## 3. `button_to`

```erb
<%= button_to "Убрать из реестра", company_path(@company), method: :delete %>
```

Отрисовывается в:

```html
<form class="button_to" method="post" action="/companies/MID">
  <input type="hidden" name="_method" value="delete">
  <button type="submit">Убрать из реестра</button>
</form>
```

Кнопка внутри формы — это то, что умеет HTML без единой строки скрипта.
Вариант со ссылкой, `link_to … data: { turbo_method: :delete }`, работает
только со скриптом, и без него превращается в `GET`.

`data: { turbo_confirm: "…" }` у формы — Turbo спросит подтверждения до
отправки. Без Turbo вопроса не будет; поэтому подтверждение — удобство, а не
защита.

## 4. Перенаправление после `DELETE`

| Код | `POST` | `PATCH`, `DELETE` |
|---|---|---|
| 301, 302 | браузер переходит `GET`-ом (исторически) | браузер вправе повторить тот же глагол |
| 303 | переходит `GET`-ом | переходит `GET`-ом |
| 307, 308 | повторяет `POST` | повторяет глагол |

`button_to` шлёт `POST` со скрытым `_method`, так что сам по себе 302 его не
сломает. Но `DELETE` приходит и настоящим — от программы, от `fetch`, от
ссылки с `data-turbo-method`. 303 одинаково честен для всех.

## 5. Отказ: какой код

| Ситуация | Код |
|---|---|
| записи нет | 404 |
| запрос кривой: нет нужного параметра | 400 |
| запрос понят, но запись не проходит проверку | 422 |
| запрос понят, но состояние не позволяет (есть расчёты) | 422 или 409 |
| окно сломалось | 500 |

409 Conflict — «запрос спорит с текущим состоянием ресурса»: тоже честный
ответ на «у дороги есть расчёты». Курс берёт 422 по одной причине: Turbo
отрисовывает ответ на форму с любым кодом 4xx, а у 422 в Rails есть готовое
имя (`:unprocessable_content`) и привычный смысл «форма не принята».

Главное — не 303. Перенаправление говорит «сделано».

## 6. `flash` и `flash.now`

| | Когда прочтут | Для чего |
|---|---|---|
| `flash[:notice] = …` (или `notice:` у `redirect_to`) | на следующем запросе | перед перенаправлением |
| `flash.now[:alert] = …` | в этом же ответе | когда отвечаешь страницей сразу |

`flash` без `now` перед `render` — классическая ошибка: сообщение покажется
на этой странице **и** на следующей, куда человек уйдёт.

## 7. `destroy` против `delete`

| Метод | Колбэки и `dependent:` | Проверки модели |
|---|---|---|
| `record.destroy` | да | `restrict_with_error` отказывает |
| `record.delete` | нет | нет — сразу `DELETE` в базе |
| `Model.delete_all` | нет | нет |

`delete` быстрее, и он идёт мимо всего, что модель знает про связи. Отказать
тогда может только внешний ключ базы (s04e05) — исключением, страницей 500.

## 8. Чего эта серия не закрывает

- **мягкое удаление** (отметка вместо удаления, как погашенные строки архива
  в `s04e10`) — упомянуто и не нужно окну;
- **права: кто вправе снимать дорогу с реестра** — сезон 7;
- **история правок** — сезон 7, аудит.
