## Чему ты научишься

- Писать правку: `edit` и `update`, форма, которая сама шлёт `PATCH`.
- Писать удаление кнопкой, а не ссылкой: `button_to ... method: :delete`.
- Отвечать на удаление 303 — и знать, почему не 302.
- Доводить отказ модели до человека: 422 и страница записи с причиной.
- Приёму, который дороже синтаксиса: **отказ — не перенаправление.**
  Перенаправление говорит «сделано, смотри там». Если ничего не сделано,
  честный ответ — остаться на месте и сказать почему.

Подробнее — в [`theory.md`](theory.md).

## Теория: телеграмма от секретариата

### Правка

```ruby
def update
  if @company.update(company_params)
    redirect_to company_path(@company), status: :see_other, notice: "…"
  else
    render :edit, status: :unprocessable_content
  end
end
```

Два исхода и два кода — как у бланка в прошлой серии. Форма правки —
`form_with model: @company`: запись существует, поэтому адрес — `/companies/MID`,
глагол — `PATCH` (скрытым полем `_method`).

Код дороги в форме не правится и в списке разрешённого его нет. Код — адрес
дороги (s05e02): ключ, который меняют, ломает все ссылки, журналы и закладки
сразу.

### Удаление — форма, а не ссылка

```erb
<%= button_to "Убрать из реестра", company_path(@company), method: :delete,
              form: { data: { turbo_confirm: "Убрать дорогу MID из реестра?" } } %>
```

`button_to` делает маленькую форму: кнопка, скрытое `_method=delete`, адрес
записи. Ссылкой удалять нельзя: ссылка — это `GET`, а `GET` обещает ничего не
менять. Его повторяют, запрашивают заранее, присылают по почте — и удаление
по ссылке однажды случится само.

### 303, а не 302

```ruby
redirect_to companies_path, status: :see_other
```

`redirect_to` по умолчанию отвечает 302. Для `POST` браузеры исторически
меняют глагол на `GET`; для `PATCH` и `DELETE` — нет: на `DELETE`,
перенаправленный кодом 302, браузер вправе повторить `DELETE` по новому
адресу. 303 говорит однозначно: «дальше — `GET`».

### Отказ

`has_many :settlements, dependent: :restrict_with_error` (s04e05): `destroy`
не удаляет дорогу с расчётами, а возвращает `false` и кладёт причину в
`errors`.

```ruby
def destroy
  if @company.destroy
    redirect_to companies_path, status: :see_other, notice: "…"
  else
    flash.now[:alert] = @company.errors.full_messages.to_sentence
    set_settlements
    render :show, status: :unprocessable_content
  end
end
```

| Ответ на отказ | Что говорит | Правда? |
|---|---|---|
| 303 на страницу дороги с `alert` | «сделано, смотри там» | нет: ничего не сделано |
| 200 и страница дороги | «вот страница» | Turbo не покажет ответ на форму с 200 |
| **422** и страница дороги с причиной | «понято, но нельзя, и вот почему» | да |

`flash.now` — для этого же ответа, без перенаправления. Адрес в браузере не
меняется: человек остаётся на странице дороги и читает, почему она осталась.

## Проверка: ADA задаёт вопросы

```
[ADA · ЧАСТНАЯ ЛИНИЯ]
ТРИ ВОПРОСА.
```

**1.** ADA: «Удаление ответило 302, реестр открылся, дороги нет. Что не так?»

<details><summary>Ответ</summary>

Сегодня — почти ничего: кнопка шлёт `POST` со скрытым `_method`, и на 302
после `POST` браузер переходит уже `GET`-ом.

Но `DELETE` приходит не только от кнопки. Ссылка с `data-turbo-method`,
программа по проводу, `fetch` из сезона 3 шлют настоящий `DELETE` — и на 302
повторяют его по адресу из `Location`: `DELETE /companies`. Сейчас такого
маршрута нет — придёт 404 после удачного удаления. В день, когда маршрут
появится, удалится не то.

303 закрывает вопрос для всех, кто пришёл: дальше — только `GET`.
</details>

**2.** ADA: «Отказ удалить. Почему не перенаправить на страницу дороги с
сообщением? Человек увидит то же самое».

<details><summary>Ответ</summary>

Человек — да. Браузер и Turbo — нет: они получат «сделано, смотри там» и
поверят. История браузера запомнит переход, которого не было; всё, что
смотрит на коды, — журнал, монитор, следующий сезон с фоновыми задачами, —
запишет удачу.

422 говорит правду: запрос понят, выполнить его нельзя, и вот страница с
причиной.
</details>

**3.** ADA: «Модель проверит образец кода. Почему не дать его править?»

<details><summary>Ответ</summary>

Потому что проверка образца отвечает на вопрос «похоже ли это на код», а
вопрос другой: что станет со всем, что на старый код ссылается. Адрес дороги
лежит в ссылках, в журналах поста, в маршрутной книге Эшворт. Сменить код —
значит сломать их все сразу и молча.
</details>

## Разбор типичных ошибок

1. **Удаление ссылкой.** `GET`, который меняет реестр.
2. **302 после `DELETE`.** Удачное удаление, за которым следует второй `DELETE`.
3. **Отказ — перенаправлением.** «Сделано, смотри там» о том, чего не было.
4. **Отказ без причины.** Дорога не убрана, и никто не знает почему.
5. **`delete` вместо `destroy`.** Мимо запретов модели — расчёты остаются без
   дороги.
6. **Код в списке разрешённого.** Адрес дороги правится формой.
7. **Правка, отвергнутая с 200.** Turbo её не покажет.
