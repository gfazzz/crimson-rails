## Что даёт сезон

Интерфейс поверх `ledger` в объёме, после которого Rails перестаёт выглядеть
как генератор страниц и становится тем, чем он является: программой, которая
отвечает на запросы по HTTP — и отвечает честно.

Критерий отбора тот же, что во всех сезонах: **концепт входит, только если без
него Rails выглядит магией.** Поэтому здесь есть маршруты и контроллеры,
формы и сильные параметры, коды ответа, Turbo Drive, Frames и Streams — и
Stimulus ровно в одной серии: там, где Turbo мало.

Главная мысль сезона: **код ответа — часть ответа.** Turbo держится на кодах:
форма, вернувшая 200 вместо 422, молча не покажет ошибок; удаление,
ответившее 302 вместо 303, повторит `DELETE`. Страница, которая «открылась»,
ещё ничего не доказала.

**Чем сезон кончается.** Ты даёшь телеграфу конторы ответ, который он поймёт,
и прослеживаешь один маршрут — подтверждения по `MDL` — от Ломбард-стрит до
штампа в книге кассы. Маршрут заявлен в одну сторону и ведёт в другую.

## Контракт проверки сезона

`SPEC.md` §4. Для этого сезона:

**Обязан проверять** — код ответа, форму ответа и работу Turbo: маршрут ведёт
куда заявлено, 404 там, где нечего показать, неудачная форма — 422, удачная —
303, фрейм получает свой фрейм, поток попадает в то, что есть на странице.

**Не засчитывается как проверка** — наличие тега в шаблоне; «страница
отрендерилась»; поиск подстроки в коде контроллера.

## Среда

Ruby 3.3 или новее, Rails 8, SQLite. Установка — в
[`docs/GETTING_STARTED.md`](../docs/GETTING_STARTED.md).

```bash
cd season-05-derby/app
bundle install
bin/rails db:prepare
```

Прогон — обычный minitest:

```bash
make test SEASON=05             # весь сезон без браузера
make test SERIES=s05e01         # одна серия
make test-visual                # серии с настоящим браузером
```

Что стоит знать про эту среду:

- **приложение стартует с конца сезона 4.** В `app/` уже лежат миграции,
  модели и схема реестра; сезон добавляет к нему окно — маршруты,
  контроллеры, шаблоны. `starter/` и `solution/` — патч-наборы, как в
  сезоне 4;
- **запросы идут в процессе, без сервера.** Проверка поднимает приложение и
  шлёт запросы через стойку Rack — ровно так, как их видит Rails. Turbo — это
  протокол поверх HTTP, и у него есть серверная половина: заголовок
  `Turbo-Frame`, тип `text/vnd.turbo-stream.html`, коды 303 и 422. Всё это
  видно без браузера;
- **две серии — с настоящим браузером.** То, что страница **не
  перезагрузилась**, видно только в браузере: `s05e07` про Turbo Drive и
  `s05e10` про Stimulus. Им нужен Chrome; драйвер под него Selenium найдёт
  сам. Основной прогон без браузера остаётся зелёным.

## Сквозной артефакт: `signal_box`

Окно конторы в Дерби поверх реестра Палаты. Растёт от серии к серии:

```
app/
├── config/routes.rb        e01–e11 — табличка на раме: что окно обещает
├── app/controllers/        e01–e11 — одно действие, одно решение
├── app/views/              e03–e11 — страницы, фреймы, потоки
└── app/javascript/         e10    — один контроллер Stimulus, и только там
```

В сезоне 6 поверх этого окна появятся фоновые задачи, кеш и каналы: то, что
сегодня приходит в ответ на форму, начнёт приходить само.

## Как проходить серию

```bash
cd season-05-derby/s05e01-a-route-is-a-promise
cp -R starter/. ../app/          # патч-набор ложится в приложение
# написать то, что помечено TODO
make test
```

Эталон — на копии приложения, вашу работу не трогает:

```bash
make solution
```
