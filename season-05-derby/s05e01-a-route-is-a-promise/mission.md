## Обстановка

Каждую строку реестра контора в Дерби выписывает из Лондона письмом, ответ
приходит через три дня. Реестр теперь на машине, и машина стоит на другом
конце частной линии. Нужно окно: адрес, по которому контора смотрит в реестр
сама.

Первое, что конторе нужно, — список дорог и страница одной дороги.

## Приказ

Объявить маршруты, написать контроллер и два шаблона. Объявить ровно то, что
окно умеет, и ничего сверх.

## `config/routes.rb`

| Маршрут | Куда |
|---|---|
| `GET /companies` | список дорог |
| `GET /companies/:id` | одна дорога |
| `GET /` | тот же список |

Через `resources` — он даёт и маршруты, и их имена (`companies_path`,
`company_path`). Из семи маршрутов `resources` нужны два.

## `app/controllers/companies_controller.rb`

| Действие | Что делает |
|---|---|
| `index` | все дороги, по коду |
| `show` | одна дорога по номеру из адреса; если её нет — **404** |

404 здесь получается без единой строки сверху. Подумай, какой из двух способов
найти запись даёт его сам.

## `app/views/companies/`

| Шаблон | Что на странице |
|---|---|
| `index.html.erb` | у каждой дороги — код ссылкой на её страницу и название; для пустого реестра — фраза, что дорог нет |
| `show.html.erb` | код главным заголовком, название, дата вступления в реестр (если есть), путь обратно в реестр |

Адреса ссылок — от помощников маршрутов, не строкой.

## Критерии приёмки

**Таблица маршрутов**

- [ ] `GET /companies` ведёт в `companies#index`.
- [ ] `GET /companies/:id` ведёт в `companies#show`.
- [ ] Корень ведёт в реестр.
- [ ] У каждого объявленного маршрута есть действие, которое на него ответит.
- [ ] У маршрутов есть имена: `companies_path`, `company_path`.
- [ ] Адрес, которого нет в таблице, даёт 404.

**Список**

- [ ] Ответ — страница: 200, `text/html`.
- [ ] Пустой реестр — 200, а не ошибка.
- [ ] На списке все дороги, у каждой — ссылка на её страницу.
- [ ] Дороги стоят по коду.
- [ ] Ссылка «`MID`» ведёт на страницу `MID`, а не другой дороги.

**Одна дорога**

- [ ] Страница — про ту дорогу, о которой спросили.
- [ ] Отсутствующая дорога — 404: не пустая страница и не перенаправление.
- [ ] Со страницы дороги есть путь обратно в реестр.

- [ ] `make test` → четырнадцать зелёных проверок.

## Подводный камень

Первый: `resources :companies` без `only:`. Все проверки ответов будут
зелёными — запрос на `/companies/new` всё равно получит 404, потому что
действия нет. Но табличка на раме обещает семь маршрутов, а рычагов под ними
два.

Второй: `find_by` и страница, которая «не падает». Отсутствующая дорога
получит 200 и пустоту — ответ, которому поверят все, кто спросил.

Третий: адрес ссылки строкой, `"/companies/#{company.id}"`. Сегодня он верен.
В следующей серии дорогу начнут звать кодом, и строка разойдётся с таблицей
молча.

## Выполнение

```bash
cp -R starter/. ../app/
# дописать то, что помечено TODO
cd ../app && bin/rails routes -c companies && cd -
make test
```

`bin/rails routes -c companies` должен показать две строки и корень. Семь —
значит, `only:` забыт.

Посмотреть глазами:

```bash
cd ../app && bin/rails server
# http://localhost:3000/
```

## После выполнения

Фэрбенк садится перед аппаратом и сам читает список. На пятой строке его
палец останавливается: `MDL`. В книгах конторы в Дерби — кодах всех дорог,
станций и касс, с которыми Мидленд считается, — таких трёх букв нет.
