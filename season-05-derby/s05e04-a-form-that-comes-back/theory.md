# Теория — s05e04

## 1. Что отправляет форма

Браузер отправляет форму так:

| Что | Откуда |
|---|---|
| адрес | атрибут `action` |
| глагол | атрибут `method`: только `GET` или `POST` |
| поля | все `input`, `select`, `textarea` с `name`, кроме отключённых и неотмеченных |
| тело | `name=значение&name=значение`, тип `application/x-www-form-urlencoded` |

HTML не умеет `PATCH` и `DELETE`. Rails обходит это скрытым полем
`_method=patch`: запрос приходит `POST`-ом, а стойка `Rack::MethodOverride`
превращает его в `PATCH` до маршрутов.

Имена со скобками, `consignment[reference]`, Rails разбирает во вложенный
хеш: `params[:consignment][:reference]`.

## 2. `form_with`

```erb
<%= form_with model: @consignment do |form| %>
```

| Запись | Адрес | Глагол |
|---|---|---|
| новая | `polymorphic_path(Consignment)` — `/consignments` | `POST` |
| сохранённая | `polymorphic_path(record)` — `/…/:id` | `PATCH` (через `_method`) |

Можно и без модели: `form_with url: …, method: …`, и тогда поля без скобок.

`form.label :reference` берёт подпись из
`activerecord.attributes.consignment.reference` в локали. Если перевода нет —
из имени столбца: «Reference».

В Rails 8 `form_with` по умолчанию отправляется через Turbo. Это не меняет
ни адреса, ни глагола — меняет то, как ответ ложится на страницу (`s05e07`).

## 3. Сильные параметры

```ruby
params.expect(consignment: %i[company_id reference description sent_on pence weight_lb])
```

| Запрос | Что вернёт `expect` |
|---|---|
| бланк с разрешёнными полями | эти поля |
| бланк с лишними полями | только разрешённые; лишние молча выброшены |
| бланка нет, или вместо хеша строка | `ParameterMissing` — 400 |

`expect` появился в Rails 8 и заменяет `require(...).permit(...)`: старый
вариант на запросе `consignment=строка` падал с 500, новый — отвечает 400.

Вложенные поля и массивы разрешают явно:

```ruby
params.expect(consignment: [:reference, legs: [[:position, :miles]]])
```

Зачем всё это, если форма и так шлёт только свои поля: запрос составляет не
форма. Его составляет тот, кто его шлёт, — и поле `settled=1` дописывается в
одну строку.

## 4. Коды ответа на форму

| Код | Когда | Что сделает Turbo |
|---|---|---|
| 303 See Other | принято | перейдёт по `Location` запросом GET |
| 302 Found | принято, по старинке | для `POST` — то же, что 303; для `PATCH` и `DELETE` — может повторить глагол |
| 422 Unprocessable Content | не принято | отрисует ответ вместо страницы |
| 200 OK | «вот страница» | ошибка: ответ на форму обязан быть перенаправлением или отказом |
| 500 | окно сломалось | отрисует страницу ошибки |

Отсюда правило сезона: **после формы — 303, при отказе — 422.** Для `POST`
разница между 302 и 303 почти не видна; для `DELETE` в следующей серии она
станет повторным удалением.

## 5. Post/Redirect/Get

Страница, показанная в ответ на `POST`, остаётся ответом на `POST`. Браузер
это помнит: «обновить» предложит отправить форму повторно, «назад» тоже.
Перенаправление после приёма разрывает связь: на экране — результат запроса
`GET`, и его можно обновлять сколько угодно.

## 6. `flash`

```ruby
redirect_to company_path(company), notice: "Бланк внесён."
```

`flash` — значение, которое живёт ровно до следующего запроса: положили
перед перенаправлением, прочли на странице, куда перенаправили. Хранится в
сессии, то есть в подписанной куке.

`flash.now[:alert] = …` — для того же запроса, без перенаправления. Им не
заменяют форму с причинами: причины — у полей, а не в строке сверху.

## 7. Отказ индекса

| Кто отказал | Когда | Чем |
|---|---|---|
| валидация | до записи, если успела увидеть | `save` вернул `false` |
| уникальный индекс | при записи, если валидация не успела | `ActiveRecord::RecordNotUnique` |
| внешний ключ | при записи | `ActiveRecord::InvalidForeignKey` |
| `NOT NULL` | при записи | `ActiveRecord::NotNullViolation` |
| `CHECK` | при записи | `ActiveRecord::StatementInvalid` — общий класс; причина в сообщении |

Ловят ровно то исключение, которое ожидают, и превращают в ту же форму, что
дала бы валидация. `rescue => e` не годится: он превратит в «бланк не
внесён» и сломанную базу.
