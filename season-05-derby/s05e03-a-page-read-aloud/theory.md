# Теория — s05e03

## 1. Из чего собирается ответ

Действие контроллера кончилось; Rails отрисовывает ответ в три слоя:

```
макет          app/views/layouts/application.html.erb
  └─ шаблон    app/views/companies/show.html.erb
       └─ частичные   app/views/settlements/_settlement.html.erb × N
```

Макет выбирается по имени контроллера (`layouts/companies`, если есть), иначе
`application`. Отключить — `render layout: false`; это понадобится в `s05e08`,
где Turbo сам попросит ответ без макета.

## 2. `yield` и `content_for`

```erb
<%# в шаблоне %>
<% content_for :title, @company.code %>

<%# в макете %>
<title><%= [content_for(:title), "Окно реестра"].compact.join(" · ") %></title>
<main><%= yield %></main>
```

`yield` без имени — сам шаблон. `content_for :имя` — кусок, который шаблон
кладёт, а макет забирает. Шаблон отрисовывается **раньше** макета, поэтому
макет видит всё, что шаблон положил.

## 3. Частичные шаблоны

Имя начинается с подчёркивания; зовут без него:

```erb
<%= render "companies/company", company: @company %>   <%# один, явно %>
<%= render @company %>                                  <%# один, по модели %>
<%= render @companies %>                                <%# коллекция %>
```

Для коллекции Rails берёт имя частичного шаблона у модели
(`Company#to_partial_path` → `companies/company`), отрисовывает его по разу на
запись и кладёт запись в переменную с тем же именем. Пустая коллекция даёт
`nil`, поэтому бывает удобно:

```erb
<%= render(@settlements) || tag.p("Расчётов не было.") %>
```

Частичный шаблон — единица повторного использования, а не сокращение. Строка
дороги в сезоне отрисовывается в списке, в ответе фрейму (`s05e08`) и в потоке
(`s05e09`); три копии разойдутся, один шаблон — нет.

## 4. Помощники

Модули в `app/helpers/` подмешаны во все шаблоны. Туда идёт то, что:

- считается из данных для показа (деньги, состояние словом);
- нужно больше чем одному шаблону;
- в модели было бы чужим: модели всё равно, как сумма читается вслух.

Rails даёт свои: `link_to`, `number_to_currency`, `time_tag`, `pluralize`.
`number_to_currency` для фунтов, шиллингов и пенсов не годится: он знает
только десятичные деньги.

## 5. Фунты, шиллинги и пенсы

| Единица | Пенсов |
|---|---|
| пенни, `d` | 1 |
| шиллинг, `s` | 12 |
| фунт, `£` | 240 |

Британия перешла на десятичные деньги в 1971 году. До того `divmod` —
единственный честный способ:

```ruby
shillings, pence = total.divmod(12)
pounds, shillings = shillings.divmod(20)
```

Хранятся деньги по-прежнему целыми пенсами (`s04e02`): переводят только для
показа.

## 6. Разметка — контракт, и Rails её не делает

Rails отдаёт то, что написано в шаблоне; семантику он не добавляет. Всё, что
сезон 2 требовал от полосы Брэдшоу, требуется и здесь:

| Элемент | Что говорит |
|---|---|
| `lang` у `<html>` | язык, а с ним произношение и переносы |
| `<header>`, `<nav>`, `<main>` | ориентиры: по ним прыгают с клавиатуры |
| один `<h1>` | о чём страница |
| `<caption>` | о чём таблица |
| `<th scope="col">` / `scope="row"` | к чему относится клетка |
| `aria-label` у `<nav>` | какая это навигация, если их несколько |

Машины, читающие вслух, — VoiceOver, NVDA, JAWS — озвучивают клетку вместе с
её заголовками. Без заголовков остаются числа.

## 7. Экранирование

`<%= %>` превращает `<`, `>`, `&`, `"` и `'` в сущности. Отключить можно:

| Способ | Что делает |
|---|---|
| `raw(text)` | вставить как есть |
| `text.html_safe` | пометить «уже безопасно» — и вставить как есть |
| `<%== text %>` | то же, что `raw` |
| `sanitize(text)` | оставить разрешённые теги, остальное вырезать |

`html_safe` не делает текст безопасным — он **обещает**, что текст уже
безопасен. Обещание даёт тот, кто пишет, а не тот, кто проверил.

Помощники Rails (`link_to`, `content_tag`) экранируют аргументы сами, поэтому
`link_to company.name, …` безопасен.
