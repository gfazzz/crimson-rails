## Теория: лист, который читают

### Макет

`app/views/layouts/application.html.erb` — рамка, в которую вставляется каждая
страница. Шаблон действия попадает туда, где стоит `yield`:

```erb
<html lang="ru">
  <head><title><%= [content_for(:title), "Окно реестра"].compact.join(" · ") %></title></head>
  <body>
    <header><nav><%= link_to "Реестр дорог", companies_path %></nav></header>
    <main><%= yield %></main>
  </body>
</html>
```

`content_for :title` в шаблоне кладёт кусок, который макет забирает в
`<head>`. Путь в реестр — в макете, а не в каждом шаблоне: он общий для всех
страниц, и решение о нём одно.

### Частичный шаблон и коллекция

```erb
<ul>
  <%= render @companies %>
</ul>
```

`render` с коллекцией записей ищет частичный шаблон по имени модели —
`companies/_company.html.erb` — и отрисовывает его по разу на запись; внутри
шаблона запись зовётся `company`. Для расчётов — `settlements/_settlement`.

Частичный шаблон — не для краткости. Строка дороги понадобится ещё в трёх
местах сезона: в списке, в ответе фрейма, в потоке, который дописывает её на
страницу. Одна строка — один шаблон.

### Помощник

```ruby
module ApplicationHelper
  def money(pence)
    shillings, pence = pence.divmod(12)
    pounds, shillings = shillings.divmod(20)
    "£#{pounds} #{shillings}s #{pence}d"
  end
end
```

Деньги хранятся пенсами (s04e02) и читаются фунтами, шиллингами и пенсами.
Считать это в шаблоне — значит считать в каждом шаблоне; помощник — одно место.

Все три части — всегда, даже нулевые. «£801» и «£801 0s 0d» — одна сумма, но
вслух во втором случае слышно, что шиллингов и пенсов нет, а не что их забыли.

### Разметка — контракт

Всё, что сезон 2 проверял разбором страницы, остаётся в силе, когда страницу
отдаёт Rails:

| Что | Зачем |
|---|---|
| `<html lang="ru">` | машина, читающая вслух, выбирает произношение |
| один `<main>` | по нему пропускают шапку и слышат содержание |
| один `<h1>` | о чём страница |
| `<caption>` | о чём таблица — до первой клетки |
| `<th scope="col">` | что в столбце |
| `<th scope="row">` | о чём строка: «1891-09, сумма, £801 0s 0d» |

### Чужой текст остаётся текстом

`<%= @company.name %>` экранирует всё, что похоже на разметку: `<b>` приходит
в браузер как `&lt;b&gt;` и читается как текст. `raw` и `html_safe` отключают
экранирование — и название дороги, внесённое из архива шестьдесят девятого
года, становится частью страницы. Это s03e08, только на стороне сервера.

## Проверка: ADA задаёт вопросы

```
[ADA · ЧАСТНАЯ ЛИНИЯ]
ТРИ ВОПРОСА.
```

**1.** ADA: «Месяц и так стоит в первой клетке. Зачем ему `<th scope="row">`?»

<details><summary>Ответ</summary>

Затем, что «первая клетка» — это то, что видно глазами. Машина, читающая
вслух, и человек, который идёт по таблице с клавиатуры, слышат клетку вместе
с её заголовками: столбца и строки. Без заголовка строки клетка «£801 0s 0d»
звучит как «сумма, £801 0s 0d» — и за какой месяц, не сказано.

Ровно то, что случилось с Гиббсом.
</details>

**2.** ADA: «Почему путь в реестр — в макете, а не в шаблоне каждой страницы?»

<details><summary>Ответ</summary>

Потому что это одно решение: «с любой страницы окна можно вернуться в реестр».
Написанное в каждом шаблоне, оно однажды окажется не в каждом — в том, который
добавят через месяц. Та же мысль, что с образцом кода в прошлой серии.
</details>

**3.** ADA: «Название дороги — из нашего же реестра. Почему нельзя `raw`?»

<details><summary>Ответ</summary>

Потому что «наш реестр» заполняют люди, переносы и архивы. Сезон 4 перенёс в
него листы с шестьдесят девятого года как есть. Экранирование по умолчанию
существует ровно для того, чтобы не решать в каждом шаблоне, чей это текст.
</details>

## Разбор типичных ошибок

1. **Нет `lang`.** Русская страница читается английским произношением.
2. **Шапка в каждом шаблоне.** Одна страница окажется без неё.
3. **Второй `<h1>` в макете.** Каждая страница начинает говорить о двух вещах.
4. **Таблица без `<caption>` и без `scope`.** Клетки без смысла.
5. **Деньги пенсами или без нулевых частей.** «£801» не говорит, что шиллингов
   нет.
6. **В фунте сто пенсов.** До 1971 года — двести сорок.
7. **Состояние именем `enum`.** `pending` вслух не читается.
8. **`raw` для «своего» текста.** Своего текста в реестре нет.
9. **Пустая таблица.** «Таблица, ноль строк» — шум, а не ответ.
