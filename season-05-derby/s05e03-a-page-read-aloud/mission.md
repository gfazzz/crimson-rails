## Обстановка

Счётная контора сверяет расчёты вслух: один читает с листа, второй ведёт по
книге. Страница дороги пока — три числа и слово `pending`: какой месяц, не
сказано, а `pending` вслух не читается.

## Приказ

Собрать страницу так, чтобы её можно было прочесть вслух: макет, частичные
шаблоны, расчёты таблицей, деньги фунтами, шиллингами и пенсами.

## Критерии приёмки

**Документ**

- [ ] У каждой страницы объявлен русский язык.
- [ ] Один `<h1>`, одна главная часть, заголовок — внутри неё.
- [ ] Заголовок окна на странице дороги называет дорогу.
- [ ] С каждой страницы из навигации можно попасть в реестр.
- [ ] Дороги в реестре — пункты списка.

**Таблица расчётов**

- [ ] Таблица с подписью.
- [ ] У каждого столбца — заголовок столбца; клеток в строке столько, сколько
      столбцов.
- [ ] Каждая строка названа своим месяцем.
- [ ] Месяцы по порядку.

**Деньги и слова**

- [ ] Одиннадцать сумм, от пенса до восьмисот фунтов, переводятся обратно в
      пенсы без потерь; шиллингов меньше двадцати, пенсов меньше двенадцати.
- [ ] Состояние — словом.

**Чужой текст и пустота**

- [ ] Название дороги с разметкой остаётся текстом.
- [ ] Дорога без расчётов — страница без таблицы.

- [ ] `make test` → тринадцать зелёных проверок; s05e01 и s05e02 — тоже.

## Подводный камень

Первый: считать деньги в шаблоне. Строка «£… s … d» понадобится в трёх местах
сезона; три копии разойдутся на первом же шиллинге.

Второй: опустить нулевые части. «£801» — та же сумма, но вслух не слышно, что
шиллингов нет.

Третий: `raw` для названия дороги, потому что оно «своё». Реестр заполняют
люди и архивы.
