## Обстановка

Печатающий аппарат телеграфного зала умеет сам спрашивать реестр — если
реестр ответит ему так, как он читает: полями по именам, числами. Касса хочет
лист расчётов файлом, чтобы положить рядом со своей книгой. Человеку
по-прежнему нужна страница. В 16:40 откроется линия на Лондон.

## Приказ

Один лист расчётов — три вида ответа. Реестр — JSON для аппарата. Чего окно не
умеет — 406; отказ — в формате вопроса. И приёмка сезона.

## `app/controllers/settlements_controller.rb`

| Спросили | Ответ |
|---|---|
| страницу | как было |
| JSON (`.json` или `Accept: application/json`) | `index.json.jbuilder` |
| CSV (`.csv`) | файл: `text/csv`, `attachment`, имя называет дорогу; столбцы — месяц, пенсы, чтение, состояние |
| другое | 406 |

## `app/views/settlements/index.json.jbuilder`

```json
{ "company": "MID",
  "settlements": [ { "period": "1891-08", "pence": 190565, "reading": "£794 0s 5d", "state": "paid" } ] }
```

Пенсы — целым числом. Имена полей — ровно эти.

## `app/controllers/companies_controller.rb` и `companies/index.json.jbuilder`

Реестр — JSON: у каждой дороги `code`, `name`, `url`, `settlements_url`; адреса
полные, со схемой и хостом.

## `app/controllers/application_controller.rb`

Нет записи, а спросили JSON — JSON с кодом 404 и полем `error`. Человеку —
страница 404, как было.

## `app/views/settlements/index.html.erb`

Ссылка на CSV для кассы — файлом, мимо Turbo (`download`).

## Критерии приёмки

**Форматы**

- [ ] Лист отвечает JSON по `.json` и по `Accept`.
- [ ] В JSON месяцы по порядку, пенсы целыми, состояния — именами.
- [ ] Чтение в JSON совпадает с чтением на странице.
- [ ] Реестр — JSON с полными адресами, и они ведут на листы дорог.
- [ ] Нет дороги — 404 JSON-ом, с полем `error`.
- [ ] CSV — файл с именем дороги; строки и пенсы те же, что в реестре.
- [ ] Ссылку на CSV Turbo не перехватит.
- [ ] `.xml` у листа и `.csv` у реестра — 406.
- [ ] Страница — по-прежнему страница.

**Приёмка сезона** (обход всех адресов окна на засеянном реестре)

- [ ] У каждого маршрута есть кому ответить.
- [ ] Каждая страница открывается — 200 и страница.
- [ ] Где ключ в адресе ведёт в никуда — 404.
- [ ] Каждая страница читается вслух: язык, одна главная часть, один
      заголовок, путь в реестр.
- [ ] Ни одна ссылка ни в одном фрейме не ведёт в «Content missing».
- [ ] Каждая форма уходит туда, где её принимают.
- [ ] Обход запросами GET ничего в реестре не меняет.

- [ ] `make test` → восемнадцать зелёных проверок.
- [ ] `make solution` в корне сезона → одиннадцать серий, ни одной красной;
      с браузером (`make test-visual`) — тоже.

## Подводный камень

Первый: пенсы в JSON строкой «£801 0s 0d». Для глаз удобно — машине
придётся разбирать её обратно, по-своему.

Второй: `format.any` «на всякий случай». 406 пропадёт, и аппарат примет
страницу за ответ.

Третий: ссылка на CSV без `download`. Turbo запросит файл и попытается
нарисовать его вместо страницы.
