# Теория — s05e02

## 1. Что лежит в адресе

Адрес `/companies/MID` — это не путь к файлу, а строка, которую таблица
маршрутов разбирает по образцу. Всё, что в образце названо через двоеточие,
попадает в `params`:

```ruby
get "companies/:code", to: "companies#show"
# /companies/MID  →  params[:code] == "MID"
```

Параметры — всегда строки. `params` собирает в одно место три источника:
куски адреса, строку запроса (`?period=1891-09`) и тело формы. Для
контроллера они неразличимы, и это удобно ровно до того дня, когда имя
совпадёт.

## 2. `to_param`: запись решает, как её адресовать

Помощник маршрута не знает про коды и номера. Он зовёт у записи `to_param` и
подставляет результат:

```ruby
company_path(mid)   # → "/companies/#{mid.to_param}"
```

По умолчанию `to_param` — номер строки, для несохранённой записи — `nil`.
Переопределяют его, когда у записи есть естественный ключ: код дороги, номер
бланка, человекочитаемое имя.

Два требования к естественному ключу:

- **уникален** — за ним стоит уникальный индекс (сезон 4, `s04e04`);
- **неизменен или почти** — адрес живёт в ссылках, журналах и закладках; ключ,
  который меняют, ломает их все сразу.

Код дороги подходит под оба.

## 3. `param:` и `constraints:`

```ruby
resources :companies, only: %i[index show], param: :code,
                      constraints: { code: Company::CODE }
```

`param:` меняет имя куска адреса: `/companies/:code`.

`constraints:` ставит образец на этот кусок. Образец — регулярное выражение
**без якорей**: Rails сам требует, чтобы оно покрыло кусок целиком. Якоря
`\A` и `\z` в ограничении маршрута — ошибка при загрузке.

Ограничения бывают и сложнее: на глагол, на поддомен, на произвольный объект
с методом `matches?(request)`. Сезону хватает образца.

## 4. Порядок маршрутов

Таблица перебирается сверху вниз; первый подошедший маршрут выигрывает.

```ruby
resources :companies, only: :show           # /companies/:id
get "companies/dormant", to: "companies#dormant"
```

`/companies/dormant` здесь попадёт в `show` с `id = "dormant"`: первый
маршрут подошёл. Лечится двумя способами:

| Способ | Как |
|---|---|
| порядок | частное — выше общего |
| ограничение | общий маршрут не берёт то, что на него не похоже |

`resources` сам ставит `new` выше `:id`. Но ограничение надёжнее порядка: оно
не зависит от того, в каком месте файла кто-то допишет строку.

## 5. `before_action`

```ruby
before_action :set_company, only: %i[show edit update destroy]
```

Фильтр — метод, который зовут до действия. Если он отрисовал ответ или
перенаправил, действие не зовут вовсе. Отсюда два применения:

- **общее для нескольких действий** — найти запись, как здесь;
- **отказ до действия** — «сначала войдите» (сезон 7).

Фильтры — закрытые методы (`private`): это не действия, и маршрут до них
дойти не должен. Открытый метод контроллера Rails считает действием.

Есть `after_action` и `around_action`; сезону они не нужны.

## 6. Одно решение в одном месте

Правило старше Rails: у каждого факта одно место, где он записан, а все
остальные его читают. В этой серии таких фактов три:

| Факт | Где решается | Кто читает |
|---|---|---|
| как выглядит код | `Company::CODE` | модель, таблица маршрутов |
| как адресовать дорогу | `Company#to_param` | все помощники маршрутов |
| как найти дорогу | `set_company` | каждое действие одной дороги |

Нарушение видно не сразу. Два образца кода совпадают в день, когда их пишут, и
расходятся в день, когда поправили одно место из двух.

## 7. Перенаправление постоянное и временное

Если адрес менялся, а старые ссылки жалко:

| Код | Значит |
|---|---|
| **301** Moved Permanently | теперь это там, насовсем; можно запомнить |
| **302** Found | сейчас это там; завтра может вернуться |
| **308** Permanent Redirect | как 301, но глагол не меняется |

```ruby
get "/companies/:id", to: redirect { |params, _| ... }, constraints: { id: /\d+/ }
```

Это честнее второго адреса: страница одна, ссылка на старый адрес говорит,
где она теперь.

## 8. Чего эта серия не закрывает

- **составные ключи в адресе** (`/settlements/MID/1891-09`) — `s05e06`;
- **форматы в адресе** (`/companies/MID.json`) — `s05e11`;
- **`find_or_create` по ключу из адреса** — никогда: `GET` не заводит.
