# CRIMSON RAILS

**Интерактивный курс по Ruby on Rails 8 через расследование на железной
дороге.** Сезон 1 готов, сезоны 2–8 в работе.

1891 год. Ты — младший вычислитель Расчётной палаты железных дорог: человек,
который переводит вопросы старших клерков в перфокарты для машины и читает
то, что она печатает в ответ. То есть программист — просто это слово ещё не
придумали.

В твоих столбцах перестаёт сходиться: доли пенса на перевозку, всегда в одну
сторону и всегда на одних и тех же линиях. Подделать поезд нельзя — подделать
запись о поезде можно. Инструмент расследования не револьвер, а хорошо
спроектированная схема данных.

Наставник — **ADA**, Аналитическая машина в подвале Палаты. Она машина и в
сюжете, и в жизни: в жизни это чат твоего редактора. Курс не притворяется, что
помощник — человек, и потому может учить тому, чему обычно учат отдельно: как
задать машине вопрос, на который стоит отвечать.

## Быстрый старт

```bash
git clone https://github.com/gfazzz/crimson-rails.git
cd crimson-rails
make test SERIES=s01e01          # прогон по эталону — репозиторий всегда зелёный

cd season-01-yokohama/s01e01-one-pass
cp starter.rb artifacts/ledger.rb
make test                        # теперь проверяется твой код
```

Нужен только **Ruby 3.1+**. Минитест входит в поставку; ни Rails, ни базы, ни
сети в первом сезоне не требуется. Подробнее — [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md).

## Восемь сезонов, а не четыре

Курс не начинается с `rails new`: первые три сезона — Ruby как язык, HTML и CSS
как контракт, JavaScript как язык браузера. Курс по Rails для человека, не
знающего Ruby, — это курс по копированию из документации.

| Сезон | Тема | Локация | Артефакт | Состояние |
|---|---|---|---|---|
| [1](season-01-yokohama/) | Ruby | Йокогама | `abacus` | **готов: 15 серий, 14 ч 05 мин, 516 проверок** |
| 2 | HTML и CSS | Лондон, Сент-Панкрас | `bradshaw` | в работе |
| 3 | JavaScript | Нью-Йорк | `telegraph` | план |
| 4 | схема и Active Record | Лондон, Сеймур-стрит | `ledger` | план |
| 5 | маршруты, контроллеры, Hotwire | диспетчерская Мидленда | `signal_box` | план |
| 6 | фон, кеш, каналы, интеграции | Транссиб | `dispatch` | план |
| 7 | аутентификация, права, аудит | Восточный экспресс | `keyring` | план |
| 8 | тесты, производительность, выкат | Чикаго, 1893 | `crimson` | план |

Каждая локация выбрана потому, что в ней предмет сезона виден лучше, чем
где-либо: колея 1067 мм объясняет соглашения, Транссиб — фоновые задачи,
Восточный экспресс — паспорт и ключ, то есть аутентификацию и права. Маршрут
целиком — в [docs/ROUTE.md](docs/ROUTE.md).

## Чем это проверяется

Rails 8 позволяет пройти весь курс на ноутбуке без единого внешнего сервиса:
очередь, кеш и каналы живут в той же SQLite, что и данные. `bin/rails test` не
требует ни Redis, ни Postgres, ни Docker.

**Тест проверяет свойство, а не текст.** Ни один тест курса не ищет подстроку
в коде студента: он создаёт данные, вызывает поведение и сверяет результат.
Поэтому тест можно и нужно читать — он и есть техническое задание.

Типов серий в курсе нет. Вместо них — контракт проверки сезона: что сезон
обязан проверять и что в нём не засчитывается за проверку
([SPEC.md](SPEC.md), §4).

```bash
make test                  # все серии
make test SEASON=01        # сезон
make test SERIES=s01e07    # серия
make check                 # links + test, как в CI
make progress              # где я остановился
```
