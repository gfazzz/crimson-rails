## Чему ты научишься

- Собирать палитру пользовательскими свойствами и менять её целиком.
- Спрашивать у читателя тёмный набор, а не предлагать переключателем.
- Считать коэффициент контраста и знать, какое число откуда.
- Объявлять браузеру, какие темы полоса поддерживает.
- Приёму, который дороже синтаксиса: **тема — это значения, а не другие
  правила.** Всё, что в теме объявлено помимо палитры, придётся поддерживать
  дважды.

Подробнее — в [`theory.md`](theory.md).

## Теория: цвет как значение

### Палитра

```css
html {
  --paper: #f6f1e7;
  --ink: #1c1a17;
  --rule: #8a7f68;
  --crimson: #7b1220;
  --on-crimson: #f6f1e7;
}

body { color: var(--ink); background-color: var(--paper); }
```

Цвет, написанный на месте, темы не знает: при тёмном наборе он останется
прежним. Палитра — это имена, у которых в каждой теме своё значение.

Имена дают по **роли**, а не по виду: `--paper`, а не `--beige`. Через месяц
бумага станет серой, и `--beige: #2a2a2a` будет читаться как издевательство.

### Спросить, а не предложить

```css
@media (prefers-color-scheme: dark) {
  html {
    --paper: #16151a;
    --ink: #e8e3d8;
    --rule: #7a7466;
    --crimson: #f0929c;
    --on-crimson: #16151a;
  }
}
```

Настройка у читателя уже есть — в системе, и часто по расписанию: днём
светлая, вечером тёмная. Переключатель на странице дублирует её и почти всегда
расходится с ней.

Внутри добавки — **только палитра**. Ни одного правила раскладки: иначе
раскладок становится две, и однажды правку внесут в одну.

### `color-scheme`

```css
html { color-scheme: light dark; }
```

Объявление для браузера, а не для свода. По нему красятся поля ввода, полосы
прокрутки, выпадающие списки и фон за краем полосы. Без него в тёмном наборе
остаётся светлая полоса прокрутки и белая вспышка при загрузке.

### Выворотка — не инверсия

```css
html { filter: invert(1); }   /* ✘ */
```

Выворачивание меняет всё разом, включая изображения: схема линии станет
негативом, фотография — рентгеновским снимком. И красный превращается в
голубой.

И ровно та же беда, что у Гарнетт: светлый текст на тёмном **расплывается**
оптически. Поэтому в тёмном наборе берут не чистый белый (`#e8e3d8`, а не
`#ffffff`) и более светлые чернила, чем в светлом.

### Коэффициент контраста

Отношение относительных яркостей двух цветов, от 1 (одинаковые) до 21 (чёрное
на белом).

| Что | Порог | Откуда |
|---|---|---|
| основной текст | 4,5 | WCAG 1.4.3 (AA) |
| крупный текст (от 24px или 19px полужирного) | 3 | там же |
| линии и элементы управления, несущие смысл | 3 | WCAG 1.4.11 |
| повышенный уровень | 7 | WCAG 1.4.6 (AAA) |

Числа взяты не из вкуса: 4,5 — это порог, на котором текст остаётся читаемым
при остроте зрения около 20/40, обычной после сорока лет.

Считать вручную не нужно: коэффициент показывает любой инспектор рядом с
образцом цвета, а при разборе свода его считает проверка.

### Цвет — не единственный признак

```css
a { color: var(--crimson); text-decoration-thickness: 1px; }
```

Ссылка, отличающаяся от текста одним лишь цветом, не видна тем, кто цвет
различает иначе, — а это каждый двенадцатый мужчина. Подчёркивание остаётся
(WCAG 1.4.1).

То же и на полосе: условные обозначения — буквы, а не цветные значки. Буква
читается вслух, печатается на чёрно-белом принтере и видна при любом зрении.

### Что появилось недавно

`light-dark(светлое, тёмное)` берёт значение по `color-scheme`, без
медиазапроса. `oklch()` задаёт цвет так, что одинаковая светлота выглядит
одинаково светлой при любом тоне, — удобно для палитры, где все тона равно
контрастны. Здесь довольно палитры и медиазапроса: механизм проще, а
объясняет больше.

### Где это в Rails

```erb
<meta name="theme-color" content="#f6f1e7"
      media="(prefers-color-scheme: light)">
```

Rails к палитре отношения не имеет — это тот же свод. Но в макете приложения
живёт `theme-color`, которым красится строка браузера на телефоне, и его
объявляют парой, по одному на тему: иначе тёмный набор получает светлую шапку.

## Проверка: ADA задаёт вопросы

```
[ADA · ВНУТРЕННЯЯ ЛИНИЯ]
ТРИ ВОПРОСА.
```

**1.** ADA: «`filter: invert(1)` у корня. Что получится и что сломается?»

<details><summary>Ответ</summary>

Получится тёмный набор, и почти сразу — жалобы. Выворачивается всё: схема
линии станет негативом, красные чернила — голубыми, а фотография —
рентгеновским снимком.

И тонкий светлый штрих на тёмном расплывается оптически, ровно как в
выворотке у Гарнетт. Тёмная тема — другие значения, а не те же наизнанку.
</details>

**2.** ADA: «Серый `#767676` на белом — 4,54. На бумаге `#f6f1e7` — сколько?»

<details><summary>Ответ</summary>

Меньше: около 4,2. Бумага темнее белого, и порог перестаёт выполняться.

Отсюда практическое: коэффициент считают для **пары**, а не для цвета.
Изменив фон, надо пересчитать все тексты на нём — и в каждой теме отдельно.
</details>

**3.** ADA: «Ссылка отличается от текста только цветом, контраст к фону 7.
Достаточно?»

<details><summary>Ответ</summary>

Нет. Семь — это контраст к фону; речь о другом. Читатель должен отличить
ссылку **от соседнего текста**, а не от бумаги, и для этого цвета мало:
дальтонизм красно-зелёного ряда есть у каждого двенадцатого мужчины.

Нужен второй признак: подчёркивание, начертание, рамка. WCAG 1.4.1 требует
именно этого.
</details>

## Разбор типичных ошибок

1. **Цвет написан на месте.** Он темы не знает.
2. **Имена по виду, а не по роли.** `--beige: #2a2a2a` через месяц.
3. **Нет `color-scheme`.** Светлая полоса прокрутки посреди тёмного набора.
4. **Тёмная тема выворачиванием.** Негатив вместо схемы, голубое вместо
   красного.
5. **В тёмной теме перекрашен только фон.** Линейки и чернила остались от
   светлой и пропали.
6. **В теме объявлена раскладка.** Раскладок стало две.
7. **Контраст оценён на глаз.** На своём мониторе, при своём зрении, при своём
   освещении.
8. **Порог взят один на всё.** У текста 4,5, у линеек 3 — это разные числа.
9. **Ссылка отличается одним цветом**, обозначения — цветными значками. Не
   видно каждому двенадцатому, не читается вслух, не печатается.

## Debriefing

Полоса читается при обоих наборах. Ты проверяешь переключением системной
настройки: бумага темнеет, чернила светлеют, линейки остаются видны, схема
линии остаётся схемой.

Гарнетт смотрит на прошлогодний образец в том же тёмном наборе — и
останавливается.

— А это откуда?

Строка Колвик-Сайдингс. В карманном издании служебные остановки не печатают:
правило Палаты, восемьдесят седьмой год. В прошлогоднем образце она напечатана
и там.

— Может, набрали по ведомости, — говоришь ты.

— В ведомости она есть с пометой «не печатать». — Гарнетт водит пальцем по
оттиску. — И вот ещё: прочие станции набраны одинаково, а эта — как заголовок
полосы. Она не из ведомости. Она из самого образца.

Никто не вписывал Колвик-Сайдингс в данные. Её вписали в **образец** — один
раз, в девяностом, — и с тех пор она печатается сама, в каждом выпуске,
потому что так устроен образец.
