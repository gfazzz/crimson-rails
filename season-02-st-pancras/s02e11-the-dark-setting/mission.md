## Обстановка

В станционной кассе газовый рожок и стекло в копоти. Просят набрать так, чтобы
читалось — вывороткой, светлым по тёмному.

Вывернуть готовый набор нельзя: тонкие штрихи заплывают. Для выворотки берут
другие литеры. То же и здесь: тёмный набор — другие **значения** при тех же
правилах.

У Палаты есть таблица плотностей: краска обязана отличаться от поля не меньше
чем на столько-то, и число для набора одно, а для линеек другое.

## Приказ

Довести `artifacts/bradshaw.css` до седьмой редакции. Разметка не меняется
вовсе: `artifacts/bradshaw.html` копируется из `starter.html` как есть.

## Палитра

Имена дают по роли, а не по виду: `--paper`, а не `--beige`.

| Имя | Роль |
|---|---|
| `--paper` | фон полосы |
| `--ink` | основной набор |
| `--ink-soft` | подписи и пометы |
| `--rule` | линейки таблицы и служебной колонки |
| `--crimson` | красные чернила: ссылки и пометы |
| `--on-crimson` | набор поверх красного |

## Пороги

| Что | Не меньше |
|---|---|
| основной текст к своему фону | 4,5 |
| подписи и пометы к своему фону | 4,5 |
| линейки к своему фону | 3 |

В обоих наборах. Считать руками не нужно: коэффициент показывает любой
инспектор рядом с образцом цвета.

## Критерии приёмки

- [ ] Ни одного цвета, написанного на месте: все `color`, `background-color`,
      `border*` и `outline` берут цвет из палитры через `var(--…)`. Печатный
      набор — исключение: там чёрным по белому.
- [ ] В палитре не меньше четырёх цветов, и цвет бумаги объявлен у корня
      полосы.
- [ ] Объявлен `color-scheme`, и в нём названы обе темы.
- [ ] Есть добавка `@media (prefers-color-scheme: dark)`.
- [ ] В ней переобъявлено не меньше трёх значений палитры.
- [ ] В ней **не объявлено ничего, кроме палитры** — ни одного правила
      раскладки.
- [ ] Нигде нет `filter: invert(…)`.
- [ ] В светлом наборе каждая пара «текст на своём фоне» даёт не меньше 4,5.
- [ ] В светлом наборе каждая линейка на своём фоне — не меньше 3.
- [ ] То же в тёмном наборе.
- [ ] Палитры двух наборов не совпадают больше чем в одном имени.
- [ ] Ни одно правило для ссылок не снимает подчёркивание (кроме печатного
      набора).
- [ ] Условные обозначения остаются буквенными.
- [ ] Свод остался сводом: ни `!important`, ни идентификаторов, правила по
      неубыванию веса; перелом и печатный набор из `s02e10` на месте;
      структура полосы цела.
- [ ] `make test` → семнадцать зелёных проверок.

## Подводный камень

Коэффициент считается для **пары**, а не для цвета. Серый `#767676` на белом
даёт 4,54 и проходит; он же на бумаге `#f6f1e7` даёт около 4,2 и не проходит.
Поменяв фон, надо пересчитать все тексты на нём — в каждой теме отдельно.

Второй: в тёмном наборе чистый белый `#ffffff` на чёрном формально даёт 21, а
читается хуже, чем `#e8e3d8`: светлый штрих на тёмном расплывается оптически.
Порог — нижняя граница, а не цель.

## Выполнение

```bash
cp starter.html artifacts/bradshaw.html
cp starter.css  artifacts/bradshaw.css
make test
```

Проверить руками стоит так: переключить системную настройку светлый/тёмный и
посмотреть на полосу целиком — включая схему линии, красные пометы и линейки
таблицы.

## После выполнения

Полоса станет читаемой при обоих наборах.

А в прошлогоднем образце обнаружится строка, которой там быть не может:
Колвик-Сайдингс напечатана и в карманном издании, где служебные остановки не
печатают с восемьдесят седьмого года. И набрана она не как строка ведомости, а
как часть самого образца.
