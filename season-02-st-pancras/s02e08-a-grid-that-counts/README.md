## Лондон, верстальный стол, 14 апреля, 09:10

На столе лежит лист с расчерченным прямоугольником. Внутри — пять клеток, и в
каждой написано слово: **шапка**, **оглавление**, **набор**, **служебное**,
**подпись**.

— Макет, — говорит Прингл. — По нему верстают любую полосу справочника, хоть
мидлендскую, хоть ирландскую. Места названы, и в каждое кладут своё.

— А если поменять местами?

— Перечерчиваешь макет. Один лист. — Он постукивает по бумаге. — Раньше
считали по линиям: «от третьей до пятой, от второй до четвёртой». Потом
кто-нибудь добавлял колонку, и вся полоса ехала. Со словами так не бывает.

Ты смотришь на клетку «служебное» — узкую, вдоль правого края.

— Здесь что?

— Типография, дата сверки Палатой. Это не про линию, это про выпуск. — Прингл
хмурится. — И Палата требует, чтобы стояло отдельно, не в наборе. Смешаешь —
получится, что сверяли расписание, а сверяли выпуск.

Он достаёт прошлогодний оттиск. Служебная колонка на месте, и в ней дата:

## Теория: сетка

### Макет строками

```css
body {
  display: grid;
  grid-template-columns: minmax(0, 1fr) fit-content(12rem);
  grid-template-areas:
    "head head"
    "nav  nav"
    "main side"
    "foot foot";
  gap: 1.5rem;
  align-items: start;
}

header { grid-area: head; }
main   { grid-area: main; }
aside  { grid-area: side; }
```

Строки в `grid-template-areas` — это и есть чертёж: сколько слов в строке,
столько колонок; сколько строк, столько рядов. Одно имя, повторённое подряд,
растягивает область на несколько клеток. Точка (`.`) оставляет клетку пустой.

Альтернатива — номера линий (`grid-column: 1 / 3`). Они работают, но
рассыпаются от одной вставленной колонки: все номера после неё сдвигаются, и
найти это можно только глазами.

### Ряд и сетка — разные инструменты

| | Flexbox | Grid |
|---|---|---|
| направление | одно | два сразу |
| кто задаёт раскладку | содержимое | контейнер |
| колонки соседних рядов | не выравниваются | выравниваются всегда |
| когда брать | ряд однородных штук | макет страницы, таблица блоков |

Правило первого приближения: **раскладка идёт от содержимого — ряд; раскладка
задана заранее — сетка.**

### Единица `fr` и ловушка `1fr`

`1fr` — «одна доля свободного места». Но по умолчанию это `minmax(auto, 1fr)`,
и нижняя граница `auto` означает «не меньше минимальной ширины содержимого».
Длинное слово, широкая картинка или таблица распирают колонку изнутри, и сетка
вылезает за родителя.

```css
grid-template-columns: minmax(0, 1fr) fit-content(12rem);
```

`minmax(0, 1fr)` снимает нижнюю границу: колонка держит заданную долю, а
содержимое, которое не влезло, разбирается само (переносом, прокруткой,
уменьшением). Это первое, что проверяют, когда «сетка поехала».

`fit-content(12rem)` — колонка по содержимому, но не шире двенадцати единиц.

### Зазор и выравнивание

`gap` в сетке тот же, что во флексе, и работает по обеим осям сразу. Поля
областей ему не замена: сетка не схлопывает их, а прибавляет.

Выравнивание — четыре свойства, по две оси:

| | Вдоль строки (inline) | Вдоль колонки (block) |
|---|---|---|
| **содержимое клетки** | `justify-items` | `align-items` |
| **сетку целиком** | `justify-content` | `align-content` |

По умолчанию `stretch`: область растягивается на всю клетку. Для колонок
разной длины это значит, что короткая справка вытянется по высоте длинного
набора. `align-items: start` прижимает каждую к началу своей строки.

### Колонки, которых никто не считал

```css
grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
```

`auto-fit` и `auto-fill` считают число колонок сами: сколько влезет по
`minmax`, столько и будет. Автор не пишет ни числа колонок, ни ширины окна —
раскладка перестраивается без единого медиазапроса.

Разница между ними видна, когда элементов мало: `auto-fill` оставляет пустые
колонки, `auto-fit` их схлопывает, и оставшиеся растягиваются.

### Где это в Rails

```erb
<%# app/views/layouts/application.html.erb %>
<body>
  <%= render "shared/header" %>
  <%= render "shared/nav" %>
  <main><%= yield %></main>
  <aside><%= yield :sidebar %></aside>
  <%= render "shared/footer" %>
</body>
```

Макет страницы в Rails — это `layouts/application.html.erb`, и он один на всё
приложение. Области названы и там: `yield :sidebar` — именованное место, куда
любой вид может положить своё. Имя вместо номера — та же мысль этажом выше.

## Проверка: ADA задаёт вопросы

```
[ADA · ВНУТРЕННЯЯ ЛИНИЯ]
ТРИ ВОПРОСА.
```

**1.** ADA: «`grid-template-columns: 1fr 1fr`. В левой колонке таблица шире
колонки. Что произойдёт?»

<details><summary>Ответ</summary>

Левая колонка раздуется до минимальной ширины таблицы, правая сожмётся, а если
места не хватит — сетка вылезет за родителя.

`1fr` — это `minmax(auto, 1fr)`, и `auto` снизу значит «не меньше содержимого».
Лечится `minmax(0, 1fr)`: колонка держит долю, а содержимое разбирается само.
</details>

**2.** ADA: «Область справки короче области набора. Почему справка вытянулась
на всю высоту и как это отменить?»

<details><summary>Ответ</summary>

Потому что по умолчанию `align-items: stretch`: клетка растягивает своё
содержимое, а высоту строки задаёт самая высокая область.

Отменяется `align-items: start` у сетки — или `align-self: start` у одной
области, если исключение нужно только ей.
</details>

**3.** ADA: «Что сломается, если раздавать области номерами линий и потом
вставить колонку слева?»

<details><summary>Ответ</summary>

Все номера сдвинутся на единицу, и каждая область встанет левее своего места.
Ошибки не будет: номера остались допустимыми, просто указывают не туда.

С именами этого не бывает. Вставленная колонка меняет чертёж — то есть строки
`grid-template-areas`, одно место в своде, — а раздача областей не меняется
вовсе.
</details>

## Разбор типичных ошибок

1. **Области раздаются номерами линий.** Одна вставленная колонка — и всё
   съехало, молча.
2. **`1fr` вместо `minmax(0, 1fr)`.** Колонка раздувается изнутри содержимым.
3. **Забытый `align-items: start`.** Короткая область тянется за длинной.
4. **Зазор держится на полях областей.** В сетке поля не схлопываются —
   складываются с `gap`.
5. **Область нарисована, но никем не занята.** Пустое место, о котором знает
   только свод.
6. **Рисунок сетки расходится с порядком разметки.** Глаз видит одно,
   клавиатура идёт по другому.
7. **Справка положена внутрь `<main>`.** Это уже не справка рядом с
   содержанием, а часть содержания.
8. **Ссылка в обход возвращается в поток по фокусу.** В сетке она становится
   клеткой и сдвигает всю полосу.

Полоса легла в макет. Служебная колонка встала справа, по верхнему краю
набора, и не тянется за ним по высоте.

— Одинаково, — говорит он. — Кроме одного.
