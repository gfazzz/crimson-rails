# Теория — s02e08

## 1. Что делает `display: grid`

Как и флекс, объявление меняет правила для **детей**. Но флекс раскладывает в
одном направлении, а сетка — в двух сразу: контейнер задаёт рисунок клеток,
дети в него ложатся.

Отсюда главное различие:

| | Flexbox | Grid |
|---|---|---|
| направление | одно | два |
| кто задаёт раскладку | содержимое | контейнер |
| колонки соседних рядов | не выравниваются | выравниваются всегда |
| типичное применение | ряд однородных штук | макет страницы, таблица блоков |

Правило первого приближения: **раскладка идёт от содержимого — ряд; раскладка
задана заранее — сетка.**

## 2. Чертёж строками

```css
grid-template-columns: minmax(0, 1fr) fit-content(12rem);
grid-template-rows: auto auto auto auto;
grid-template-areas:
  "head head"
  "nav  nav"
  "main side"
  "foot foot";
```

Читается как чертёж: слов в строке — столько колонок, строк — столько рядов.
Повторённое имя растягивает область на несколько клеток; точка (`.`) оставляет
клетку пустой.

```css
main { grid-area: main; }
```

Сокращение `grid-template` собирает всё вместе:

```css
grid-template:
  "head head" auto
  "main side" 1fr
  "foot foot" auto
  / minmax(0, 1fr) fit-content(12rem);
```

## 3. Имена против номеров

Второй способ раздачи мест — по номерам линий:

```css
main { grid-column: 1 / 3; grid-row: 2; }
main { grid-column: 1 / -1; }   /* от первой до последней */
```

Он работает и иногда незаменим (динамическое число колонок). Но вставленная
колонка сдвигает все номера после неё, и каждая область встаёт левее своего
места. Ошибки при этом нет: номера остались допустимыми.

Именованные линии — середина между двумя способами:

```css
grid-template-columns: [full-start] 1fr [content-start] 40rem [content-end] 1fr [full-end];
main { grid-column: content; }   /* имя линии + -start/-end */
```

## 4. Единицы дорожек

| Запись | Что значит |
|---|---|
| `200px`, `12rem` | фиксированная дорожка |
| `auto` | по содержимому; тянется, если есть излишек |
| `min-content` | по самому длинному неразрывному куску |
| `max-content` | по содержимому без переносов |
| `1fr` | доля свободного места **после** фиксированных |
| `minmax(a, b)` | не меньше `a`, не больше `b` |
| `fit-content(n)` | по содержимому, но не шире `n` |
| `repeat(3, 1fr)` | три одинаковых |
| `repeat(auto-fit, minmax(14rem, 1fr))` | сколько влезет |

**Ловушка `1fr`.** По определению `1fr` — это `minmax(auto, 1fr)`. Нижняя
граница `auto` означает «не меньше минимальной ширины содержимого», и широкая
картинка, таблица или длинное слово распирают дорожку изнутри. Сетка вылезает
за родителя, появляется горизонтальная прокрутка.

`minmax(0, 1fr)` снимает нижнюю границу: дорожка держит долю, а содержимое
разбирается само — переносом, прокруткой или уменьшением. Это первое, что
проверяют, когда «грид поехал».

## 5. Зазор и выравнивание

`gap` работает по обеим осям: `gap: 1.5rem 1rem` — между рядами и между
колонками. Поля областей ему не замена: сетка их не схлопывает, а прибавляет.

Восемь свойств выравнивания, но устроены они просто — две оси и два предмета:

| | inline (вдоль строки) | block (вдоль колонки) |
|---|---|---|
| **содержимое клеток** | `justify-items` | `align-items` |
| **сетка целиком в контейнере** | `justify-content` | `align-content` |
| **одна область** | `justify-self` | `align-self` |

По умолчанию `stretch`. Для областей разной длины это значит, что короткая
вытянется по высоте самой длинной в своей строке: рамка уедет на пустое место,
фон растянется. `align-items: start` прижимает каждую к началу строки.

Сокращения: `place-items: start center` (`align` затем `justify`),
`place-content`, `place-self`.

## 6. Автоматическое размещение

Дети, которым не назначена область, раскладываются автоматически — по строкам,
слева направо, сверху вниз. Управляют этим:

```css
grid-auto-flow: row | column | dense;
grid-auto-rows: minmax(6rem, auto);   /* размер незапланированных рядов */
```

`dense` заполняет дыры, переставляя элементы, — и значит расходится с порядком
разметки. Тот же запрет, что у `order` во флексе: только там, где порядок
ничего не значит.

## 7. Колонки, которых никто не считал

```css
grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
```

Браузер делит доступную ширину на дорожки не уже `14rem` и не шире доли, и
считает их сам. Раскладка перестраивается при любой ширине без единого
медиазапроса.

`auto-fill` против `auto-fit`: при нехватке элементов первый оставляет пустые
дорожки, второй схлопывает их в ноль, и оставшиеся растягиваются. На полной
сетке разницы нет.

## 8. Подсетка

```css
.card { display: grid; grid-template-rows: subgrid; grid-row: span 3; }
```

`subgrid` позволяет вложенной сетке пользоваться дорожками родительской — и
тем самым выровнять, скажем, заголовки всех карточек по одной линии, чего
флексом нельзя добиться вовсе. Появилось позже остального грида; поддержка
сегодня повсеместная, но в старых проектах встречается редко.

## 9. Инструмент

В инспекторе любого браузера рядом с элементом-сеткой есть значок `grid`:
включённый, он рисует поверх страницы линии, их номера и имена областей. Это
единственный быстрый способ увидеть, где заканчивается дорожка и почему
область встала не туда.
