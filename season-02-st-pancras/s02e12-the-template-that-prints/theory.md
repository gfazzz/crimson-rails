# Теория — s02e12

## 1. Что такое шаблон

Шаблон — текст с дырками, в которые подставляются значения. У него всегда две
половины и одно соединение:

```
данные      что печатать        data/april-1891.json
шаблон      как печатать        bradshaw.html.erb
печать      соединить одно с другим   render.rb
```

Разделение полезно ровно тем, что каждую половину можно проверить отдельно:
данные — на полноту, шаблон — сменой данных.

## 2. ERB: три скобки

```erb
<%= выражение %>     напечатать результат
<%  выражение %>     выполнить, ничего не печатая
<%# что угодно %>    примечание, в вывод не попадает
```

Управляющие конструкции Ruby разбиваются на несколько скобок:

```erb
<% issue["sections"].each do |section| %>
  <h2><%= h section["name"] %></h2>
<% end %>

<% if section["current"] %>текущий<% end %>
```

### Обрезка

`ERB.new(текст, trim_mode: "-")` включает дефисы:

```erb
<%- ... -%>
```

Открывающий дефис съедает пробелы перед скобкой, закрывающий — перевод строки
после. Без них строка-управление оставляет в выводе пустую строку на каждом
обороте цикла. Другие режимы: `"<>"` (обрезать у строк, целиком состоящих из
скобки), `"%"` (строки, начинающиеся с `%`, считать кодом).

## 3. Экранирование

Обычный ERB печатает как есть:

```erb
<p><%= "Брэдшоу & сыновья" %></p>    →  <p>Брэдшоу & сыновья</p>
<p><%= "<b>жирно</b>" %></p>         →  <p><b>жирно</b></p>
```

Второе — не украшение, а исполнение чужой разметки. Если значение пришло из
формы, то же место исполнит и `<script>`. Это межсайтовый скриптинг, и он
начинается ровно здесь.

```ruby
require "cgi"
def h(value) = CGI.escapeHTML(value.to_s)
```

`CGI.escapeHTML` заменяет `&`, `<`, `>`, `"` и `'` на именованные подстановки.

**В Rails это делается само.** `<%= %>` в видах Rails экранирует всегда;
чтобы напечатать разметку, нужно объявить это вслух:

```erb
<%= raw value %>
<%= value.html_safe %>
<%= sanitize value %>      <%# разрешает список безопасных тегов %>
```

`html_safe` ничего не проверяет — он лишь помечает строку как уже безопасную.
Позвать его на значении из формы значит выключить защиту нарочно. Правило:
экранировано по умолчанию, исключение объявляется и объясняется.

## 4. Как проверить, что данных нет в шаблоне

Не чтением. Печатью по другому листу:

```bash
ruby render.rb bradshaw.html.erb data/april-1891.json   /tmp/april.html
ruby render.rb bradshaw.html.erb tests/fixtures/control.json /tmp/control.html
```

Всё, что вшито в шаблон, напечатается в обеих полосах — и в контрольной
окажется чужим. Способ дешёвый, механический и не зависящий от внимательности.

Тот же приём годится для любого шаблона: письма, счёта, отчёта. Если по двум
разным наборам данных выходит один и тот же кусок текста — он в шаблоне, и
надо решить, там ли ему место.

## 5. Что шаблону можно знать

| Можно | Нельзя |
|---|---|
| порядок частей полосы | какие станции бывают |
| «если есть схема — напечатать» | «если станция Колвик — не печатать» |
| формат: `[1]` вокруг номера пометы | сам номер пометы |
| разметку: какие теги и атрибуты | текст, который в них попадёт |

Признак того, что логика уехала в шаблон: условие сложнее, чем «есть — нет».
Как только в шаблоне появляется сравнение со значением (`== "Колвик"`,
`> 1891`), решение спряталось от того, кто читает данные, — а данные читают
чаще, чем разметку.

## 6. Частичные виды

Повторяющийся кусок выносят. Здесь это делается вручную, в Rails — механизмом:

```erb
<%# app/views/timetables/_row.html.erb %>
<tr>
  <th scope="row"><%= station.name %></th>
  <% station.times.each do |time| %><td><%= time %></td><% end %>
</tr>

<%# в основном виде %>
<%= render partial: "row", collection: @stations, as: :station %>
```

Частичный вид полезен ровно тогда, когда у куска есть имя. Если имени нет,
вынос делает не понятнее, а на файл больше.

## 7. Макет

```erb
<%# app/views/layouts/application.html.erb %>
<!doctype html>
<html lang="ru">
<head>
  <%= stylesheet_link_tag "application" %>
  <%= yield :head %>
</head>
<body>
  <%= render "shared/header" %>
  <main><%= yield %></main>
</body>
</html>
```

Обвязка полосы — та, что одинакова на всех страницах, — живёт в макете и
пишется один раз. `yield` — место, куда ляжет вид; `yield :name` — именованное
место, куда любой вид может положить своё (`content_for :head`).

Наш `bradshaw.html.erb` пока содержит и обвязку, и содержание. В сезоне 5 они
разойдутся по двум файлам, и это будет единственное изменение.

## 8. Две развилки, которые здесь пройдены

Фаулер называет их Template View и Transform View:

| | Template View | Transform View |
|---|---|---|
| как устроено | разметка с дырками | функция данные → разметка |
| пример | ERB, Jinja, Handlebars | XSLT, JSX, генерация из кода |
| читается | как будущая страница | как программа |
| опасность | логика заползает в разметку | разметка теряется среди кода |

ERB — первое. Опасность у него ровно одна, и вся эта серия про неё: не дать
логике заползти.
