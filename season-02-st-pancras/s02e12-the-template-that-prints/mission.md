## Обстановка

Прошлогодний образец Мидленда печатал станцию, которой нет в ведомости. Три
года, каждый выпуск, потому что она была вписана в **образец**, а не в данные.

Палата обязана дать образец настоящий: такой, чтобы копия у кого угодно ничего
не решала.

## Приказ

Переписать `artifacts/bradshaw.html.erb` так, чтобы он ничего не знал, кроме
того, что приходит в листе выпуска. Свод правил переносится из `s02e11` без
изменений.

## Что есть под рукой

```
data/april-1891.json      лист выпуска: что печатать
render.rb                 печать: ruby render.rb <шаблон> <лист> <куда>
starter.html.erb          прошлогодний образец, переложенный в шаблон как есть
starter.css               свод седьмой редакции, из s02e11
```

`render.rb` менять не нужно. Он даёт шаблону лист в переменной `issue` и
помощник `h()` для экранирования.

## Что должно прийти из листа

| Часть полосы | Откуда |
|---|---|
| заголовок окна, название линии, выпуск | `title`, `issue` |
| ссылка в обход | `skip` |
| название справочника и его язык | `guide` |
| оглавление и пометка текущего раздела | `sections` |
| разделы, вступления, сокращения | `sections[].intro` |
| служебные остановки | `sections[].service_stops` |
| схема линии и наборная линейка | `sections[].figure`, `sections[].rule` |
| расписание: подпись, группы, поезда, станции, времена | `sections[].schedule` |
| условные обозначения | `sections[].legend` |
| служебная колонка | `aside` |
| примечания | `notes` |

В образце не должно остаться **ни одного названия станции, ни одного времени,
ни одной даты**.

## Пропуск

У станции в листе есть помета `print`. Станция с `print: false` в таблицу не
попадает — решение принимает лист, а образец его исполняет.

## Критерии приёмки

**Печать по листу**

- [ ] `<title>` содержит название линии и выпуск из листа; `<h1>` равен
      названию.
- [ ] Оглавление напечатано по `sections`, и `aria-current="page"` стоит ровно
      на том разделе, который назван текущим в листе.
- [ ] Число строк таблицы равно числу станций с `print: true`, и времена в
      каждой строке совпадают с листом.
- [ ] Все примечания напечатаны, тексты совпадают дословно; условные
      обозначения — из листа.
- [ ] Значения экранированы: амперсанд из листа выходит как `&amp;`.

**В образце нет данных** — проверяется печатью по второму, контрольному листу

- [ ] По контрольному листу печатается его собственная полоса.
- [ ] Ни одной станции апрельского листа в контрольной полосе.
- [ ] Ни одной станции с `print: false` ни в одной из полос; все станции с
      `print: true` — на месте.
- [ ] Ширина таблицы равна числу поездов плюс колонка станций — в обеих
      полосах.
- [ ] Ссылка в обход ведёт по адресу из листа и попадает внутрь `<main>`.

**Приёмка сезона: полоса** (обе полосы, и апрельская, и контрольная)

- [ ] Семантика: `lang="ru"`, один `<h1>`, уровни без пропусков, ни одного
      `<div>`, по одному ориентиру каждого вида, помеченное иноязычное
      вкрапление.
- [ ] Таблица: `<caption>`, шапка в две строки, `scope` у каждого заголовка,
      у каждой строки свой `<th scope="row">`.
- [ ] Доступность: ссылка в обход первая, `alt` у каждого изображения, ни
      одного положительного `tabindex`, ни одной роли-повтора, объявлена
      область просмотра, прокручиваемая область с ролью, именем и
      `tabindex="0"`.
- [ ] Каждая внутренняя ссылка ведёт к существующему `id`.

**Приёмка сезона: свод**

- [ ] Ни одного `!important`, ни одного идентификатора, правила по неубыванию
      веса.
- [ ] Классы разметки и правила свода сходятся один в один.
- [ ] Кегли не в пикселях, интерлиньяж без единиц, в шкале есть текучая
      ступень со слагаемым от кегля и мера строки в знаках.
- [ ] Основной рисунок сетки одноколоночный; переломов один-три, все снизу
      вверх и в `em`; есть печатный набор и тёмный набор.
- [ ] Контраст: 4,5 для текста и 3 для линеек — в обоих наборах.

- [ ] `make test` → двадцать три зелёные проверки.

## Подводный камень

Проверка «в образце нет данных» печатает шаблон **дважды**. Это единственный
честный способ: прочесть образец глазами три года не помогало.

Второй: `h()` нужен каждому значению, а не тем, где «вроде бы могут быть
спецсимволы». Лист правят люди; в следующем выпуске в названии типографии
появится `&`, и кто-нибудь узнает об этом от браузера.

Третий: обрезка. `<% %>` оставляет в полосе пустую строку на каждом обороте
цикла. Разметке это не мешает, чтению — мешает; `<%- -%>` убирает.
