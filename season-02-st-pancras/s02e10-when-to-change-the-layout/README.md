## Чему ты научишься

- Писать свод «сперва узкое» и добавлять широкое, а не отнимать.
- Назначать перелом содержимым, а не списком устройств.
- Задавать перелом в `em` и делать таблицу прокручиваемой так, чтобы в неё
  можно было попасть клавишей.
- Приёму, который дороже синтаксиса: **основа достаётся всем, добавку можно
  не получить.** Поэтому в основе лежит то, без чего нельзя.

Подробнее — в [`theory.md`](theory.md).

## Теория: добавка, а не вычитание

### Два направления

```css
/* сперва узкое: основа для всех, добавка для широких */
.layout { grid-template-columns: minmax(0, 1fr); }
@media (min-width: 45em) { .layout { grid-template-columns: 1fr 12rem; } }

/* сперва широкое: основа для широких, отнимание для узких */
.layout { grid-template-columns: 1fr 12rem; }
@media (max-width: 45em) { .layout { grid-template-columns: minmax(0, 1fr); } }
```

Результат на двух ширинах одинаков. Разница — в том, что происходит, когда
добавка не доехала (запрос не поддержан, стиль загружен частично, полоса
открыта в читалке): в первом случае читатель получает узкую полосу — рабочую,
во втором — широкую раскладку в узком окне.

И вторая разница, важнее: **вычитать забывают.** Добавляя, автор перечисляет,
что появилось; отнимая — что должно исчезнуть, а этот список нигде не записан.

### Перелом назначает содержимое

Перелом — это ширина, на которой полоса перестаёт читаться; найти её можно
только сужая окно и глядя. Списки вида «телефон 480, планшет 768, ноутбук
1024» описывают модели, которые устареют, и не описывают ни одного окна: люди
открывают браузер в половину экрана и делят его пополам. Отсюда и число
переломов: один или два, а не семь.

### Перелом в `em`

```css
@media (min-width: 45em) { … }
```

`em` в медиазапросе считается от **начального** кегля браузера — от настройки
читателя, а не от `font-size` корня. Тот, кто увеличил шрифт, получает перелом
раньше: текста в строку влезает меньше, и узкая раскладка ему нужна на более
широком окне.

С `px` этого не происходит вовсе: окно не изменилось, значит и перелом не
сработал, хотя полоса уже не читается.

### Что бывает в запросе, кроме ширины

```css
@media (prefers-reduced-motion: reduce) { … }   /* читатель просил без движения */
@media (prefers-color-scheme: dark) { … }       /* s02e11 */
@media (prefers-contrast: more) { … }
@media (pointer: coarse) { … }                  /* палец, а не мышь */
@media print { … }
```

Первые три — настройки читателя, а не свойства устройства. Их не угадывают и
не предлагают переключателем: их спрашивают. Современная запись диапазона —
`@media (width >= 45em)` и `@media (30em <= width <= 60em)`.

### Печатный набор

Расписание печатают. На бумаге нет ни прокрутки, ни ссылок, ни фона:

```css
@media print {
  nav, .skip { display: none; }
  body { color: #000; background-color: #fff; max-inline-size: none; }
  a { text-decoration: none; }
}
```

Прятать в печати можно оглавление и служебные ссылки; содержание — нельзя:
читатель нажал «печать» ради него.

### Прокручиваемая область

Пять колонок в ладонь не входят, и уменьшать кегль нельзя. Значит, область
прокручивается:

```html
<figure class="scroller" role="region" aria-labelledby="schedule" tabindex="0">
  <table class="timetable">…</table>
</figure>
```

```css
.scroller { overflow-x: auto; }
```

Три атрибута — не украшение. `tabindex="0"` ставит область в обход: без него в
неё нельзя попасть клавишей, а значит и прокрутить без мыши. `role="region"` и
имя сообщают, куда читатель попал. Прокрутку объявляют **всегда**, а не в
добавке для узких: узким окно делает не только телефон, но и крупный шрифт на
широком экране.

### Чего медиазапрос не умеет

Он знает про окно и ничего не знает про место, куда положили блок: карточка в
узкой колонке широкого окна получит «широкие» стили и сломается. На это есть
контейнерные запросы (`container-type` и `@container`). Здесь они не нужны:
раскладку задаёт полоса целиком, и лишний механизм объяснил бы меньше, чем
стоит.

### Где это в Rails

```erb
<%= stylesheet_link_tag "application", media: "all" %>
```

`media: "screen"` встречается в Rails-приложениях по инерции — и означает, что
страница напечатается без единого стиля. Печатный набор пишут внутри свода, а
не отдельным файлом: так его труднее забыть.

**1.** ADA: «Свод написан от широкого через `max-width`. Читатель открыл полосу
там, где медиазапросы не поддержаны. Что он увидит?»

<details><summary>Ответ</summary>

Широкую раскладку в узком окне: две колонки, из которых одна ушла за край.

Основной свод — тот, что достаётся всем. Всё, что объявлено вне запроса,
получает и телефон, и читалка, и браузер, который о запросах не знает. Поэтому
в основе лежит то, без чего нельзя, а в добавке — то, что улучшает.
</details>

**2.** ADA: «Перелом задан `@media (min-width: 720px)`. Читатель поставил
крупный шрифт. Когда сработает перелом?»

<details><summary>Ответ</summary>

Ровно тогда же — на семистах двадцати пикселях. Окно не изменилось.

Но текста в строку влезает вдвое меньше, и широкая раскладка ему уже не
годится. `em` в запросе считается от настройки читателя — перелом сдвигается
вместе с ней.
</details>

**3.** ADA: «`overflow-x: auto` у таблицы и больше ничего. Кто не сможет её
прочесть?»

<details><summary>Ответ</summary>

Тот, кто работает с клавиатуры: коробка без `tabindex="0"` не попадает в обход,
фокус в неё не встаёт, прокрутить её нечем. И тот, кто слушает: без роли и
имени область не объявляется вовсе, и читатель не знает, что вправо есть ещё.
</details>

## Разбор типичных ошибок

1. **Свод от широкого, добавки через `max-width`.** Вычитать забывают.
2. **Перелом в пикселях.** Не сдвигается вместе с кеглем читателя.
3. **Семь переломов по списку устройств.** Список устареет, окна останутся.
4. **Кегли пересматриваются в медиазапросе.** Шкала уже текучая — выйдет
   скачок на переломе.
5. **В добавке потеряна область сетки.** Элемент встанет туда, куда его
   положит автоматическое размещение.
6. **Прокрутка объявлена только для узких.** Крупный шрифт делает узким любое
   окно.
7. **Прокручиваемая область без `tabindex="0"`.** Без мыши её не прокрутить.
8. **Область без роли и имени.** Читатель оказался «в коробке».
9. **Нет печатного набора** — или он прячет содержание. На бумагу уедут фон и
   оглавление; или не уедет то, ради чего нажимали «печать».
