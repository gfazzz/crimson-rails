## Обстановка

Мидленд перевёрстывает справочник. Палата обязана дать образец разметки —
такой, из которого видно, чем является каждый кусок полосы, а не как он
выглядит.

## Приказ

Разметить `artifacts/bradshaw.html`. Стилей в этой серии нет: полоса должна
быть понятна без единой строки CSS.

## Содержание полосы

| Часть | Что в ней |
|---|---|
| шапка | «Справочник Брэдшоу»; заголовок «Мидлендская линия»; выпуск за апрель 1891 года |
| оглавление | три ссылки: «Дерби — Лондон», «Лестер — Бедфорд», «Примечания» |
| раздел 1 | «Дерби — Лондон». Сообщение круглый год; составы следуют через Ноттингем (сокращённо «Нтм.») и Лестер; почтовый — без остановки в Лестере |
| подраздел | «Служебные остановки»: Колвик-Сайдингс [1] и Тоттон-Юкцион [2] |
| раздел 2 | «Лестер — Бедфорд». Сообщение с апреля по октябрь |
| примечания | 1. Колвик-Сайдингс: служебная остановка, для сверки не учитывается. 2. Тоттон-Юкцион: остановка по требованию, кроме воскресений |

## Критерии приёмки

- [ ] Объявлен `<!doctype html>`, язык страницы (`lang="ru"`) и кодировка
      `utf-8`; `<title>` заполнен.
- [ ] Ровно один `<h1>`; уровни заголовков идут без пропусков; разделов
      полосы — не меньше трёх `<h2>`.
- [ ] Ровно по одному `<header>`, `<nav>`, `<main>`, `<footer>`.
- [ ] Оглавление — список; каждая ссылка внутри своего `<li>`; у `<nav>` есть
      имя — заголовок внутри или `aria-label`.
- [ ] Ни одного `<div>`: на этой полосе для всего есть свой тег.
- [ ] Ни одного `<b>`, `<i>` и `<br>`.
- [ ] Дата выпуска — `<time>` с `datetime` вида `1891-04`.
- [ ] Сокращение станции — `<abbr>` с раскрытием в `title`.
- [ ] Примечания — `<ol>` внутри `<footer>`, не меньше двух пунктов.
- [ ] Каждая ссылка вида `href="#..."` ведёт на существующий `id`.
- [ ] На каждое примечание кто-то ссылается.
- [ ] Все шесть названий из таблицы выше присутствуют в тексте полосы.
- [ ] `make test` → девятнадцать зелёных проверок.

## Подводный камень

Соблазн взять `<div>` возникает дважды: под шапку и под раздел. Оба раза для
этого есть тег. Прежде чем писать `div`, назови вслух, чем является кусок, —
обычно после этого тег находится сам.
