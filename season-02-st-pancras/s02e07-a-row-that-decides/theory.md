# Теория — s02e07

## 1. Что такое флекс-контейнер

```css
nav ul { display: flex; }
```

Одно объявление меняет правила для **детей** элемента, а не для него самого.
Дети перестают быть блоками в потоке и становятся флекс-элементами:

- встают вдоль главной оси, а не друг под друга;
- их поля больше не схлопываются;
- `float` и `vertical-align` на них не действуют;
- ширина считается не от `width`, а от `flex-basis`.

Внутри самих детей всё по-прежнему: флекс раскладывает только своих
непосредственных потомков, на один уровень.

## 2. Две оси

```
flex-direction: row            flex-direction: column
┌──────────────────────┐       ┌──────────┐
│ [1] [2] [3]      →   │       │ [1]      │
└──────────────────────┘       │ [2]    ↓ │
главная: слева направо         │ [3]      │
поперечная: сверху вниз        └──────────┘
```

| Свойство | По какой оси |
|---|---|
| `justify-content` | главная: как распределить излишек |
| `align-items` | поперечная: как выровнять элементы |
| `align-content` | поперечная: как распределить **ряды** (нужен перенос) |
| `align-self` | поперечная: исключение для одного элемента |

Смена `flex-direction` меняет смысл первых двух разом. Это и есть главный
источник путаницы: `justify-content: center` то горизонтальное, то
вертикальное.

Значения `justify-content`: `flex-start`, `flex-end`, `center`,
`space-between` (крайние по краям), `space-around` (полуполя по краям),
`space-evenly` (равные промежутки везде).

## 3. Перенос

```css
flex-wrap: nowrap;        /* по умолчанию: не переносить */
flex-wrap: wrap;          /* переносить */
flex-wrap: wrap-reverse;  /* переносить вверх — редко и осторожно */
```

Без переноса ряд сжимает детей (`flex-shrink: 1` у всех по умолчанию) до
минимальной ширины содержимого, а дальше вылезает за край родителя. Появляется
горизонтальная прокрутка у всей страницы — и не у того, кто верстал.

`flex-flow: row wrap` — сокращение для направления и переноса вместе.

## 4. `flex` по частям

```css
flex: <grow> <shrink> <basis>;
flex: 1 1 auto;
```

| Часть | Что решает | По умолчанию |
|---|---|---|
| `flex-grow` | делить ли излишек и в какой пропорции | `0` |
| `flex-shrink` | сжимать ли при нехватке | `1` |
| `flex-basis` | с какого размера начинается счёт | `auto` |

Порядок работы браузера: взять у каждого `flex-basis`, сложить, сравнить с
шириной контейнера, разницу разделить по `grow` (если излишек) или по
`shrink` (если нехватка).

Два сокращения, которые надо различать:

```css
flex: 1;      /* = 1 1 0%   — поровну, содержимое не учитывается */
flex: auto;   /* = 1 1 auto — излишек пропорционально содержимому */
```

Первое даёт равные колонки, второе — колонки по тексту. Это разные вещи, и
путать их — причина половины «почему одна колонка шире».

`flex-basis` сильнее `width`: при `flex-basis: 0%` объявленная ширина не
учитывается вовсе.

## 5. `gap`

```css
gap: 0.5rem 1.5rem;   /* row-gap column-gap */
```

`gap` появляется **между** элементами и не появляется по краям — то, чего
полями добиться нельзя без исключения для крайнего.

Две вещи, о которых забывают:

1. во флексе поля **не схлопываются**. Собственное поле ребёнка прибавляется
   к `gap`. Объявил `gap` — сними поля детей по той же оси;
2. `gap` одинаково работает во флексе, сетке и многоколонной раскладке: это
   свойство не флекса, а общего модуля выравнивания.

## 6. Чего флекс не делает

Флекс раскладывает в **одном** направлении. Ряд ничего не знает о ряде ниже:
если пункты перенеслись, колонки соседних рядов не выравниваются между собой —
каждый ряд считает ширины заново.

Иногда это то, что нужно (обозначения, теги, кнопки). Когда нужно, чтобы
колонки совпадали, — нужна сетка, и она в `s02e08`.

## 7. Порядок: чего делать нельзя

```css
order: -1;
flex-direction: row-reverse;
```

Оба меняют порядок **на экране**, не трогая порядок в разметке. По разметке
идут: клавиша Tab, голосовой браузер, выделение текста мышью, поиск по
странице, режим чтения.

Расхождение между тем, что видно, и тем, что слышно, — не мелочь: читатель с
клавиатурой видит, как фокус прыгает из начала ряда в середину, и не понимает
почему.

Правило: раскладкой переставляют только то, где порядок ничего не значит. В
оглавлении, в списке шагов, в таблице он значит.

## 8. Частые случаи

```css
/* прижать последний элемент к правому краю ряда */
.row > :last-child { margin-inline-start: auto; }

/* центрировать по обеим осям */
.center { display: flex; justify-content: center; align-items: center; }

/* колонка во всю высоту, подвал прижат вниз */
body { min-block-size: 100vb; display: flex; flex-direction: column; }
main { flex: 1; }
```

`margin: auto` во флексе съедает весь свободный излишек по своей оси — это
единственный случай, когда поле и выравнивание делают одно и то же.
