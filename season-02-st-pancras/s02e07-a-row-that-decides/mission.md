## Обстановка

Четыре условных обозначения Прингл ставит враспор вручную четвёртый год.
Меняется формат — всё ставится заново. Свинец сам ничего не решает.

Ряд в браузере решает сам: сколько пунктов поместилось, столько и стоит, а
остальные переносятся.

## Приказ

Довести `artifacts/bradshaw.css` до третьей редакции и добавить в
`artifacts/bradshaw.html` список условных обозначений.

## Что добавить в разметку

Под таблицей расписания — `<ul class="legend">` из четырёх пунктов. Текст
короткий, обозначение и расшифровка в одну строку:

```
п — почтовый
т — по требованию
сл — служебная
× — пересадка
```

## Что добавить в свод

Новая секция **«Ряды»** — между «Полосой» и «Частными случаями». Селекторы в
ней из тегов (`header`, `nav ul`), значит по весу она встаёт именно туда;
`.legend` — класс, и его правило идёт в «Частные случаи».

| Что | Как |
|---|---|
| Шапка | колонкой, зазор объявлен `gap`, собственные поля строк сняты |
| Оглавление | рядом, с переносом, без маркеров и без отступа под них |
| Условные обозначения | тем же рядом, с переносом |

Зазоры задаются `gap`. Полей у детей ряда по той же оси быть не должно: во
флексе они не схлопываются, а складываются с зазором.

## Критерии приёмки

Проверяется настоящим браузером — по координатам боксов и вычисленным
значениям, а не по тексту файла.

- [ ] Пунктов оглавления три, и при ширине окна 1024px они стоят в одном ряду.
- [ ] `list-style-type` у оглавления — `none`, `padding-inline-start` — ноль.
- [ ] Зазоры между пунктами одинаковые и ненулевые.
- [ ] Измеренный зазор совпадает с объявленным `column-gap`: поля не
      прибавились.
- [ ] Строки шапки разделены одинаково, и расстояние между ними равно
      объявленному `row-gap`.
- [ ] Условных обозначений не меньше четырёх; при 1024px они в одном ряду и
      выровнены по одной верхней грани.
- [ ] При ширине окна 380px оглавление занимает больше одного ряда.
- [ ] При 380px условные обозначения тоже переносятся.
- [ ] При 380px ни один пункт обоих рядов не выходит за край полосы.
- [ ] Порядок пунктов на экране совпадает с порядком в разметке.
- [ ] Ссылка в обход при 1024px занимает не больше 2×2 пикселей, а по фокусу
      разворачивается.
- [ ] Свод остался сводом: ни `!important`, ни идентификаторов, правила по
      неубыванию веса, классы разметки и свода сходятся.
- [ ] Структура полосы, таблица и внутренние ссылки целы.
- [ ] `make test` → восемнадцать зелёных проверок.

## Подводный камень

`flex-wrap` по умолчанию `nowrap`. Ряд без него не переносится, а сжимается —
и, дойдя до предела, вылезает за край родителя. На широком экране это не
видно вовсе: проверять надо сужая окно.

Второй: `gap` вместе с собственными полями детей даёт сумму, а не большее.
Схлопывание полей — свойство обычного потока; флекс из него вышел.

## Выполнение

```bash
npm install                      # playwright, один раз на репозиторий
npx playwright install chromium  # сам браузер, один раз на машину

cp starter.html artifacts/bradshaw.html
cp starter.css  artifacts/bradshaw.css
make test
```

Серия помечена `NEEDS_BROWSER`: в общий прогон `make test` она не входит,
запускается через `make test-visual SEASON=02`.
