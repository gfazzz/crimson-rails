## Что даёт сезон

Разметку и стили в объёме, который делает шаблоны Rails объяснимыми. Критерий
отбора тот же, что в сезоне 1: **концепт входит, только если без него Rails
выглядит магией.**

Поэтому здесь есть семантика, таблицы, формы со встроенной проверкой,
доступность, каскад и специфичность, блочная модель, Flexbox и Grid, единицы,
медиазапросы и тёмная тема. И нет ни препроцессоров, ни сборщиков, ни
CSS-фреймворков, ни методологий именования: всё это — надстройки над тем, чего
без них не понять.

**Чем сезон кончается.** Полосу перестают набирать руками: её печатает
шаблон. Ты пишешь свой — на ERB, том самом, на котором написаны виды Rails, —
и выясняется, что шаблон умеет добавить в полосу то, чего в данных нет.

## Контракт проверки сезона

`SPEC.md` §4. Для этого сезона:

**Обязан проверять** — семантику документа разбором (`parse5`) и объявленные
свойства стилей (`css-tree`): единственный `<h1>`, порядок уровней без
пропусков, `<caption>` и `<th scope>` у таблицы, связанный `<label>` у каждого
поля, специфичность селектора, отсутствие `!important`, объявленную тёмную
тему, коэффициент контраста пары цветов. Для двух серий про раскладку —
**вычисленные координаты боксов** в настоящем браузере.

**Не засчитывается как проверка** — посимвольное совпадение с эталонной
разметкой; снимок экрана; «в CSS есть такая строка». Проверяется не текст
файла, а то, что из него следует.

## Среда

Node 18 или новее и два пакета разбора — оба чистый JavaScript, без сборки:

```bash
cd season-02-st-pancras
npm install --omit=optional     # parse5 и css-tree
```

Прогон — встроенный `node --test`, внешнего раннера нет.

```bash
make test SEASON=02             # весь сезон, без браузера
make test SERIES=s02e01         # одна серия
```

Финал сезона печатает полосу шаблоном ERB — для него нужен **Ruby 3.0 или
новее**. Гемов не нужно: `ERB` и `JSON` входят в стандартную библиотеку.

**Две серии требуют браузера** — `s02e07` (Flexbox) и `s02e08` (Grid). Они
помечены файлом `NEEDS_BROWSER`, в основной прогон не входят и запускаются
отдельно:

```bash
npm install                     # теперь и playwright
npx playwright install chromium
make test-visual SEASON=02
```

Разбор отвечает на вопрос «что написано». Браузер — на вопрос «что
получилось». Для раскладки второй вопрос единственный, который имеет смысл.

## Сквозной артефакт: `bradshaw`

Полоса расписания — та самая, которую с 1839 года печатает справочник
Брэдшоу. Растёт от серии к серии:

```
bradshaw/
├── bradshaw.html       e01–e02, e04 — разметка полосы
├── search.html         e03 — форма справочной конторы
├── bradshaw.css        e05–e11 — свод правил, семь редакций
└── bradshaw.html.erb   e12 — образец, который печатает полосу
```

Лист выпуска, по которому печатается полоса, лежит в
`s02e12-the-template-that-prints/data/april-1891.json`. Всё, что видно на
полосе, приходит оттуда; чего там нет — того нет и на полосе.

В сезоне 5 эта полоса станет видом Rails: `.erb`-шаблон из финала — тот же
самый, что лежит в `app/views`.
