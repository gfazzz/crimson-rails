## Обстановка

Полоса шире отведённого места на четверть цицеро: типография меряет по
набору, Палата — по внешнему краю рамки. Зазоры между блоками получаются то
те, то не те. А корректор требует убрать с бумаги строку «К расписанию», не
убирая её из набора.

## Приказ

Переписать `artifacts/bradshaw.css` во вторую редакцию. Разметка не меняется
вовсе: `artifacts/bradshaw.html` копируется из `starter.html` как есть.

## Что меняется во второй редакции

| Что | Как |
|---|---|
| Мера коробки | по внешнему краю, объявлено в основании для всего сразу, включая псевдоэлементы |
| Предел ширины полосы | у корня, абсолютной мерой, не долей окна |
| Внутреннее поле полосы | есть, ненулевое |
| Высота блоков | не назначается: её даёт содержимое |
| Зазоры | только вниз: `margin-block-end` и ничего вверх |
| Стороны | логические: `block` / `inline`, `inline-size` / `block-size` |
| Изображение | не вылезает за полосу |
| Ссылка в обход | спрятана от глаза, возвращается при фокусе |

## Приём сокрытия

Требуется коробка, которой для глаза нет, а для всего остального есть:

- вынута из потока (`position: absolute` или `fixed`);
- сжата до `1px` по обеим мерам — **не до нуля**;
- обрезана (`overflow: hidden` или `clip-path`);
- и **не** `display: none`, **не** `visibility: hidden`.

Парное правило на `:focus` возвращает её: положение, меры, обрезку. Оно стоит
ниже правила сокрытия и весит не меньше.

## Критерии приёмки

- [ ] `box-sizing` объявлен правилом основания весом `0-0-0`, и его селектор
      охватывает всё (`*` плюс псевдоэлементы).
- [ ] Нигде не объявлено `box-sizing: content-box`.
- [ ] Предельная ширина (`max-inline-size` или `max-width`) объявлена у корня
      (`:root`, `html` или `body`) и задана не в процентах.
- [ ] Ни одно правило, кроме правила сокрытия, не назначает блочный размер
      иначе как `auto`.
- [ ] Ни одного `margin-top`, ни одного `margin-block-start`.
- [ ] `margin-block` — только с одним значением.
- [ ] Сокращение `margin` — только нулём.
- [ ] Ни одной физической стороны: `margin-*` и `padding-*` с `top`,
      `bottom`, `left`, `right` запрещены.
- [ ] У корневого правила объявлено ненулевое внутреннее поле.
- [ ] У ссылки в обход есть собственное правило, найденное по её классу.
- [ ] В нём нет `display: none` и нет `visibility: hidden`.
- [ ] В нём объявлены положение `absolute`/`fixed`, обе меры (`1px`, если
      заданы явно) и обрезка.
- [ ] Есть правило `:focus` (или `:focus-visible`) для того же класса, и оно
      возвращает положение или обрезку.
- [ ] Правило фокуса стоит ниже правила сокрытия и весит не меньше.
- [ ] Редакция первая в силе: ни одного `!important`, ни одного
      идентификатора, для каждого свойства правила идут по неубыванию веса,
      классы разметки и правила свода сходятся один в один.
- [ ] Полоса связана со сводом; структура полосы, таблица и внутренние ссылки
      целы.
- [ ] `make test` → девятнадцать зелёных проверок.

## Подводный камень

`*` не покрывает псевдоэлементы. `:where(*) { box-sizing: border-box }` оставит
`::before` и `::after` меряться по набору — и найдётся это однажды в
декоративной черте, которая на четыре пикселя шире всего остального.

Второй: `inline-size: 0` вместо `1px` выглядит аккуратнее и работает хуже.
Коробку нулевого размера часть браузеров выбрасывает из дерева доступности —
то есть делает ровно то, что `display: none`, только незаметно.
