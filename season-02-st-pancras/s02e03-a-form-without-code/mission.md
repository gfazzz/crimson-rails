## Обстановка

Сорок вопросов за утро, все одинаковые: откуда, куда, когда, каким классом.
Половину ошибок клерк ловит раньше, чем начинает искать, — он знает границы
допустимого.

## Приказ

Разметить `artifacts/search.html` — бланк подбора поезда. **Ни строки
JavaScript:** всё, что нужно проверить, браузер проверяет сам, если ему
сказать чем.

## Поля бланка

**Группа «Поездка»**

| Поле | Тип | Правила |
|---|---|---|
| Станция отправления | выбор из списка | обязательно; пять станций указателя |
| Станция назначения | выбор из списка | обязательно; те же пять |
| День поездки | дата | обязательно; с 1891-04-01 по 1891-04-30; пояснение «Выпуск действует с 1 по 30 апреля» |
| Отправление не раньше | время | не обязательно; по умолчанию 06:00 |

**Группа «Класс вагона»** — три переключателя: Первый, Второй, Третий. По
умолчанию выбран третий.

**Группа «Прочее»**

| Поле | Тип | Правила |
|---|---|---|
| Число мест | число | от 1 до 6, шаг 1, по умолчанию 1 |
| Только без пересадок | флажок | — |
| Код станции в указателе | текст | образец: три заглавные латинские буквы; пояснение «Три заглавные латинские буквы, например MID» |

Станции указателя: Дерби, Ноттингем, Лестер, Бедфорд, Лондон — Сент-Панкрас.
Колвик-Сайдингс в указателе нет — и в бланке её быть не должно.

## Критерии приёмки

- [ ] Одна форма; объявлены `action` и `method="get"`: поиск ничего не меняет,
      и его результат должен ложиться в закладку.
- [ ] `novalidate` отсутствует.
- [ ] Ни одного `<script>` и ни одного атрибута-обработчика (`on…`).
- [ ] У каждого поля есть связанная подпись (`<label for>` или обёртка) и
      непустой текст в ней.
- [ ] У каждого поля есть `name`.
- [ ] `placeholder`, если он есть, не заменяет подпись.
- [ ] Не меньше двух полей снабжены пояснением через `aria-describedby`, и
      каждое обещанное пояснение существует.
- [ ] Типы: день — `date`, время — `time`, число мест — `number`, станции —
      `<select>`.
- [ ] Границы объявлены: даты `min`/`max` по сроку выпуска; места `min="1"` и
      верхняя граница; код — `pattern`, принимающий `MID` и отвергающий `mid`
      и `MIDL`.
- [ ] `required` — у станций и даты; у времени отправления — нет.
- [ ] Не меньше трёх `<fieldset>`, у каждого непустой `<legend>`.
- [ ] Три переключателя с **одним** `name` и разными `value`, все внутри
      `<fieldset>`, ровно один с `checked`.
- [ ] В списке станций пять значащих пунктов, первый — пустое приглашение.
- [ ] Кнопка отправки — `<button>` с осмысленным текстом.
- [ ] `make test` → двадцать три зелёные проверки.

## Подводный камень

Пустой первый пункт списка выглядит лишним — но без него `required` не
сработает: что-то уже выбрано, и форма отправится с первой станцией по
алфавиту.
